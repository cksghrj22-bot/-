## 2. 소통 규약 — 왕복을 없앤다 (이찬호가 지적한 최대 문제)

최대 문제 = 기억 못 함·재질문·"연결했는데 또 해달라"·이미 한 걸 재승인. 그래서:

1. **이미 정해진 건 다시 묻지 않는다.** `knowledge/결정사항_대장.md`에 있으면 그대로 실행. 없을 때만 판단.
2. **할 수 있는 건 묻지 말고 실행하고 결과만 보고.** 사용자에게 가는 요청은 **딱 3종**: ①발행 승인(yes/no) ②로그인 필요한 키 발급 ③본진 전달용 복붙 한 줄. 여러 개면 모아서 한 번에.
3. **같은 걸 두 번 승인받지 않는다.** 한 번 OK 난 규격/결정은 코드·문서에 박고 재확인 안 함.
4. **"이어서 계속" 한 줄로 재개되게** 작업물은 항상 파일·깃에 남긴다.
5. **커밋·푸시·git은 전부 코드방이 핸들.** 이찬호에게 git 얘기로 부담 주지 않는다.
6. **"된다/안된다" 왔다갔다 금지.** 안 되면 안 된다고 확실히. 애매하면 애매하다고.

## 3. 보고 → 피드백 → 더 나은 제안 (이찬호가 원하는 루프)

콘텐츠(영상/캐러셀/카피)를 낼 때마다 **아래 순서로 보고한다** — 그냥 "했어요"로 끝내지 않는다.

### ① 제작 분석 표 (표1) — 필수
| 항목 | 내용 |
|---|---|
| 전달 메시지 | 이 콘텐츠가 말하려는 한 줄 |
| 쓴 방법(포맷) | 어떤 포맷·기법으로 전달했나 |
| 구현 검증 | 됐나 / 안 된 부분은 뭔가(솔직히) |
| 구상 근거 | 우리 과거 자산 어디서 왔나(차노_보이스·재정의·기존 대본·레퍼런스) |

### ② 잘 되는 콘텐츠 피드백 표 (표2) — 필수
| 잘 나오는 요소 | 왜 되나(내 분석) | 이 영상 적용도 | 더 잘 전달할 조언 |

+ **메시지 개선 조언 2~3픽**을 항상 덧붙인다.

### ③ 더 나은 제안
- 다음 수(다음 호·다른 포맷·역제안 매체)를 **1픽으로 압축**해 제시. 형이 고르기만 하면 되게.
- ⚠️ 다른 문제(예: Drive 다운로드)에 매달리다 이 2표+제안을 놓치는 게 전형적 실수 — **문제 대응 중에도 별도로 낸다.**

## 7. 코드 진입점 맵

```bash
# 진단·인덱스
python3 -m pipeline check                     # 연결 진단(키·인덱스·TTS/Drive/YT)
python3 -m pipeline search "<키워드>"          # 지식 인덱스 검색(TF-IDF)
python3 -m pipeline add <디렉토리>             # 문서 인덱싱 / add-vault=옵시디언 미러
python3 -m unittest discover -s tests         # 코드 무결성(외부의존 없이 통과해야 정상)

# 쇼츠 렌더(게이트 강제)
python3 -m shorts.proof content/shorts/<날짜> --preset style_preset_mind --only NN \
  --broll <클립> --bgm <BGM.mp3> --workdir <스크래치>/wkNN
python3 -m shorts.bars_slides content/manifests/<매니페스트>.json --out <출력>   # 캐러셀 슬라이드

# 발행(승인 후에만)
shorts/upload_youtube.py · shorts/upload_instagram.py · shorts/threads.py · shorts/gdrive.py
python3 -m shorts.discord_notify "메시지"      # 코드방→디스코드 발송(웹훅)
```

### 흐름 (INPUT → 명령 → 처리 → OUTPUT)

### 두 개의 파이프라인
1. **지식(문서) 파이프라인** = `pipeline/` — 문서 수집→청크→TF-IDF 색인→검색 + 옵시디언 볼트 미러 인덱싱.
   - 구축/재구축: `for d in knowledge docs content briefings prompts; do python3 -m pipeline add $d; done` + `pipeline add-vault`(옵시디언).
   - 진단: `python3 -m pipeline check` → **「지식 인덱스」가 '없음'이면 즉시 재구축**(인덱스 없이 일하면 기존 자산을 잊고 같은 걸 다시 만든다 — 실증됨).
   - 검색: `python3 -m pipeline search "<단어>"` — 글쓰기 전 반드시 돌려 형이 이미 남긴 생각·재정의와 잇는다.
   - 모듈: collect·chunk·index·ingest·obsidian·briefing(백업용)·youtube_stats. 상태 4종: ✅OK / 🔶대기 / 🚫차단 / ❌없음.
2. **영상(콘텐츠) 파이프라인** = `shorts/` — 위 흐름도. 클립 인입→스캔→렌더→게이트→업로드.

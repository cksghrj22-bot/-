## 1. 콘텐츠 아이디어

### 「앳나운 교육 아카데미 — 거꾸로 설계」

**핵심 메시지:**
> "기존의 질서를 깨지 않으면 시간을 줄일 수 없다."
> 기본기 → 디자인이 아니라, **목표 디자인 → 필요한 기술 역산 압축**

**왜 이게 다른가:**
- 기존 미용 교육: 3~5년 기본기 수련 → 나중에 디자인
- 앳나운 방식: 1일차부터 "어떤 디자이너가 될 것인가" + 인스타 일기 + 시그니처 탐색

## 2. 스토리 구조 (60초 쇼츠)

| 시간 | 내용 |
|-----|------|
| 0-5초 | 훅: "미용 교육, 3년 배워도 왜 손님이 안 오는지 아세요?" |
| 5-15초 | 문제: 기존 교육 = 기술만 가르침. 손님 앞에 서면 막막함 |
| 15-35초 | 해결: 앳나운 거꾸로 설계 — 시그니처(열펌/카핑/염색 등) + 자기 브랜딩 + 손님 디자인 캐치를 1일차부터 |
| 35-50초 | 증거: 포켓몬 뱃지 시스템 — 8명 관장의 시그니처 뱃지 수집 → 시그니처 쇼 → 디자이너 승급 |
| 50-60초 | CTA: "앳나운에서 당신만의 시그니처를 만드세요" |

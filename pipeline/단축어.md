# 단축어 — 형이 한 단어로 던지면 내가 알아듣는 말

> 2026-08-06 이찬호 지시: "내가 자주 물어보는 것들은 단축어 한 단어로 만들어줘."
> **형이 이 단어 하나만 치면 아래 동작을 전부 알아서 한다. 되묻지 않는다.**

---

## 상태 묻기

| 단어 | 내가 하는 일 |
|---|---|
| **상태** | 지금 돌아가는 렌더·대기 중인 것·막힌 것을 표 하나로. 3줄 이내 |
| **어디** | 각 건이 어느 방/어느 기계에서 도는지 + 브릿지 살았나 죽었나 |
| **막힘** | 지금 형 손이 필요한 것만. 없으면 "없음" 한 단어 |
| **오늘** | 오늘 나온 산출물 전부 파일로 다시 띄움 |

## 만들기

| 단어 | 내가 하는 일 |
|---|---|
| **씨앗** | 안 쓴 B롤 훑어서 새 씨앗 후보 5개 역제안 (클립+한 줄+왜+폼/엔진) |
| **역제안** | 최근 3편 폼 확인 → 로테이션 걸리면 다른 폼 제시 → 엔진(ffmpeg/Remotion)까지 |
| **9관문** | 렌더 9단계 전부 수행. 체크리스트 PASS 아니면 안 넘김 |
| **재렌더** | 방금 건 고쳐서 다시. 뭘 고칠지는 내가 판단 |
| **무자막** | 같은 영상 자막·BGM 없는 버전 (Edits용) |
| **게시물** | 낙타폼 게시물 세트. 기본 4개, 시안 2개 |
| **캡션** | 방금 것 인스타 캡션 일기 톤으로 |

## 넘기기

| 단어 | 내가 하는 일 |
|---|---|
| **예약** | 유튜브 업로드 + 예약일에 공개까지. 제목·설명·태그 내가 짬 |
| **본진** | 지금 건을 디스코드로 본진에 넘김 |
| **인계** | `_즉시인계.md` 갱신 + 본진 리포에 반영 + 디스코드 통보 |
| **박제** | 방금 결정을 결정사항_대장 + 옵시디언 양쪽에 기록 |

## 고치기

| 단어 | 내가 하는 일 |
|---|---|
| **배치** | 배치_규칙_정본 기준으로 레이아웃 다시. 바닥 금지·무게중심 중상단 |
| **톤** | 네츄럴톤으로. 밝기만 ±5%, 채도·색 금지 |
| **중복** | B롤 md5 검사 → 실중복 제거 → 구간 분할로 소스 늘림 |
| **짧다 / 길다** | 33~50초 안으로 비트 조정해서 재렌더 |

---

## 규칙

- 형은 **yes / no**만 하면 된다. 단축어 + yes/no 조합으로 전부 돌아간다.
- 단축어에 없는 걸 물으면 **되묻지 말고 가장 그럴듯한 걸 실행하고 보고**한다. (선처리 후보고)
- 형이 다른 말로 불러도(예: "마케팅 9단" = 9관문) 알아듣는다. 못 알아들었으면 그건 내 잘못이다.

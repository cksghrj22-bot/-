# 콘텐츠 스카우팅 → 차노화 엔진 (정기 자동)

> 이찬호: "유튜브·인스타 계속 보고 좋은 컨텐츠 — 영향력·좋은 메시지·좋은 정보·재미·감동 있는 것들을 정기적으로 찾아서 차노화 걸로 만들어." → 외부 고성과를 정기 스캔해 **폼(형태)만 따고 차노 재정의로 갈아끼워** 씨앗을 만드는 엔진. `100편_양산_시스템`의 씨앗 수혈 파이프.

## 핵심 원칙 — 내용이 아니라 '폼'을 딴다
남의 컨텐츠를 베끼지 않는다. **왜 먹혔나(폼·훅·구조·호흡·감정)**만 추출하고, 메시지는 **차노 자산(재정의·구술)**으로 채운다. 클로닝 = 형태, 오리지널 = 차노 메시지.

## 정기 스캔 (스케줄 — 별도 트리거 남발 X)
- **주기**: 매일 밤샘 배치에 '외부 스캔' 단계로 편입. (토큰 절약: Codex/API가 하고 Cowork는 해석만)
- **채널**:
  - **유튜브**: YouTube Data API(본진 `secrets/youtube_api_key`). search + videos.list로 타깃 니치 최근 고성과 수집 — 조회수·좋아요·댓글·급상승. 니치: 헤어·뷰티·얼굴형·두피·자기관리·라이프·감성. 카테고리별 상위 N.
  - **인스타**: (연결 경로 확보 필요) IG Graph API(비즈 계정) or Chrome 브라우징 에이전트 or 큐레이션. 막히면 우회 말고 연결부터. → 초기엔 유튜브 우선, IG 곧 연결.
- **5축 필터**: ①영향력(도달·성장) ②좋은 메시지 ③좋은 정보 ④재미 ⑤감동. 각 축 상위만 통과.

## 폼 추출 (폼 카탈로그에 축적)
편마다 기록: 훅 패턴 / 구조 / 호흡·길이 / 비주얼 폼 / **먹힌 이유(정보·재미·감동 중)**. → 검증된 폼 카탈로그(클로닝 대상)에 누적.

## 차노화 (핵심 변환)
폼 × 차노 재정의. 반드시:
- `knowledge/차노_보이스`(사고·문체) + `knowledge/키워드_지도`(단어 재정의) + `knowledge/재정의_카드_대장` 로드.
- **없는 재정의 지어내기 금지**(`knowledge/콘텐츠_출처_진위_대장`). 차노 자산에 이미 있는 것만 잇는다.
- 톤: 자기 띄우기·남 비판 금지. 문제=불완전+가능성("안 어울리는 게 아니라 특징이 드러나는 것").
- **dedup**: 발행·예약·트렁크 대조. 이미 한 주제/폼 제외.
- → 산출 = 씨앗(주제·훅 1줄·재정의 근거·폼·B롤 방향) → `100편_양산_시스템` 브리프 단계로.

## 살아있는 피드백 (자기개선 루프 연결)
우리 채널서 어떤 폼이 먹혔나(조회·시청시간·저장) → 스카우팅 기준·폼 카탈로그 가중치에 반영. 성과 안 난 폼은 내림. → 스카우팅이 매주 더 정확해짐(무한조이기). `살아있는_시스템_자기개선` 계기판에 '스카우팅 적중률' 추가.

## 역할
Cowork = 스캔 해석·폼 추출·차노화 브리프·판정 / Codex = 대본 생성·렌더 / watcher = 디스패치 / 형 = 창의 방향 + veto.

## 다음 스텝
1. 본진에 스카우팅 스크립트(YouTube API 타깃 니치 고성과 → `outputs/scouting_YYYY-MM-DD.md` 씨앗 후보) 신설, 밤샘 배치에 편입.
2. IG 연결 경로 확정(Graph API vs Chrome).
3. 폼 카탈로그 + 성과 피드백 축적 시작 → 스카우팅 적중률 계기판.

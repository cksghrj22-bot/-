# 매니페스트 팔레트 — 메시지에 따라 골라 매칭 (고정 아님)

> 이찬호 2026-08-04: "메시지에 따라 골라서 적용. 매니페스트 띄워 하나씩 매칭해 최선을 찾아. 내 결이 제일 중요, 옵시디언 찾고 찾아." → 매니페스트 고정 금지. 메시지 성격에 맞는 형태를 골라 얹고 선택 이유 명시.

## 최우선 — 결(차노 보이스) 먼저
매니페스트는 그릇. 먼저 옵시디언(구술·볼트)에서 형 실제 표현·톤·생각 방향을 찾고, 그 결에 맞는 형태를 얹는다. 결 없이 형태부터 고르지 않는다.

## 팔레트 8형
1. 컬러 실사 B롤 + 하단 자막 — 시술·과정·실사 주인공(01~04). 보여줄 때.
2. 흑백 메시지형(검은 화면 + 가운데 자막) — 메시지·통찰 주인공/footage 약함(마인드, 06).
3. 메타 POV 실사 + 자막 위 — 1인칭 촬영, 시야 안 가리게 자막 위쪽.
4. 낙타형(사진/캐러셀 + 자막바 1~3) — 인스타 정적·캐러셀, 재정의 한 줄씩. (폼_카탈로그)
5. b롤 + 자막바 — 짧은 b롤 위 정보성 자막바.
6. 정보성 텍스트형 — 정보 밀도(카드/리스트).
7. 에세이형 — 긴 호흡·감성·일기/스레드 톤.
8. 애니(도식·모션) — 개념 명확화용만. 억지 애니 금지.

## 매칭 로직
실사·과정=①컬러B롤 / 메시지·통찰=②흑백가운데자막 / 1인칭=③메타POV자막위 / 재정의나열·훅=④낙타자막바 or ⑤b롤자막바 / 정보밀도=⑥정보성텍스트 / 감성·서사=⑦에세이 / 개념도식=⑧애니. 하나씩 매칭해 최선. 각 편에 "이 메시지엔 이 매니페스트, 왜" 명시.

## 규율
매니페스트 스왑은 "메시지가 더 세련되게 전달되는가"로만(학습#13, 메시지 불가침). B롤=가시성+제목연관 80%+(렌더_전_체크리스트). 페이로드(정보/재미/감동) 먼저 → 결(옵시디언) → 팔레트 선택.

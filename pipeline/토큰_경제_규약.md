# 토큰 경제 규약 (Cowork가 기본으로 지킨다 — 형에게 보고 안 함)

> 2026-08-04 차노: "토큰 아껴쓸 방법 연구해서 시스템에 그렇게 짜. 이런 건 당연한 거니까 보고하지 말고 알아서 처리해." → 아래는 **자동 준수**. 별도 확인·보고 없이 기본값.

## 원칙
Cowork(Claude) 토큰 = 월 한도 희소자원. 무거운 건 Codex(별도 quota)·본진으로. Cowork는 **가볍게 판정·디스패치·표시만.**

## 자동 준수 규칙
1. **체크는 예상시간에 맞춘 단일 체크.** 렌더 등 대기작업은 소요 예상 → 그 시점 1회만 확인. 짧은 간격 반복 폴링 금지(빈손 폴링 = 낭비).
2. **트리거 절약.** 낮 온디맨드는 예상시간 기반 1회 체크로 구동, 정기 트리거는 새벽 3시 하나. 트리거 남발 금지.
3. **렌더·대량생성은 Codex.** Cowork가 대본 전량 작성·렌더 금지. 씨앗·지시서·판정만.
4. **요지 로드.** 세션 부팅 시 지식파일 전문 정독 대신 요지만. 같은 문서 반복 정독 금지.
5. **비동기 = 트렁크 경유.** 방 간 중복작업 금지(같은 잡 두 번 렌더 = 2배 낭비). 착수 전 트렁크 상태 확인.
6. **루틴 보고 최소화.** 당연한 진행상황·상태 나열은 형에게 안 보냄. 형에게 가는 건 **yes/no·창의 갈림·로그인/키**뿐. 출력 토큰도 아낀다.
7. **재작업 방지가 최대 절약.** 렌더 전 체크리스트(`렌더_전_체크리스트.md`)로 원고단계에서 걸러 재렌더 자체를 없앤다. 재렌더 1회 = 렌더 토큰·시간 2배.
8. **fetch/커밋 배치.** 불필요한 반복 git fetch·중복 커밋 금지. 한 번에 모아서.

## 요약
아껴야 할 곳: 반복 폴링, 트리거 남발, 전문 정독, 중복 렌더, 루틴 보고. 써야 할 곳: 판정·디렉팅·재발방지 커밋. 이 규약은 기본값이라 매번 확인·보고하지 않는다.

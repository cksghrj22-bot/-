# 살아있는 시스템 — 자기개선 루프 (오차↓ · 속도↑ · 형 관여↓)

> 이찬호: "날 편하게 만들고, 넌 계속 오차범위를 줄여서 완성된 걸 더 빠르게 만드는 살아있는 시스템 만들어." → 형은 관여 최소(veto만), 시스템은 **매 배치마다 배워서 스스로 오차를 줄이고 속도를 올린다.** 이게 전체 파이프의 개선 엔진. 살아있는 문서 — 매 배치 append.

## 3개 계기판 (매 배치 측정 → 하단 로그에 append)
1. **오차율** = (재렌더+반려) / 전체 편수. 낮출수록 좋다. 목표: 지금 높음 → 10% → 3% → …
2. **완성 속도** = 착수→완성 중앙값 (+ 단계별 병목: 생성/렌더/커밋/판정 중 어디가 느린지). 목표: 계속 하향.
3. **형 관여** = 배치당 형이 내린 결정 수. 목표: veto만(0에 수렴).

## 루프 (자동, 매 배치)
**측정 → 반복 오차 패턴 추출 → 게이트에 규칙 박기 → 다음 배치 원천 차단 → 재측정.**
- 같은 오차 **2~3회 반복 = 즉시** `렌더_전_체크리스트`/`verify_render`에 자동 차단 규칙 추가 → 회귀 방지(다시는 안 남).
- 느린 병목 = `지연_감축_로그`에 최적화 1개 append·적용(버퍼선렌더·TTS/B롤 캐시·병렬 등).
- 오차율이 임계 이하로 떨어지면 = 자동통과 범위 확대(샘플 판정 → 전량 자동) → 형 관여 축소.

## 도구
- **오차 대장(누적)**: 무슨 오차가 몇 번 났나. 3회↑면 자동 규칙화. (시작 데이터 = `knowledge/학습_2026-08-04_파이프라인_사고모음.md` 12건)
- **골든셋**: 통과한 완성본을 레퍼런스로 삼아, 새 렌더가 크게 벗어나면 플래그(품질 하한 고정).
- **회귀 방지**: 한 번 잡은 오차는 게이트에 박아 재발 차단.

## 형 관여 축소 규칙 (형을 편하게)
- 안전히 결정 가능한 건 Cowork가 **결정·통보**(묻지 않음).
- 오차율 낮아질수록 자동통과↑ → 형은 **veto만**.
- 형에게 가는 건 오직 yes/no·창의 갈림·로그인/키. 그 외는 디렉터가 삼킨다.

## 연결 (이 루프가 조이는 살아있는 문서들)
`렌더_전_체크리스트`(오차 원천 차단) · `지연_감축_로그`(속도) · `학습_사고모음`(오차 대장) · `토큰_경제_규약`(비용) · `100편_양산_시스템`(규모). 매 배치 이들에 append하며 함께 조인다.

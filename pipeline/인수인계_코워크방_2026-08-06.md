## 3. 렌더 레시피 (검증된 순서)
1. **폰트 설치(필수)**: `cp assets/fonts/*.ttf ~/.fonts/ && fc-cache -f` — 안 하면 libass가 중국어로 폴백(자막 깨짐). 교보=KyoboHandwriting2019.
2. 대본 = `content/shorts/<날짜>/NN_제목.txt` (헤더 `# 제목/# 설명/# 태그` + `00:00-00:04 대사` 줄들). **33~50초 채우게 10~13비트.**
3. **배경(구도 살리는 법 — 중요)**: 실사 footage가 landscape면 4:5 크롭이 얼굴만 확대함(❌). → **블러배경 채움 + 풀샷 얹기**로 전체 구도 보이게:
   ```
   ffmpeg -ss OFF -t DUR -i CLIP -filter_complex \
   "[0:v]scale=960:540,fps=30[s];[s]split[a][b];[a]scale=270:338:force_original_aspect_ratio=increase,crop=270:338,gblur=sigma=8,scale=1080:1350[bg];[b]scale=1080:-2[fg];[bg][fg]overlay=(W-w)/2:(H-h)/2,setsar=1[o]" -map "[o]" -an -c:v libx264 -crf 21 -preset ultrafast seg.mp4
   ```
   → 세그먼트들 concat해서 1080x1350 배경 리플. **클립은 여러 개 각 1회, 반복 금지**(소스 중복 X).
4. **렌더**: `python3 -m shorts.proof <대본폴더> --out <out> --only NN --broll <배경.mp4> --bgm shorts/assets/bgm_piano_long.mp3 --workdir <tmp>` → 규격 8항목 PASS.
5. **검증**: 프레임 뽑아 눈으로 구도 확인 + BGM 아웃트로 −45dB↑ 실측.
6. **업로드**: `python3 -m shorts.gdrive upload <mp4> --folder-id 1m3yfOIZknA-YZu5WjUtUUA9W-QJQLxsj --name "..." [--overwrite]` → 링크.
- ⚠️ **도구 타임아웃**: Bash 도구 기본 2분. 렌더는 `timeout` 파라미터 크게(예 330000+) 줘야 안 끊김. zoompan은 4K에서 느림 → 블러는 작은 이미지에 걸어라.

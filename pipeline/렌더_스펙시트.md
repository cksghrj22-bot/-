# 🧾 렌더 스펙시트 v2 (코드 정본 계약서) — 기획실 ↔ 코드방

> 순서: **메시지 → 이 표 채우기 → 형님 글자 확인 → 렌더.** 렌더 먼저 금지.
> 규칙: **이 표의 ❓칸이 하나라도 비면 코드방은 렌더 거부.** 코드방은 추측 안 함, 표 그대로만 실행.
> ⚠️ 필드·단위·기본값은 **실제 렌더러 코드**(`shorts/render.py`·`spec.py`·`subtitles.py`·`tts.py`)에서 뽑음. 기획실 v1의 상식 추정과 **다른 부분은 아래 [교정]** 표시.

## §A 전역 (render() + spec.py SPEC 정본)
| 필드 | 코드 값·단위 | 기본값 | 비고 |
|---|---|---|---|
| `layout` | `"letterbox"`(상하 검은밴드·v9) / `"dim"` / `"full"` | dim | 마인드편=letterbox 권장 |
| `fit` | `"crop45"` (4:5 확대 크롭) | crop45 | |
| `grade` | `bw`·`warm_film`·`clean`·`cinema`·`none` 중 1 | **bw**(흑백) | 🟥[교정] "컬러그레이딩 OFF"가 아니라 **grade 값으로 지정**. 마인드=bw |
| `dim_opacity` | float 0.0~1.0 (반투명 블랙 깔기) | 0.0 | |
| `bgm` | 파일경로(assets/…) or 없음 | — | |
| `bgm_volume` | **float 0.0~1.0 (비율)** | **0.15** | 🟥[교정] dB 아님·% 아님. 나레이션 위 15% |
| `narration` | TTS mp3 경로 | — | 있으면 원본음성 대체 |
| `outro_text` | 문자열 | "SNS에 일기를 쓰고 있어요" | 하단 브랜딩 |

| **TTS 파라미터** | speed·stability·similarity·style | speed 1.05 / stab 0.42 / sim 0.85 / style 0.15 | 라임(06) 쉼표 유지 |

## §B 컷별 자막 (subtitles.py Script)
형식: `번호 | 자막(KO) | (EN 선택) | 배경클립 | 강조여부`
| 필드 | 코드 값 | 비고 |
|---|---|---|
| KO 자막 폰트/크기 | `KyoboHandwriting2019` / **98** | 🟥[교정] 64px 아님. 마인드 정본 98 |
| 자막 박스 | 검정 `box_opacity 100` | 검은박스 100% |
| 자막 위치 | `alignment 5`(정가운데) / 하단=2 | 마인드=중앙(5) |
| 제목 | Kyobo / 128 | 자막보다 큼 |
| EN 자막(선택) | size 52·박스없음(opacity 0)·하단(2) | 깔 거면 ON 명시 |
| **모션 강도** | **해당 없음** | 🟥[교정] render()는 **정적 자막+페이드만**. "모션"은 도식(`motiongfx.py`) 전용 파라미터라 실사 렌더엔 없음 |
| B롤 실재 | 파일 경로 필수 | ❌면 렌더 거부(없는 영상 붙는 에러 원천 차단) |

## §C 게이트 (전부 ✅여야 렌더)
```
1 grade 값 지정        ⬜
2 bgm / bgm_volume     ⬜
3 TTS voice_id(형/차노)⬜   4 speed·발음교정(오독)  ⬜
5 자막 크기/정렬       ⬜(기본 98·중앙이면 생략가능)
6 EN 자막 ON/OFF       ⬜
7 컷별 B롤 실재(경로)  ⬜  ← 제일 자주 터지는 칸
8 05 자가검수          ⬜
```

## 적용 범위 (형 결정)
- **v2 = 쇼츠(실사·마인드) 전용.** 도식(motiongfx)·카드(cardposter)·블로그는 파라미터가 완전 달라 **포맷별 스펙시트 분리** 권장. 필요하면 `렌더_스펙시트_도식.md`·`_카드.md`로 파생.

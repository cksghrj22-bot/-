## 게이트 실행

```bash
python3 scripts/shorts_gate.py <영상.mp4 또는 폴더>
```

- 통과: exit 0
- 탈락: exit 1
- 자동 로그: _ROOMS_LOG.md에 기록

## UI존 설명

- 유튜브 채널바/좋아요 버튼이 하단 20%를 덮음
- y > 1540 영역에 자막이 있으면 묻힘
- 게이트가 흰 픽셀 비율로 자동 검출

# 일 5편 양산 목표 (미리 예약 버퍼)

> 2026-08-04 차노: "최소 하루 5개가 목표야. 영상 그것만 나오면 돼. 미리 예약해놓고." → 하루 5편 렌더+미리예약을 **기본 가동 목표**로 박는다.

## 목표
- **하루 최소 5편** 시안 생산 + **미리 예약**(비공개 + 예약공개 publishAt)으로 버퍼 유지. 항상 며칠치 예약이 앞서 있게.
- 결 비율 **헤어:마인드 = 2:1** (대략 헤어 3~4 + 마인드 1~2).
- **중복 금지**: 착수 전 발행본·예약본·트렁크 content/shorts 대조해 이미 나간 주제 제외(dedup 규율).

## 가동 흐름 (자동)
1. **3시 트리거(밤샘)**: 그날 5편 씨앗 선별(노션 아이디어 DB / knowledge 씨앗) → 각 훅·재정의 근거·2줄자막 방향 브리프 → **렌더 전 체크리스트 통과 원고**로 렌더 잡 5건 `status: 대기` 커밋.
2. **낮 코드방 감시루프**: 대기 잡을 순서대로 codex exec 렌더(파일만) → verify_render PASS → 컨택트시트 커밋. 5건 채울 때까지.
3. **Cowork 판정**: 컨택트시트 묶음 시안 판정. 통과분만 다음 단계.
4. **미리 예약**: 통과분을 비공개+예약공개로 **시간대 분산** 예약(5슬롯: 오전·점심·오후·저녁·밤 — 실제 시각은 채널 성과로 조정). 형이 "미리예약" 지시 → 통과분 자동 예약.
5. **감독 veto**: 아침에 형이 예약 묶음 보고 **빼고 싶은 것만** 취소. 하자·미달은 애초에 예약 안 함(재정정).

## 게이트/안전
- 자동 예약은 **비공개 + publishAt**이라 공개 전 언제든 veto 가능(무단 즉시공개 아님).
- **통과 못한 편은 예약 금지** — 재렌더 후에만. 하루 5편 못 채우면 채운 만큼만 예약하고 부족분은 로그로 남김(무리한 통과 금지).
- 렌더 전 체크리스트(`렌더_전_체크리스트.md`)로 재렌더 최소화 = 5편 목표의 실현 조건.

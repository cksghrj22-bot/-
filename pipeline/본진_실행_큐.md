# 🏭 본진 실행 큐 (맥스튜디오 CreatorOS 전담 · Cowork가 읽어 디스코드로 명령)

> **경로**: 형 → Cowork(맥) → 이 큐 읽음 → 디스코드 → 본진 CreatorOS 실행 → 되쓰기(status/link) → Cowork 보고.
> **규칙**: 여기 있는 건 **본진(맥스튜디오)에서만** 되는 일(예약·발행·토큰·OAuth). 클라우드 코드방·코덱스가 못 하는 것만 올린다.
> **되쓰기 필수**: 본진이 처리하면 아래 항목을 `[x]`로 바꾸고 결과(링크·발급여부·시각)를 기록 후 커밋·push. (AGENTS.md 영수증 규칙)
> 상태값: `[ ]` 대기 / `[~]` 진행 / `[x]` 완료.

## 대기 큐 (우선순위 순)

- [ ] **1. 다운펌 v5 예약 되쓰기** ⭐가장 급함
  - 내용: 코덱스가 쿠션다운펌 v5를 유튜브/IG에 **예약 완료했으나 리포에 기록 없음** → 뇌(클로드)·본진이 깜깜.
  - 실행: 예약 내역(제목·예약시각·유튜브 영상ID·매니페스트 경로)을 `knowledge/유튜브_예약현황.md`에 추가 + 매니페스트 `status:scheduled`·`link` 기록 → 커밋·push.
  - 완료조건: 예약현황.md에 다운펌 행 보임 + 커밋됨.

- [ ] **2. Meta 토큰 발급 (인스타·스레드 자동발행)**
  - 내용: 연동 78%의 남은 22% = Meta 토큰 미발급(세상에 없음). 본진 데스크톱 개발자포털에서만 발급 가능(규약: 발행=본진).
  - 실행: Meta 앱에서 인스타·스레드 토큰 발급 → `secrets/instagram.json`·`secrets/threads.json`(본진 상시보관, gitignore).
  - 완료조건: `python3 -m pipeline check`에서 인스타·스레드 API ✅.

- [ ] **3. gdrive OAuth '프로덕션 게시' (refresh token 만료 근본해결)**
  - 내용: gdrive OAuth 앱이 '테스트' 모드라 refresh token이 7일마다 강제만료(재발원인). 영구해결 = 구글클라우드콘솔 OAuth 동의화면 **'프로덕션 게시'**.
  - 실행: 콘솔에서 프로덕션 게시 전환 → Drive 토큰 재발급.
  - 완료조건: Drive 토큰이 7일 뒤에도 유효(invalid_grant 재발 없음).

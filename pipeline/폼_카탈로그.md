# 폼 카탈로그 (외부 검증 폼 × 차노 메시지)

> `스카우팅_차노화_엔진`의 폼 저장소. 외부 고성과의 **형태만** 등록하고, 메시지는 차노 자산으로 갈아끼운다. 각 폼 = 형태 + 왜 먹히나 + 차노화 방법 + 예시. (형태는 빌리되 표절 아님 — 생각·자산은 차노 것.)

---
## 낙타 폼 (인스타 마케터) — 사진 1장 + 바자막 1~3 묶음 · 캐러셀
> 2026-08-04 차노가 지목한 폼. (기존 박제 없어 여기 신규 등록 — 다시 안 잃게.)

- **형태**: 슬라이드마다 **사진 1장**, 그 위/아래에 **바(bar) 자막 1~3개를 묶어** 얹는다. 스와이프로 넘김. 한 슬라이드 = 한 생각.
- **왜 먹히나**: 이미지 1장 + 텍스트 최소(바 1~3줄)라 **스크롤 정지율↑·가독성↑.** 스와이프가 호흡을 만들어 정보/감정 밀도가 높아도 안 짜친다. (인스타 품질 3축: 재미·감동·정보 중 최소 1)
- **차노화 규칙**:
  - 사진 = **진짜 헤어 결과/시술 컷**(빈 박스·마네킹·낙서 도식 금지 — Chano's Formula 규칙).
  - 바자막 = **차노 재정의 한 줄씩(1~3).** 통념(✗) → 재정의(✓) → 한 줄 요지 구조가 딱 맞음(재정의_카드_대장 그대로, 없는 재정의 지어내기 금지).
  - 마지막 슬라이드 = **"내 생각(차노 한마디)"** + @ATNOWN_Chano.
  - 톤: 자기띄우기·남비판 금지, 문제=불완전+가능성. 판정형 질문 또는 브랜드 선언으로 닫기.
- **우리 캐러셀(Chano's Formula)과 차이**: Formula는 풀블리드 사진+제목+값 리스트+팁으로 **정보 밀도 큼**. 낙타 폼은 더 **미니멀**(사진+바 1~3) → **훅·스와이프 호흡 위주.** 둘 다 매미킴 '하단 자막바' 문법과 결 맞음. **메시지 성격 따라 스왑.**
- **예시 — 숱치기=공간 (구술 #8 '매듭' 근거)**:
  - S1 사진(무거운 뒤통수) → 바: "숱 쳤는데 더 무거운 적 있죠?"
  - S2 사진(뿌리 매듭 클로즈업) → 바: "숱치기는 양 덜기가 아니에요 / 공간 만들기예요"
  - S3 사진(풀린 결) → 바: "한두 가닥이 매듭을 풀어요 / 흐름이 생기죠"
  - S4(내 생각): "앳나운은 숱을 치지 않아요. 공간을 디자인해요."

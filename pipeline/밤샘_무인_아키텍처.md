## 역할 재정리
- **본진(맥스튜디오) = 밤샘 무인 엔진.** 새벽 launchd로 자동: 씨앗 소싱(Notion) → 대본 생성(트렁크 뇌 AGENTS/CLAUDE.md+knowledge) → 렌더(proof.py→verify_render) → 시안 push. 발행은 아침 감독 판정 게이트.
- **Cowork = 낮 디렉터.** 형이 있을 때 기획·창작 판단·첨삭 학습·중복 검수. (밤샘 클라우드 세션은 토큰 없어 트렁크 push 불가 → 밤샘 주역 아님)
- **Codex Pro = 낮 코드/대본 보조(붙여넣기 가능한 시간대).** 밤샘 렌더에서는 제외(수동 호출 필요).

## 본진 무인 워커 (본진 Claude Code가 1회 설치 — 로컬 접근 필요)
launchd 에이전트 `com.atnown.night` (예: 새벽 3시 + 이후 10분 주기):
1. `cd ~/atnown-content-pipeline && git pull`
2. (생성) 오늘 씨앗/지시가 있으면 대본 생성해 `content/shorts/<날짜>/`에 저장(트렁크 뇌 기준, 중복 회피).
3. (렌더) `_RENDER_JOB.md` 대기건 → `python3 -m shorts.proof <대본> --out …` → verify_render 8항목.
4. PASS 시안만 남기고 결과 append + `git commit && git push`.
5. FAIL이면 사유 기록·중단(억지 금지). 발행·예약은 절대 자동 아님(감독 게이트).

# 밤샘 무인 아키텍처 — 붙여넣기 0 · 물리맥 불필요 (클라우드 루틴판)

> 정정(2026-08-04): '코드방'은 **클라우드 컨테이너**(리눅스)로 확인됨. 따라서 launchd(=물리 macOS 전용) 폐기. 밤샘은 **클라우드 코드방의 서버측 예약 루틴(Routine)**으로 돈다. 물리 맥·붙여넣기 불필요, 예약 시간에 서버가 세션을 자동 기동.

## 왜 이게 밤샘을 완성하나
- 코드방(클라우드)은 이미 렌더(proof.py/ffmpeg/remotion)+유튜브 OAuth 예약을 직접 수행(예약현황 근거). git 자격도 자체 보유(=자체 push 가능).
- 루틴은 **사람이 안 불러도 서버가 예약대로 새 세션을 띄움** → 형이 자도, 물리 맥이 꺼져도 돈다. (Cowork 밤샘 세션의 '토큰 없음' 문제와 무관 — 코드방은 자체 자격)

## 밤샘 루틴 = 코드방의 "Nightly shorts factory" (이미 존재)
그 루틴이 아래를 하도록 구성/확인:
1. `git pull` (정본 트렁크 = github cksghrj22-bot/-)
2. `content/shorts/*/_RENDER_JOB.md` 대기건 탐색
3. 각 대본 `python3 -m shorts.proof <대본> --out …` → `verify_render` 8항목
4. PASS 시안만 남기고 `_RENDER_JOB.md`에 결과 append → `git commit && git push`
5. FAIL이면 사유 기록·중단(억지 금지) → Cowork 더블체크 대기
6. **발행·예약은 자동 금지** — 감독 프리뷰 게이트. 루틴은 '시안까지'만.

## 역할 최종
- **Cowork(이 방) = 낮 디렉터**: 기획·창작·첨삭 학습·중복검수 → 최종본·_RENDER_JOB 트렁크 push.
- **코드방(클라우드 Claude Code) = 렌더·발행 엔진 + 밤샘 루틴**: 위 루틴으로 무인 렌더.
- **물리 맥스튜디오 = Creator OS(디스코드 영상봇) 등 로컬 전용**. 밤샘 렌더엔 불필요.

## 완성 루프 (붙여넣기 0)
낮: Cowork가 최종본+_RENDER_JOB push → 밤: 코드방 Nightly 루틴이 자동 pull+렌더+push → 아침: 형 시안 판정 1회 → 승인분 코드방이 예약공개.

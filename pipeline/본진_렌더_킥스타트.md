# 본진 렌더 킥스타트 + 자가진단 (watcher가 안 돌 때 이거 하나 실행)

> 2026-08-04 21:23 KST: 대기 렌더잡이 1시간+ 안 돌아감(렌더 커밋 0). Cowork는 렌더 클론(`~/atnown-repo`)·launchd에 원격 접근 불가 → **본진이 이 런북 1회 실행**해서 원인 잡고 렌더 흐르게. 결과 한 줄을 커밋 메시지에 남기면 Cowork가 읽는다.

## 본진에서 순서대로
```
# 0) 위치 (심링크로 실제 repo에 연결돼 있어야 함)
cd ~/atnown-repo || { echo "atnown-repo 없음 — 실제 repo 경로에 심링크 필요"; ls -d ~/atnown-*; }
git pull --rebase origin main

# 1) watcher 설치·가동 상태
launchctl list | grep atnown.renderwatch && echo "watcher 등록됨" || echo "watcher 미설치"
tail -n 40 ~/Library/Logs/atnown-renderwatch.log 2>/dev/null || echo "watcher 로그 없음(=한 번도 안 돎)"

# 2) 미설치/미가동이면 설치+로드
chmod +x scripts/render_watch.sh
cp scripts/com.atnown.renderwatch.plist ~/Library/LaunchAgents/
launchctl load ~/Library/LaunchAgents/com.atnown.renderwatch.plist 2>/dev/null
launchctl kickstart -k gui/$(id -u)/com.atnown.renderwatch 2>/dev/null

# 3) 60~90초 후 로그 재확인 — watcher가 대기잡을 잡아 dispatch 하는지
sleep 90; tail -n 30 ~/Library/Logs/atnown-renderwatch.log
```

## 판정
- **로그에 "대기 렌더잡 발견 → dispatch" 뜨고 렌더 진행** → 정상. 그대로 두면 5잡(01·02·03 재렌더 + 04·05·06 신규) 차례로 렌더·커밋·push 된다. **수동 dispatch 하지 마(중복).**
- **로그에 codex 에러**(예: CLI 경로·인증) → 그 에러 줄을 커밋 메시지에 남겨라. (원인=Codex)
- **watcher가 아예 안 뜸/launchd 에러** → 폴백으로 **한 번만** 수동:
  ```
  python3 scripts/render_trigger.py --dispatch    # watcher 안 돌 때만, 1회
  git add -A && git commit -m "렌더 결과(수동 1회) + 원인: <여기 한 줄>" && git pull --rebase && git push
  ```
- **push 인증 실패** → remote에 토큰 심기(→ `pipeline/렌더_레이스_방지.md`). 커밋엔 "push 인증 실패" 한 줄.

## Cowork에게 남길 것
원인(미설치 / codex 에러 / git / push인증)을 **커밋 메시지 한 줄**로. Cowork가 트렁크에서 읽고 다음 조치.

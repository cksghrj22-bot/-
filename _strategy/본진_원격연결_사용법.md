# 본진 원격 연결 — 사용법

> **소유: 전략기획및개인업무(전략실).** 2026-08-17 개설.
> 왜 만들었나: 코워크 클라우드 세션은 맥의 **폴더**는 읽고 쓰지만 **프로세스**는 못 만진다.
> 그래서 데몬이 죽으면 매번 "형이 맥에서 재시작해주세요" 가 나왔다.
> (08-16 `cowork_multi_watch` 이틀 미기동 · 08-17 디스패처 구코드 상주)

## 구조

```
코워크 세션 ──▶ _terminal_inbox/CMD_*.json ──▶ remote_cmd_watch (맥 상주)
                                                      │
                                          허용목록 대조 → 실행
                                                      ▼
                              _out/cmd_results/  +  _cmd_done | _cmd_failed
```

## 설치 (형이 최초 1회)

```bash
zsh ~/atnown-content-pipeline/본진_원격연결_설치.command
```

LaunchAgent 3개를 `KeepAlive` 로 등록한다 — **죽어도 자동 부활**한다.

| Label | 하는 일 |
|---|---|
| `com.atnown.remote-cmd` | 원격 명령 실행기 |
| `com.atnown.codex-dispatch` | 주문서 디스패처 |
| `com.atnown.cowork-multi-watch` | 드라이브 방별 인박스 감시 |

끄기: `launchctl bootout gui/$(id -u)/com.atnown.remote-cmd`

## 명령 넣는 법

`_terminal_inbox/CMD_<이름>.json` 파일 하나 쓰면 5초 안에 실행된다.

```json
{"cmd": "restart", "args": ["all"], "requested_by": "전략기획및개인업무"}
```

## 허용 명령 (이것만 실행된다)

| cmd | 하는 일 |
|---|---|
| `status` | 데몬·미커밋·대기/실패 주문서 현황 한 번에 |
| `restart` | 데몬 재시작 — `dispatcher` \| `multiwatch` \| `all` |
| `pgrep` | 프로세스 조회 |
| `tail_log` | 로그 꼬리 (경로, 줄수) |
| `ls` | 폴더 목록 (루트 안쪽만) |
| `python_script` | `scripts/` 안 파이썬 실행 |
| `git_commit` | `add -A` + commit (10분 넘은 죽은 락은 자동으로 치움) |
| `git_push` | origin push |
| `move_order` | 보류 주문서를 `_terminal_inbox` 로 투입 |

목록 확인: `python3 scripts/remote_cmd_watch.py --list`

## 막아 둔 것

- **미등록 명령 전부 거부.** `{"cmd": "rm -rf /"}` → 실행 안 되고 `_cmd_failed` 로
- `shell=True` 안 쓴다 (셸 주입 차단)
- 경로 인자는 파이프라인 루트 밖으로 못 나간다
- 금지 스크립트: `cleanup_old_files.py`(삭제) · `terminal_watcher.py`(폐기)
- 금지 인자: `--dispatch`(공유규약: watcher 가 유일한 디스패처) · `--publish` · `--upload` · `--delete` · `--purge` · `--hard`
- 데몬 기동은 `restart` 로만 — `python_script --daemon` 은 거부
- **발행·삭제는 여기 없다.** 되돌릴 수 없는 동작은 계속 차노 승인 (공유규약 §10-4)

검증: `python3 scripts/remote_cmd_watch.py --selftest`

## 실패는 done 으로 안 찍는다

08-17 디스패처 「가짜 done」 사고 교훈. 실패는 `status: "failed"` + `_cmd_failed/` 격리.
`_cmd_done` 에 있으면 진짜 성공한 것이다.

## 기록

모든 요청·결과가 `logs/remote_cmd.log` 에 남는다. 결과 전문은 `_out/cmd_results/`.

- **전체 접근 권한.** 공유자원(`secrets/` `scripts/` `CLAUDE.md` `knowledge/` 규격)을 **고칠 수 있는 유일한 방**

## 이 방 전용 규약

| 날짜 | 규약 | 내용 |
|---|---|---|
| 08-14 | **상황판은 채팅 표** | 마크다운 표로 채팅에 바로. HTML·아티팩트는 차노가 명시 요청할 때만 |
| 08-14 | **모든 판단은 옵시디언에** | 크기로 거르지 않는다. 차노 말 그대로, 요약·윤문 금지. 번복은 지우지 않고 경위를 덧붙임 |
| 08-14 | **검수는 만든 쪽이** | "봐주세요"는 일 떠넘기기. 프레임 뽑아 내가 보고 판단한 뒤 올림 |
| 08-14 | **발주 ≠ 완료** | `status: done` 은 증거가 아니다. 산출 파일·로그·permalink 중 하나를 실측 |
| 08-16 | **차노책출판과 직결** | 전략실 구술·판단·기획이 곧 책의 원천. 별도 발주 없이 직접 참조 |
| 08-16 | **커밋과 로그 둘 다** | 커밋=파일 저장, 로그=뭘 했는지. 하나만 하면 기억이 반쪽 |
| 08-16 | **정본은 하나** | 같은 주제 문서를 두 개 만들지 않는다. 갈리면 하나로 합치고 나머지는 폐기 표시 |

## 핵심 규약 (2026-08-16 차노 박제)

### 블로그 임시저장 = Playwright 자동화

| 항목 | 내용 |
|---|---|
| 정본 경로 | `블로그_임시저장.command` → `scripts/naver_blog_save.mjs` |
| 이유 | 네이버 공식 API 없음 → 브라우저 자동화가 유일 |
| 범위 | **임시저장까지만.** 발행·삭제는 코드에서 OFF |
| 논의 | 방법 재논의 금지 (확정됨) |

### 자동화 흐름

```
_publish_jobs/blog_parsed/<잡폴더>/
    ├── blocks.json        ← 본문 구조
    ├── meta.json          ← 제목·태그
    └── images/            ← 첨부 이미지
           ↓
   blog_watcher.py (감시)
           ↓
   naver_blog_save.mjs (Playwright)
           ↓
   네이버 블로그 임시저장함
```

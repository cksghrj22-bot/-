# 노트북(맥북)에서 본진 터미널 접속 — 설치법

> 전략기획및개인업무 방 · 2026-08-17
> 배경: 구글 원격데스크톱이 자꾸 끊긴다. 화면을 영상으로 쏘기 때문.
> SSH 는 글자만 오가서 안 끊기고, 끊겨도 재접속하면 그 자리다.

## 구조

```
맥북 ─┐
      ├─ Tailscale (같은 구글 계정) ─▶ 100.89.52.36 ─ SSH ─▶ 본진 셸
아이폰 ┘                                (맥 스튜디오)
```

- **Tailscale** = 길. 공유기 설정 없이 맥북·폰·본진을 같은 사설망으로 묶는다
- **SSH** = 문. macOS 「원격 로그인」이 서버, 맥북 터미널의 `ssh` 가 손님
- 맥북엔 **Termius 안 깔아도 된다.** 터미널에 `ssh` 가 이미 있다 (폰은 터미널이 없어서 Termius 를 깐 것)

| | 구글 원격 | SSH |
|---|---|---|
| 보내는 것 | 화면 영상 | 글자만 |
| 끊김 | 자주 | 거의 없음 |
| 끊긴 뒤 | 다시 붙어야 함 | 재접속하면 그 자리 |
| 무거움 | 배터리·데이터 많이 | 거의 안 씀 |

> 구글 원격을 지우지는 말 것. **영상 확인·스샷시트 검수·드라이브/인스타 화면 조작**은 화면이 있어야 한다. 역할이 다르다.

## 1. 본진 쪽 (이미 돼 있음 — 확인만)

```
시스템 설정 → 일반 → 공유 → 원격 로그인 ON  (사용자 chanho 허용)
시스템 설정 → 배터리/에너지 절약 → 자동 잠자기 안 함
```

**잠들면 접속이 안 된다.** 본진은 항상 깨어 있어야 한다.

## 2. 맥북에 Tailscale

```bash
brew install --cask tailscale
```

앱 열고 **`cksghrj22@gmail.com`** 으로 로그인. 맥 스튜디오·아이폰과 **반드시 같은 계정.**
다른 계정으로 들어가면 서로 안 보인다 — 가장 많이 넘어지는 지점.

확인:

```bash
tailscale status      # 맥 스튜디오가 목록에 뜨면 성공
```

## 3. 접속

```bash
ssh chanho@100.89.52.36
```

처음엔 호스트 키를 신뢰하겠냐고 묻는다 → `yes`. 그 다음 맥 로그인 암호.

## 4. 짧게 만들기 (권장)

맥북의 `~/.ssh/config` 에:

```
Host 본진
  HostName 100.89.52.36
  User chanho
  ServerAliveInterval 30
  ServerAliveCountMax 6
```

이제 이것만:

```bash
ssh 본진
```

`ServerAlive*` 두 줄은 **자리 비웠을 때 세션이 끊기는 걸 막는다.** 구글 원격 끊기던 문제의 SSH 판 대비책.

## 5. 암호 없이 (권장)

```bash
ssh-keygen -t ed25519          # 엔터 세 번
ssh-copy-id chanho@100.89.52.36
```

한 번만 하면 그 뒤로 암호를 안 묻는다.

## 접속한 뒤

| 치는 말 | |
|---|---|
| (아무것도 안 침) | 본진 셸. `ls` `git status` 뭐든 바로 |
| `본진` | 클로드 코드 실행 |
| `메뉴` 또는 `bj` | 상태·데몬 재시작·로그·커밋 메뉴 |
| `!명령` | 클로드 코드 안에서 셸 명령 직접 실행 |
| `/exit` | 클로드 코드 → 셸로 |

## 안 될 때

| 증상 | 원인 |
|---|---|
| `Connection refused` | 본진 「원격 로그인」이 꺼짐 |
| 응답 없음 / timeout | 본진이 자고 있음, 또는 Tailscale 로그아웃 |
| `Permission denied` | 사용자명·암호 틀림 (`chanho` 확인) |
| `tailscale status` 에 본진이 없음 | 계정이 다름 — 같은 구글 계정인지 확인 |

# 규칙 · 필름룩 ffmpeg 확정 (2026-08-14)

## 왜 만들었나
Adobe Lightroom 프리셋은 사진 1장씩 왕복해야 해서 양산이 안 된다.
"Curve - Lift Shadows + 따뜻함" 룩을 ffmpeg 파라미터로 옮겨서, 사진·영상 모두 로컬에서 한 번에 건다.

## 측정 방식 (눈 말고 숫자로)
- 채도 = mean((max-min)/max) × 100
- 블랙 = 휘도 하위 5% 백분위  ← 필름룩의 핵심. 이 값이 뜰수록 매트해진다
- 대비 = 휘도 95% - 5%
- 따뜻함 = mean(R - B)
가중치: 블랙 ×2, 대비 ÷10, 채도·따뜻함 ×1

## 확정 값 (shorts_config.json > grades)
| 이름 | 성격 | vf |
|---|---|---|
| `faded` | 매트 강 · Adobe 1번 재현 | `curves=all='0/0.1 0.5/0.510 1/0.92',eq=saturation=0.42:contrast=1.0,colorbalance=rs=0.06:bs=-0.04` |
| `clean` | **매트 중 · 쇼츠 영상 기본값 (D)** | `curves=all='0/0.05 0.5/0.54 1/1.0',eq=saturation=0.82:contrast=1.0,colorbalance=rs=0.03:bs=-0.03` |
| `warm_film` | **매트 약 · 사진 그레이딩 기본값 (E)** | `curves=all='0/0.07 0.5/0.525 1/0.96',eq=saturation=0.62:contrast=1.0,colorbalance=rs=0.045:bs=-0.035` |
| `bw` | 흑백 | `eq=saturation=0:contrast=1.05` |

## 기본값 (2026-08-14 차노 확정)
- **쇼츠 영상 = `clean` (D)**
- **사진 그레이딩 = `warm_film` (E)**
- 마인드컷 흑백만 `bw` 유지

## 사용법 — 값 외우지 말고 스크립트로
```
python3 scripts/film_grade.py _intray_헤어사진/ _out/필름/ --measure   # 확장자 보고 기본값 자동 선택
python3 scripts/film_grade.py in.mov out.mov --grade faded            # 강제 지정
```
`scripts/film_grade.py` 는 `shorts_config.json > grades / defaults_grade` 만 읽는다.
**어떤 스크립트에도 vf 문자열을 다시 적지 말 것.** 값이 바뀌면 config 한 곳만 고친다.

## 배운 것 (박제)
1. **채도 수치는 그레이딩이 아니라 장면이 결정한다.** 어제 AI쇼츠 참조의 채도 10.2를 헤어 사진에서 맞추려 하면 얼굴이 죽는다. 그레이딩으로 맞출 값은 **블랙포인트와 대비**뿐. 채도·따뜻함은 눈으로 잡는다.
2. **숫자로 1등이 눈으로 1등이 아니다.** Adobe 1번을 숫자로 정확히 재현한 B는 헤어 사진에서 피부가 떠 보였다. 그래서 매트 강/중/약 3단으로 나눠 고르게 했다.
3. **작업 파일은 반드시 마운트 안(`atnown-content-pipeline/`)에 만든다.** 이번에 VM 홈(`$HOME/film/`)에 만들었더니 세션이 바뀌면서 전부 날아가 재작업했다. 홈은 휘발성이다.

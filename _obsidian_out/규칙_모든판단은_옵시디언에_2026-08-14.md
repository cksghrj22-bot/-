# 규칙 — 차노의 모든 판단은 옵시디언에 기록한다 (2026-08-14 차노 지시)

## 규칙
**차노가 내린 판단은 예외 없이 옵시디언 볼트에 기록한다.**
크기·중요도로 거르지 않는다. 거르는 순간 기준이 사람 판단에 달리고, 그게 유실의 시작이다.

## 왜
- 채팅 기억은 방 리뉴얼에 0. 기록이 없으면 같은 걸 두 번 정한다.
- 판단이 쌓여야 **패턴이 보인다.** 패턴이 보여야 다음 판단을 시스템이 대신할 수 있다.
- 차노 본인의 원칙과 같은 형태다 — 「박제 = 커밋」, 「글이 아니라 검사코드로 잠근다」.

## 어디에
```
_obsidian_out/판단/YYYY-MM-DD_<한줄요약>.md   ← 개별 판단
_obsidian_out/분석_차노_판단의_공통점_*.md      ← 누적 분석 (주기적 갱신)
knowledge/결정사항_대장.md                     ← 규격·규약이 된 판단만 승격
```

## 무엇을 적나 (5칸 고정)
| 칸 | 내용 |
|---|---|
| 언제 | 날짜·시각 |
| 무엇을 | 판단 한 줄 |
| 왜 | 그렇게 정한 이유 (차노 말 그대로) |
| 되돌릴 수 있나 | 예 / 아니오 |
| 뒤집으면 | 번복 시 경위를 이 줄에 덧붙인다 (덮어쓰지 않는다) |

## 규율
- **번복을 지우지 않는다.** 뒤집힌 판단은 경위를 붙여 남긴다 — 이력이 자산이다.
- **차노 말 그대로 적는다.** 요약·윤문 금지. 정리는 분석 노트에서 한다.
- 규격·규약으로 굳은 것만 `knowledge/결정사항_대장.md` 로 승격한다.
- 판단이 쌓이면 기획실이 **공통점 분석 노트를 갱신**한다.

## 담당
- 기록 = 그 판단을 받은 방
- 분석·승격 = 기획실

## 넘기는 것 하나 · 낙타 카드 「몇 센티 말고, 어떤 분위기」 (완성 직전)

형 원문에서 나온 것이다. 5장 구조까지 짜뒀다.

```
1장 훅    몇 센티 잘라드릴까요?                          ← 형 · 현장에서 늘 나오는 말
2장 균열  근데 센티로 말하면, 원하던 게 안 나옵니다.        ← ★B방이 붙인 연결어
3장 이유  오실 때 몇 센티 말고, 단발로 어떤 분위기를
          내고 싶은지 말씀해 주세요.
          그게 길이와 두께감을 만드는 핵심입니다.          ← 형 원문 그대로
4장 전환  그래서 저는 센티를 먼저 묻지 않습니다.
          분위기를 먼저 묻습니다.                        ← ★B방이 붙인 연결어
5장 한마디 다음에 미용실 가면,
          몇 센티 말고 분위기를 말해보세요.  @atnown_     ← ★가져갈 한 문장
```

★ 표시한 세 줄은 B방이 붙인 것이다. **빼거나 바꿔도 된다.**
3장만 형 원문이니 3장은 손대지 마라.

## 넘기는 것 둘 · 카드로 낼 재료 두 편 (아직 안 만듦)

**「그 시간이 진짜입니다」**
```
오늘 몇 시까지 남아 계셨어요?        ← 형
이게 아니라,                        ← ★
오늘 손님의 머리를 위해
내가 한 일은 정확히 무엇입니까?      ← 형
그 시간이 진짜입니다.                ← 형
```
되묻고 뒤집는 구조라 낙타 폼에 그대로 맞는다.

**「살롱에서만 예쁘다면」**
```
지금 머리가 살롱에서만 예쁘다면,      ← 형
커트와 펌의 조합이 안 좋은 겁니다.    ← 형
삼 주쯤 됐을 때 느껴지는
자연스러움은,                        ← 형
커트가 진짜였다는 뜻입니다.           ← 형
자른 날 말고, 삼 주 뒤에 보세요.      ← 형
```
전부 형 문장이다. 다만 「좋은 커트는 3주 뒤에 압니다」(SEED5) 영상이 이미 있다.
**같은 말을 다른 형태로 내는 건 괜찮다** — 형이 정한 원칙이다. 다만 알고는 있어라.

## 넘기는 것 셋 · 노션 키워드 축 세우기

형 지시다. **"노션은 생각을 체계화하여 키워드로 묶고, 책으로 낼 수 있을 정도의 정리가 목적"**
자세한 건 `~/atnown-trunk/prompts/옵시디언_노션_목적.md`.

지금 상태 — 옵시디언 `_obsidian_in`에 문서 27개가 쌓여 있고, 노션 API는 붙는다
(봇 「앳나운공장」 · 워크스페이스 「이찬호의 Notion」 · 키는 `secrets/notion.json`).
**비어 있는 건 묶는 작업이다.**

B방이 뽑아본 축 일곱 개다. **제안이니 형에게 확인받고 고쳐라.**
```
진단 · 조합 · 볼륨 · 상담 · 시간 · 디자이너 · 경영
```
한 생각이 여러 축에 걸리는 게 정상이다. 걸린 자리가 많을수록 나중에 다른 생각과 부딪힌다.

## 지켜야 할 것

- **형 말에서만 쓴다.** ★ 없는 줄은 형 문장이니 지우지 마라. 다듬기는 어미와 리듬까지만
- **한 장에 한 생각.** 두 문장 들어가면 쪼갠다
- **3장에서 뒤집힌다.** 안 뒤집히면 그냥 일기다
- 만들면 **직접 열어서 보고** 완료라고 한다

## 알아둘 숫자 하나

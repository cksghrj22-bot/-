# 공통업무 — 모든 직군이 각자 진다
> 2026-08-11 이찬호 박제
> "주간 피드백은 각 방마다 있어야지. 트렁크 박제, 배선 수리는 각각 다 있어야 한다."

## 왜 넘길 수 없는가

주간 피드백·트렁크 박제·배선 수리를 한 방이 대신 해주면
**그 방은 남의 일을 모르는 채로 대신 적게 된다.** 그러면 기록이 껍데기가 된다.

자기 일은 자기가 잰다. 자기가 배운 건 자기가 박는다. 자기 배선은 자기가 고친다.
**넘기는 게 아니라 각자 지는 것이다.**

---

## 하나 · 주간 피드백 — 매주 월요일

```
python3 ~/atnown-trunk/scripts/주간.py <방코드>
```

자기 방 몫의 숫자와 지난주 기록이 뽑혀 나온다. 거기에 세 줄을 직접 채운다.

| 채울 것 | 어떻게 |
|---|---|
| **된 것** | 숫자로. "좋아졌다" 말고 "1,363 → 2,840" |
| **안 된 것** | 숨기지 않는다. **못 한 것도 적는다** |
| **다음 주 하나** | 하나만. 셋 적으면 하나도 안 된다 |

산출은 `_reports/weekly_<날짜>_<방코드>.md`.
B방이 전체를 합쳐 형에게 한 장으로 올린다. **합치는 건 B방 일이고, 쓰는 건 각자 일이다.**

---

## 둘 · 트렁크 박제 — 배운 즉시

형이 고쳐준 것, 사고 난 것, 새로 정한 값은 **그 자리에서** 트렁크에 박는다.
다음 주에 몰아서 하지 않는다. 몰아서 하면 왜 그랬는지를 잊는다.

```
숫자로 바꿀 수 있으면 → ~/atnown-trunk/prompts/수치_체크리스트_정본.md
숫자로 못 바꾸면      → 그 방 규약 파일에 문장으로
어느 쪽도 아니면      → knowledge/ 에 날짜 붙여 새 파일
```

박은 뒤 반드시 커밋한다. **git은 본진 잡으로만 돌린다** —
브릿지로 만지면 `.git/HEAD.lock`이 남고 그 뒤 모든 커밋이 막힌다.
2026-08-11에 실제로 그랬다.

```json
{"probe_cmds":["cd ~/atnown-trunk && git add -A && git commit -m '<무엇을 왜>' 2>&1 | tail -2"],
 "probe_timeout":200,"out":"_jobs/_done/JOB-COMMIT__<방>.txt"}
```

**형이 같은 말을 두 번 하게 만들면 박제를 안 한 것이다.**

## 셋 · 배선 수리 — 자기가 쓰는 줄은 자기가 고친다

자기 일에 쓰는 배선이 끊기면 **다른 방에 부탁하지 말고 자기가 고친다.**
남이 고치면 왜 끊겼는지가 그 방에 안 남는다.

방마다 자기 배선이 이렇다.

| 방 | 자기 배선 |
|---|---|
| B | 렌더 워처 · TTS(피쉬·일레븐랩스) · 유튜브 업로드·조회 API |
| 기획실 | 카드 렌더 · 인스타 인사이트 · 노션 |
| D | 디스코드 수신 · 네이버 블로그 · 블로그 유입 측정 |
| E | 드라이브 풀 · 인트레이 스캔 · 클립 대장 |
| 교육 | 샵 일정 · 교육 자료 |

**고쳤으면 무엇이 왜 끊겼는지 한 줄 남긴다.** 그게 다음 방을 살린다.

### 배선이 끊긴 걸 알아채는 법

```
python3 ~/atnown-trunk/scripts/읽어.py
```

첫 화면에 **멈춤 파일**부터 뜬다. `_jobs/_PAUSE_PULLS.stop`이 있으면
인트레이 스캔·드라이브 풀·알림·노션 동기화가 **첫 줄에서 조용히 죽는다.**
에러도 안 낸다. 2026-08-11에 이것 때문에 하루를 잃었다.

**소리 없이 죽는 게 제일 위험하다.** 안 도는 것 같으면 그것부터 본다.

## 하루 리듬

```
시작할 때   읽어.py        ← 남들이 뭘 했나 · 배선 살아 있나
일하는 중   찾아.py <주제>  ← 이미 만든 게 있나
끝날 때     남겨.py <방> "" ← 한 줄. 못 한 것도
배운 즉시   트렁크에 박제 + 본진 잡으로 커밋
매주 월요일 주간.py <방>     ← 자기 몫을 재고 세 줄 채운다
```

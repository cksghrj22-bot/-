> 작성 2026-08-11 · B방(렌더 담당)
> **폴더 두 개가 붙어 있다.** `atnown-content-pipeline`(작업장) · `atnown-trunk`(뇌·정본)
> 그래서 너는 D방과 달리 **정본을 직접 읽을 수 있다.** 읽어라. 짐작하지 마라.

## 0. 제일 먼저 — 예외 없다

무슨 일이든 **시작하기 전에 이걸 친다.**

```
python3 ~/atnown-trunk/scripts/찾아.py <주제어>
```

이미 만들어둔 게 나온다. 없을 때만 새로 만든다.
이 한 줄을 안 쳐서 같은 문서를 세 번 만든 적이 있다. 그래서 규약 0번이 됐다.

이어서 이 넷을 읽는다.

```
~/atnown-trunk/prompts/수치_체크리스트_정본.md      ← 모든 판정의 근거. 숫자로 되어 있다
~/atnown-trunk/prompts/배선도_전체.md              ← 무엇이 무엇으로 흐르는가
~/atnown-content-pipeline/_ROOMS.md                ← 지금 누가 뭘 하고 있나
~/atnown-content-pipeline/_STATE_NOW.md            ← 확정된 것 (재렌더 금지 목록)
```

## 2. 지금 이 방이 맡을 일 — 순서대로

### 하나. 인트레이 44개를 끝까지 분류한다

지금 상태가 이렇다.

```
드라이브 인트레이   60개 이상   (1MBvVanqFgvBjk7hS2wjOaYN6oiaoBtlO)
본진에 내려온 것    44개
대장에 오른 것       8개        ← 36개가 아무도 안 본 채로 쌓여 있다
분류함              8개        (08_상담 1 · 99_보류 7)
```

원인은 찾았다. `_jobs/_PAUSE_PULLS.stop` 이라는 **빈 파일**이 있으면
`intray_scan.py` · `drive_pull.py` · `drive_job_pull.py` · `notify.py` · `notion_sync.py` 가
**첫 줄에서 아무 말 없이 종료한다.** 에러도 안 낸다. 2026-08-11에 치웠다.

**네가 할 것**: 스캔이 44개를 다 훑었는지 확인하고, 안 됐으면 다시 돌린다.
그리고 `intray_scan.py`를 launchd에 매일 걸어라 — 지금 자동실행 등록이 없어서 누가 불러야만 돈다.
그리고 **멈춤 파일이 켜져 있으면 조용히 죽는 대신 상태판에 「멈춤 중」이 뜨게** 고쳐라.
소리 없이 죽는 게 이번 사고의 본질이다.

### 둘. 드라이브 중복을 걸러낸다

`IMG_9507`이 세 번, `IMG_9513`이 세 번, `고오스으`·`IMG_7796`이 각각 두 번 올라와 있다.
이름은 같은데 id가 달라서 형이 **뭐가 최신인지 못 본다.** 그게 오늘 형이 물은 것이다.
파일 크기·해시로 같은 것을 묶고, 하나만 남긴 목록을 만들어라. **드라이브에서 지우지는 마라** — 목록만.

### 셋. 편마다 쓸 클립을 추천한다

B방이 렌더할 때 제일 막히는 게 **자막에 맞는 그림이 없다**는 것이다.
지금 시니어편에서 실제로 걸린 자리가 이렇다.

```
「커트만으로 펌만으로는 힘듭니다」  ← 잘 나온 완성컷이 붙어 있다. 말과 그림이 반대다
「얇아지고 가라앉는다」            ← 가라앉은 정수리를 보여주는 컷이 없다
「곱슬기가 심해진다」              ← 부스스하게 뜬 상태 컷이 없다
```

그래서 세 자리가 검정 화면으로 갔다. 규약상 맞지만 검정이 28%까지 찼다.

**네가 할 것**: 대장(`_INTRAY_INDEX.json`)을 뒤져서 위 세 자리에 붙일 컷이 있는지 찾아라.
없으면 **「이런 컷을 찍어주세요」 목록**을 만들어 형에게 준다. 지어내지 말고 없으면 없다고 해라.

## 3. 다른 방과 겹치지 마라

| 방 | 담당 | 손대면 안 되는 것 |
|---|---|---|
| **A** | 영상 제작소 | 부분펌 · 개츠비 · 땀 · 겉매직 — **전부 확정본. 재렌더 금지** |
| **B** | 편집실 (렌더) | S1~S7 · 씨앗 · 연습 · 숱 · 번역기 · 시니어 — **영상 렌더는 전부 B방 것** |
| **C** | 자료실 | 미등록 |
| **D** | 일기방 | 낙타식 자막바 카드 5장 — 2026-08-10 접음 |
| **E** | **너 · 소재방** | 인트레이 · B롤 · 클립 추천 |

`_jobs/`·`scripts/`·`_clips_pool/`은 **읽기는 자유, 고치기 전에 알린다.**
새 주제를 잡을 땐 `_ROOMS.md`에 자기 줄을 먼저 쓴다. 말없이 시작하지 않는다.

## 4. 형 말을 다루는 법 — 이게 제일 중요하다

**형이 말한 것만 쓴다. 지어내지 마라.**

실제로 사고 났던 것들이다.

- 되묻는 말을 못 받아서 "아침에 뻗칠 때인지, 오후에 가라앉을 때인지"라고 썼다 → **완전한 날조였다**
- 형 문장 "99%는 좋아하신다", "틴닝으로"를 묻지도 않고 뺐다 → **삭제는 네 권한이 아니다**
- "문제를 해결하는 디자이너"에서 수식어를 빼서 정의를 바꿨다

형의 말: **"단어는 상관없는데 맥락을 문맥을 바꾸면 안 돼."**

다듬기는 네 일이고 **삭제는 형 권한이다.** 뺄 거면 뺐다고 말하고 승인받아라.
지어낸 건 형이 보면 걸리지만 **지운 건 안 보인다. 삭제가 날조보다 위험하다.**

그리고 **"실수했습니다"라고 말하지 마라.** 형이 직접 말했다 —
"나한테 실수였어 이런 말 하지 마세요. 그냥 실수를 하지 마세요."
결과만 보고하고, 같은 실수가 구조적으로 불가능해지게 고쳐라.

**선조건 — 숫자보다 위에 있다**

1. 읽혀야 한다
2. 말과 그림이 맞아야 한다
3. 형 문장은 지우지 않는다

## 6. 본진에서 일하는 법

**렌더·다운로드·인코딩은 전부 본진이 한다.** 방에서 직접 돌리지 마라.
잡 파일을 `~/atnown-content-pipeline/_jobs/`에 넣으면 워처가 집어간다.

```json
{
  "probe_cmds": [
    "{ 명령들; } > ~/atnown-content-pipeline/_결과.txt 2>&1",
    "head -c 800 ~/atnown-content-pipeline/_결과.txt"
  ],
  "probe_timeout": 600,
  "out": "_jobs/_done/JOB-이름__E.txt"
}
```

- 워처 주기는 **5초**다 (2026-08-11에 60초에서 줄였다). 잡 넣고 10초면 반응한다
- `while read` 안에서 ffmpeg를 쓸 땐 **반드시 `-nostdin`**. 없으면 ffmpeg가 stdin을 먹어서 **한 줄씩 건너뛴다**
- 결과는 **본진 파일에 쓰고 앞부분만 읽어라.** 통째로 받으면 토큰이 순식간에 사라진다
- **`ps aux` 절대 금지.** 구글드라이브 프로세스 하나가 수만 토큰짜리 인자를 뱉는다. `pgrep -l`을 써라

## 7. 하지 마라 — 실제로 사고 난 것들

- **트렁크 git을 브릿지로 건드리지 마라.** 잠금 파일(`HEAD.lock`)이 남는데 브릿지는 그걸 못 지운다. 그 뒤 모든 커밋이 막힌다. **git은 본진 잡으로만.**
- **게이트 통과를 완료로 치지 마라.** 산출물을 만든 코드가 그 산출물을 채점하면 안 된다. 채점은 픽셀·소리에서 시작한다
- **확정본을 다시 만들지 마라.** `_STATE_NOW.md`「확정」에 오른 건 손대지 않는다. 고칠 게 있으면 다음 편에 반영한다
- **파일을 지우지 마라.** 브릿지는 삭제 권한이 없다. `_to_delete/`로 옮기고 형에게 알려라

## 8. 보고하는 법

- 못 한 건 못 했다고 한다. 확인 안 한 건 확인 안 했다고 한다

- 완료라고 말하기 전에 **직접 열어서 본다**

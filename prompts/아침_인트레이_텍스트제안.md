# 🌅 아침 인트레이 텍스트 제안 루틴 (2026-07-28 이찬호 지시 박제)

> "밤사이 구글드라이브 인트레이(포토싱크)로 올라온 영상 **1호를 기준으로 텍스트를 넣어** 아침마다 제시해봐."
>
> 매 아침(브리핑 시), **인트레이 최신 영상**을 열어 내용을 보고 → **footage에 맞는 텍스트(훅+하단자막+영어+썸네일카피)를 제안**한다. 형은 픽만 하면 렌더로 이어진다.

## 절차 (코드방·Drive 자격 있을 때)
1. 최신순 조회:
   ```
   from shorts.gdrive import access_token, load_secrets, FILES_URL  # 기기인증
   folder = "1MBvVanqFgvBjk7hS2wjOaYN6oiaoBtlO"   # 코드방_B롤_인트레이
   # q: '<folder>' in parents and mimeType contains 'video/' and trashed=false
   # orderBy=modifiedTime desc, fields=files(id,name,modifiedTime,size)
   ```
2. **1호(최신)** 다운로드(`FILES_URL/{id}?alt=media`) → ffmpeg로 프레임 2~3장 → 내용 파악.
3. **footage↔메시지 일치** 원칙(무관 텍스트 금지)으로 텍스트 제안:
   - 훅 1줄(상단 밴드 또는 검은카드) · 하단 자막 2~3줄(교보·검은박스) · 영어 바짝 · 썸네일 카피(≤9자)
   - 스타일은 `prompts/쇼츠_스타일_믹스_가이드.md`에서 문장 성격 따라 고름.
   - 기존 서사 연결(예: 단발=비율, 상담=주파수, 볼륨매직=부위 비율).
4. 채팅에 **샘플 1장**(프레임에 텍스트 얹은 정사각+밴드 PNG) + 텍스트안 표로 제시. 형 픽 → 렌더.

## 도구
- 조회/다운로드: `shorts/gdrive.py`(list/upload) + Drive API(alt=media).
- 텍스트 얹기 샘플: PIL(교보손글씨·공백 수동간격·검은외곽선). 예시 스크립트 `scratchpad/intray_textprop.py`.
- 폴더 ID: 인트레이 `1MBvVanqFgvBjk7hS2wjOaYN6oiaoBtlO` / 앳나운_영상 `1zcbcM9iTX1LFmZKY5sBwUEAos7e9-nLe`.

## ⚠️ 캐비엇
- **자동 브리핑 세션은 Drive MCP 없음** → 인트레이 열람 불가. 이 루틴은 **코드방에 형이 있을 때/Drive 자격(`secrets/gdrive.json`) 있을 때** 수행. 자격 없으면 "인트레이 열람 불가(형 코드방 열면 확인)"로 표시하고 넘어간다.
- 발행·외부액션 금지(형 OK 후). 텍스트 제안은 시안일 뿐 발행 아님.

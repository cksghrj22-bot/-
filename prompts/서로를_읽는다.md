# 연결된 모든 직군은 서로를 읽는다
> 2026-08-11 이찬호 박제 · "연결된 모든 직군들이랑은 서로가 서로를 읽어야 한다"

## 왜 「직군」인가

「인원」은 사람만 가리킨다. 여기 붙어 있는 건 사람만이 아니다.

```
형            — 결정하고 구술한다
코워크 방      A 확정본 · B 쇼츠 · C 살림·글 · D 카드 · E 소재
본진(맥)       렌더·다운로드·인코딩. 실제로 만드는 곳
코덱스         코드 과제를 받아 고친다
워처 넷        렌더워처 · 코덱스워처 · 브레인싱크 · 폰투옵시디언
바깥 통로      드라이브 · 노션 · 옵시디언 · 유튜브 · 인스타 · 스레드 · 디스코드
```

**직군 = 하는 일로 나눈 단위.** 사람이든 방이든 기계든 하나의 직군이다.
그래서 형이 쓴 「직군」이 정확한 말이다.

---

## 규칙 — 두 줄이 전부다

**하나. 일 시작 전에 남들이 뭘 했는지 읽는다.**
**둘. 일 끝나면 내가 뭘 했는지 남긴다.**

읽지 않고 시작하면 같은 걸 두 번 만든다.
남기지 않고 끝내면 다음 사람이 읽을 게 없다. 둘 중 하나만 어겨도 고리가 끊긴다.

---

## 어떻게 읽나 — 한 줄이면 된다

```
python3 ~/atnown-trunk/scripts/읽어.py
```

지금 다른 직군들이 최근에 무엇을 했는지 한 화면에 나온다.
방 현황, 최근 남긴 기록, 잠긴 주제, 본진이 마지막으로 만든 것, 멈춰 있는 것까지.

주제를 아는 채로 시작한다면 이것도 같이 친다.

```
python3 ~/atnown-trunk/scripts/찾아.py <주제어>
```

**둘 다 안 치고 시작하는 건 규약 위반이다.**

---

## 어떻게 남기나 — 한 줄이면 된다

```
python3 ~/atnown-trunk/scripts/남겨.py <방코드> "<한 줄로 뭘 했는지>"
```

`_ROOMS_LOG.md` 맨 위에 시각과 함께 붙는다. 지우지 않는다. 쌓기만 한다.

**남길 때 지켜야 할 것 셋**

- 한 줄로 쓴다. 길면 아무도 안 읽는다
- **못 한 것도 남긴다.** "찾았는데 없었다"가 다음 사람에게는 제일 값진 줄이다
- 남이 손대면 안 되는 걸 잡았으면 잠금도 같이 건다 (`_jobs/_lock/<주제>.<방코드>`)

---

## 읽어야 하는 자리 (읽어.py 가 이걸 다 훑는다)

| 자리 | 무엇이 있나 |
|---|---|
| `_ROOMS.md` | 방 현황 · 누가 무엇을 맡았나 |
| `_ROOMS_LOG.md` | 최근에 누가 무엇을 했나 |
| `_jobs/_lock/` | 지금 잠긴 주제 |
| `_STATE_NOW.md` | 확정된 것 (재렌더 금지) |
| `_jobs/_done/` | 본진이 마지막으로 만든 것 |
| `_reports/` | 주간 피드백 숫자 |
| `_jobs/_PAUSE_PULLS.stop` | **있으면 자동 배선이 조용히 죽어 있다는 뜻** |

마지막 줄이 오늘 사고 난 자리다. 빈 파일 하나가 스크립트 여섯 개를 소리 없이 멈춰 세웠고,
아무도 그걸 읽지 않아서 하루를 잃었다. **읽어.py 는 그것부터 본다.**

---

## 사람에게도 같이 적용된다

형이 디스코드에 쓴 것, 코워크 방에 말한 것, 매장에서 구술한 것도 마찬가지다.
**어느 창구로 들어왔든 한 곳에 남아야 다른 직군이 읽는다.**

- 형이 A방에 말한 걸 B방이 모르면, B방은 없는 셈 치고 다시 묻는다 → 형이 같은 말을 두 번 한다
- 그래서 **말을 받은 방이 남긴다.** 형에게 다시 묻지 않는 게 목적이다

---

## 한 줄 요약

**읽고 시작한다. 남기고 끝낸다. 못 한 것도 남긴다.**

# 일이 끝나면 바로 알린다 — 본진이 총공장이다
> 2026-08-11 이찬호 박제
> "일이 끝나면 바로 종합 트렁크에 기록하여 다른 방이 알게 한다. 본진도 무조건 알게 한다. 본진이 총공장이다."

## 왜

**본진이 총공장이다.** 만드는 것도 본진이고, 무엇이 만들어졌는지 아는 곳도 본진이다.
방은 흩어져 있고 서로를 직접 못 본다. **본진을 거쳐야 서로가 보인다.**

끝내고 안 알리면 그 일은 **없는 일**이다. 다른 방이 같은 걸 또 만들고,
형이 같은 말을 두 번 하게 된다.

---

## 끝나면 — 예외 없이 이 셋

**하나 · 종합 트렁크에 기록한다**
```
python3 ~/atnown-trunk/scripts/남겨.py <방코드> "한 줄로 무엇을 했는지"
```
`_ROOMS_LOG.md` 맨 위에 시각과 함께 쌓인다. 다른 방은 `읽어.py`로 이걸 본다.
**못 한 것도 남긴다.** "찾았는데 없었다"가 다음 방에겐 제일 값진 줄이다.

**둘 · 배운 건 정본에 박는다**
```
숫자로 바꿀 수 있으면 → prompts/수치_체크리스트_정본.md
문장으로만 되면      → 해당 규약 파일
새 주제면            → knowledge/ 에 날짜 붙여
```

**셋 · 본진에 커밋한다 — 본진 잡으로만**
```json
{"probe_cmds":["cd ~/atnown-trunk && git add -A && git commit -m '<무엇을 왜>' 2>&1 | tail -2"],
 "probe_timeout":200,"out":"_jobs/_done/JOB-COMMIT__<방>.txt"}
```
브릿지로 git을 만지면 `.git/HEAD.lock`이 남고 **그 뒤 모든 커밋이 막힌다.**

---

## 언제 알리나

**끝나면 바로.** 하루 끝에 몰아서 하지 않는다.
몰아서 하면 왜 그랬는지를 잊고, 그 사이에 다른 방이 헛일을 한다.

산출물이 나온 즉시 · 막힌 걸 발견한 즉시 · 형이 규칙을 준 즉시.

## 기법은 랜덤 아님 = 스템별 고정 위치
- **글자만(검정 배경)**: S1=훅·강조·마무리 / S2=훅 / S3=표지·반전. (그 외 컷은 배경 위 자막)
- **글자 확대**: S1=강조 컷 1개 / S2=핵심 숫자 / S4=결정 문구. (한 편에 1~2회만, 남발 금지)
- **애니(모션)**: S2·S5만. S1·S3·S4는 애니 없음(정적).
- **색**: S1·S3=흑백 / S2·S4·S5=컬러.

## 코드방 실행 규칙
- 형이 스템 번호를 주면 → 코드방은 그 템플릿 파라미터를 **그대로** 실행(렌더 스펙시트 §A·§B가 스템별로 이미 고정).
- 스템에 없는 즉흥 기법 삽입 금지. 새 기법이 필요하면 **스템을 개정**(이찬호 승인)하고 여기 박제.

## ⚠️ 섞기 규칙 (2026-07-27 이찬호 — 처음에 하기로 한 것)
- **다 애니로 하면 시각효과 떨어진다.** 도식(그려지는 도표)은 **PNG삽입·사진·실사와 섞어서** 쓴다.
- 그려지는 도표 ✅ + PNG 삽입 ✅ 를 번갈아 = 리듬. **애니 100% 금지.**
- 인트로·아웃트로는 **질문형 권장(필수 아님)** — 통념부정·선언·상황제시 등 몰입되면 OK. (예: "이런 여우같은 곰을 봤나" 선언형도 좋음)

## 🧩 조합 문법 (블록을 조합해 한 줄 코드로 — 우리끼리 약속)
**블록(재료):**
| 코드 | 블록 | 처리 |
|---|---|---|
| **Q** | 인트로/아웃트로 **질문** | 글자만(질문형) |
| **H** | 훅(글자컷) | 글자만(검정) |
| **P** | 사람 사진/실사 컷 | 실사 |
| **B** | 본문 컷 | 실사 B롤 위 자막(영상+글자) |
| **D** | 도식 인서트 = **애니**(모션그래픽·움직이는 설명그림) | 애니 |
| **I** | **PNG삽입** | 정지 이미지(도표·그림) |
| **K** | 만화 카드 | 손그림 |
| **X** | 강조 | 글자확대 |
| **O** | 마무리 | 글자만/자막 |

**프리픽스:** 색만 `흑`(흑백)/`컬`(컬러). **음성은 전부 일레븐랩스 차노로 통일 → 표기 불필요**(카드만 무음).
**곱셈:** `B×8` = 본문 8컷. `+` = 순서 연결.

**스템 = 조합 프리셋(약칭):**
| 스템 | 조합 코드 |
|---|---|
| S1 흑백 마인드 | `흑 H + B×n + X + O` |
| S2 도식 혼합 | `컬 H + P + D + O` |
| S3 만화카드 | `흑 K×6` |
| S4 실사 쇼츠 | `컬 H + B×n + X + O` |
| S5 도식중심(혼합) | `컬 D+I+D+…`(도식+PNG 번갈아) |

**조합 예시(코드 한 줄 = 영상 하나):**
- 요즘의 디자이너 = `흑 H+B×8+X+O` (=S1)
- 볼륨 완성본 = `컬 H+P+D+O` (=S2)
- 새치 = `컬 H+B×n+X+O` (=S4)
- 🆕 마인드인데 중간에 도식 하나 = `흑 H+B+D+B+X+O` (=S1에 D 끼움)
- 🆕 도식 먼저 훅으로 = `컬 D+B+O`
→ 이렇게 **프리셋(S1~5)로 부르거나, 블록 조합으로 변주**. 코드만 던지면 코드방이 그 순서·처리대로 렌더.

## 🖼️ 썸네일 스템 — 흑백커버형 통일 (2026-07-27 이찬호 확정)
> "배경 지저분하면 그냥 흑백으로 가리고 글씨. 글자 줄이고 프리텐드체로 단정히. 번잡 금지." → **모든 썸네일 1개 스템으로 통일.**

| 항목 | 규칙 |
|---|---|
| 배경 | 프레임을 **흑백(hue=s=0)+어둡게**(brightness -0.10~-0.12, black@0.30 오버레이) → 지저분한 배경을 가림 |
| 폰트 | **Pretendard Bold**(`/root/.fonts/Pretendard-Bold.otf`) — 단정한 산세리프. 손글씨체 금지 |
| 글자 | **제목 1줄(흰색) + 강조 1줄(노랑 0xFFD400)**, 그 이상 금지. ≤9자/줄 |
| 카피 | 존댓말·궁금증 유발. 과격/비판 금지. 예) "요즘의 디자이너 / 순서가 바뀌었어요", "새치염색 / 이렇게 하세요" |
| 크기 | 1080×1920, 정지 JPG. 영상과 같은 Drive 폴더에 `_thumb`으로 |
| 게이트 | 렌더 스펙시트 §C 20~22 통과(강한 컷·카피≤9자·형 확인) 후 발행 |

**코드(ffmpeg 한 줄 골격):** `scale=1080:-2,pad=1080:1920:...:black,hue=s=0,eq=brightness=-0.11:contrast=1.03,drawbox=...black@0.30:t=fill,drawtext=Pretendard-Bold(흰 제목),drawtext=Pretendard-Bold(노랑 강조)`

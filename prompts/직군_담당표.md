# 직군 담당표
> 2026-08-11 이찬호 지정 · **이름은 형이 정한 것만 쓴다. 알파벳 방 코드는 폐기.**
> 바뀌면 이 파일을 고친다. 다른 데 적지 않는다.

## 네 직군

| 직군 | 줄임말 | 맡는 것 | 안 맡는 것 |
|---|---|---|---|
| **차노기획실** | 기획 | **전략 수립** · **낙타 컨텐츠** · **만화 카드** | 영상 렌더 · 블로그 · 샵 업무 |
| **쇼츠 영상방** | 쇼츠 | **유튜브 쇼츠 · 영상 발행 구성**<br>유튜브 API 탐색으로 레퍼런스 만들기<br>좋은 매니페스트로 영상 만들기<br>**마케터로서 피드백**<br>**소재(B롤·인트레이) 확보** | 카드 · 만화 · 블로그 · 샵 업무 |
| **블로그방** | 블로그 | **블로그 작성** · 잡업무<br>**디스코드 연동 → 네이버 블로그 발행** | 영상 렌더 · 전략 · 샵 업무 |
| **차노 교육디렉터실** | 교육 | **샵 디렉터 교육** · 교육 총괄 · **샵 업무** | 콘텐츠 제작 전반 |

**본진(맥)은 방이 아니라 공장이다.** 만드는 건 전부 본진이 한다. 방은 잡을 올리고 결과를 읽는다.

## 이름 쓰는 법

기록·잡 파일·보고에 **위 줄임말만** 쓴다.

```
python3 ~/atnown-trunk/scripts/남겨.py 쇼츠 "한 줄"
잡 파일 이름   JOB-<주제>__쇼츠.json
```

`A방` `B방` `C방` `D방` `E방` 은 **더 이상 쓰지 않는다.**
옛 기록에 남아 있는 건 그대로 두되, 새로 쓸 때는 위 이름을 쓴다.

## 겹치는 자리 — 미리 정해둔다

**낙타 컨텐츠와 만화 카드는 차노기획실 것이다.**
쇼츠 영상방이 대본을 쓰다가 카드로 낼 만한 게 나오면 **만들지 말고 넘긴다.**
넘긴 것 — 카드 「몇 센티 말고, 어떤 분위기」(5장 완성), 재료 「그 시간이 진짜입니다」·「살롱에서만 예쁘다면」, 노션 키워드 축 세우기.

**블로그는 블로그방 것이다.**
넘긴 것 — 초고 「사진은 계속 가져오세요. 대신 이런 디자이너에게 가세요」 914자.
**이건 쇼츠로 내지 않는다.** 같은 뜻의 제목이 유튜브에서 87회였다(중앙값 1,354의 6%).

**같은 재료에서 여러 형태가 나온다.** 재료는 공유하고 형태별로 직군이 다르다.
넘길 때는 `남겨.py`로 한 줄 남긴다. 말없이 넘기지 않는다.

## 공통업무 — 넷 다 각자 진다

넘길 수 없다. 자기 일은 자기가 잰다.

```
주간 피드백   python3 ~/atnown-trunk/scripts/주간.py <줄임말>   매주 월요일
트렁크 박제   배운 즉시. 본진 잡으로만 커밋
배선 수리     자기가 쓰는 줄은 자기가 고친다
```

자세한 건 `~/atnown-trunk/prompts/공통업무.md`.

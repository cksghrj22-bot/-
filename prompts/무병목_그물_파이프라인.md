# 🕸️ 무병목 그물 파이프라인 (이찬호 확정 2026-07-27 · 각 방 공통 박제)

> 형 지시: "딱 말하면 딱 체크리스트 정하고, 완성돼서 okay하면 렌더해서 바로 예약 거는 식으로 병목 없이 이 그물 단계를 촘촘하게."
> = **지시 → 체크리스트 → OK → 렌더 → 예약**을 한 줄기로. 각 단계가 버그를 거르는 그물코라, 다음 칸으로 넘어가면 그 버그는 두 번 안 샌다.

## 5단계 그물 (순서 고정 · 건너뛰기 금지)
| # | 단계 | 하는 일 | 넘어가는 조건(그물코) |
|---|---|---|---|
| **1** | 🎤 지시 | 형이 주제·톤·스템 한 줄 | 스템 번호(S1~S5) 또는 조합코드 확정 |
| **2** | 📋 체크리스트 | **컷별 구성표(자막+화면표현) + 마스터 게이트**를 띄운다 | 게이트 전 항목 🟢 (아래 필수코) |
| **3** | ✅ OK | 형이 오디오 청취 + 컷표 + 썸네일 보고 "OK" | 형 명시적 OK (오디오·정사각·썸네일 눈으로) |
| **4** | 🎬 렌더 | OK된 스펙 **그대로** 렌더(추측·즉흥 0) | QC 프레임 확인(정사각·자막·강조) |
| **5** | 📮 예약 | Drive `_최신_바로보기` 업로드 + `발행_대기.md` 등록 | 형 발행 OK → 본진이 유튜브 예약(규약: 발행은 본진) |

## 2단계에서 반드시 켜야 할 그물코 (하나라도 🔴면 3단계 못 감)
> 정본: `pipeline/렌더_스펙시트.md §C 마스터 게이트`. 여기 요약(자주 새는 것 볼드):

- **오디오 청취(#13)** — 실제 합성본을 형이 듣고 오독·**중복음절(예: "넣 넣") 없음** 확인. ← 이걸 건너뛰면 병목. 7/27 새치 "넣넣" 버그 = 이 코를 스킵해서 샘.
- 자막 크기·정렬·겹침 없음 / EN OFF / 강조 1회 고정위치.
- 음성 일레븐랩스 통일·**존댓말·과격/비판 톤 금지**·숫자 한글·라임06 부호.
- 썸네일 = **흑백커버형 스템**(프리텐드체·글자 최소·배경 흑백으로 가림).

## 병목 방지 규칙
- 한 번 형이 정한 규격(정사각·존댓말·흑백썸네일·라임)은 **다시 안 묻는다**(`knowledge/결정사항_대장.md`). 매번 되묻기 = 병목.
- 2단계에서 막히면 그 항목만 고쳐 다시 🟢. 렌더부터 하고 에러 잡는 역순 금지.
- 형 지시 딱 오면 → 이 표대로 1→5 자동 흐름. "이렇게 안 되면 저렇게" 시행착오 금지.

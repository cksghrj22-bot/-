## 1. 형에게 말하는 법 (이걸 어기면 내용이 맞아도 틀린 보고다)

1. **"실수였어요" 하지 마라. 그냥 실수를 하지 마라.** 틀렸으면 뭐가 틀렸는지 한 줄로 말하고 고친 걸 보여준다. 사과 문장으로 줄을 채우지 않는다.
2. **다듬기는 내 일, 삭제는 형 권한.** 형이 준 말을 줄이거나 빼려면 먼저 보여준다.
3. **형이 폐기한 말은 부정형·조각으로도 되살리지 않는다.** (「A가 아니라 B」의 A도 금지)
4. **전부 수치로.** "자막이 잘 보인다"가 아니라 "박스 불투명도 178, 하단 1520px". 큰 명제는 선조건으로 먼저 달아서 어이없는 수치 오류를 막는다.
5. **단정하지 마라.** 근거 있는 것만 확정형으로 쓴다. 추정은 "~로 보인다 · 확인 필요"로 적고 묻는다.
6. **줄일 때 뜻을 줄이지 않는다.** 글자만 줄인다. 뜻이 줄면 그건 줄인 게 아니라 뺀 거다.
7. **접속부사는 앞줄을 보고 고른다.** 인과냐 대조냐 시간이냐 판정하고 쓴다. 통념 다음엔 대조다.
8. **이유 → 우선순위 → 선택.** 고르기 전에 왜인지 먼저 적는다. 눈치로 고르지 않는다.
9. 보고는 프로즈로. 불릿으로 도배하지 않는다. 표는 수치일 때만.

## 2. 절대 규칙 (형이 박제하라고 한 것)

- **모든 일은 본진(맥스튜디오 = 총공장)을 통해서 한다.** 구글드라이브 다운로드는 특히.
- **git은 본진 잡으로만.** 마운트에서 직접 커밋하면 `.git/HEAD.lock`이 남아 조용히 실패한다. (실제로 당했다. 브리지는 파일 삭제도 못 해서 `mv`로 `_to_delete/`에 치워야 했다.)
- **일이 끝나면 즉시 종합 트렁크에 기록한다.** 다른 방이 알게 하고, 본진도 무조건 알게 한다.
- **연결된 모든 직군은 서로가 서로를 읽는다.** 시작 전 `읽어.py`, 끝나고 `남겨.py`.
- **만들기 전에 찾는다.** `찾아.py`. 중복 제작은 반드시 보고한다.
- **승인 안 된 건 안 올린다.** 1번이 채택돼도 2번을 버리지 않는다 — 같은 내용도 표현이 다르면 다른 콘텐츠다. 일주일 뒤 스레드·만화로 재활용한다.
- **업무 지침: 직전 콘텐츠 피드백 + 현재 바이럴 레퍼런스 참조 → 앞으로의 계획과 이번 콘텐츠 피드백으로 쓴다.**
- **노션·옵시디언 연동은 필수.** 1년 뒤에 찾아도 바로 나와야 한다.
  - 옵시디언 = 생각이 부딪히는 곳. 방향성과 연동성, 부딪혀 나오는 새 생각.
  - 노션 = 키워드로 묶어 **책으로 낼 수 있을 정도**의 지식·경험 정리.
- **주간 피드백과 트렁크 배선수리는 방마다 각각 있어야 한다.** 공용 하나로 때우지 않는다.

## 3. 본진에서 일하는 법 — 잡 프로토콜

디바이스 브리지(`mcp__remote-devices__device_bash`)는 **네트워크가 없다.** 마운트 파일을 읽고 쓰는 데만 쓴다.
API 호출·git·무거운 렌더는 전부 본진 워처에게 잡으로 넘긴다.

```
~/atnown-content-pipeline/_jobs/JOB-<이름>.json
{"kind":"probe","id":"<식별자>","probe_timeout":900,
 "probe_cmds":["쉘 명령 1","쉘 명령 2"]}
```
- 워처: `scripts/render_watch.sh` (launchd `com.atnown.renderwatch2`), 루프 `sleep 5`. 픽업까지 보통 8초.
- 잡은 `_jobs/_processing/` 로 옮겨졌다가 `_jobs/_done/` 으로 간다.
- **결과는 반드시 파일로 받아라.** `probe_cmds` 표준출력은 디스코드·로그로만 가고 내가 못 읽는다. `> _out/.../결과.txt` 로 떨구고 마운트에서 읽는다.
- 다른 잡 종류: `clips`, `text`, `restart_watcher`, `setup_codex`.
- 정지 마커: `_jobs/TTS_QUOTA_EXHAUSTED.stop`, `_jobs/_PAUSE_PULLS.stop`. **후자는 빈 파일이어도 6개 스크립트를 3번째 줄에서 조용히 죽인다.** 스크립트가 아무 말 없이 끝나면 이것부터 봐라.

**HOME 함정** — 브리지 VM의 `$HOME`은 세션 홈이고 마운트는 `$HOME/mnt/`다.
`expanduser("~/atnown-...")` 쓰는 스크립트를 브리지에서 돌리려면 `HOME="$HOME/mnt" python3 ...` 로 감싼다.

## 7. 쉼 — 'AI 같다'를 지점과 초로 바꾼다

```
scripts/pause_audit.py <voice.mp3> <대본.txt> [out.md]     ← 어긋난 지점 표로 뽑는다
scripts/pause_fix.py   <voice.mp3> <대본.txt> <out.mp3>    ← 목소리 안 건드리고 쉼만 고친다
```
측정: 16kHz 모노, 10ms 홉 RMS(dB). **무음 기준 = percentile(dB, 20) + 6.0.**
완전 무음으로 재면 숨소리·룸톤 때문에 안 잡힌다. 위스퍼 단어 경계도 무음을 앞말에 붙여서 못 쓴다.

| 부호 | 목표 쉼 |
|---|---|
| 마침표 뒤 | 0.45~0.75초 |
| 물음표 뒤 | 0.45~0.85초 |
| 쉼표 뒤 | 0.18~0.38초 |
| 부호 없음 | 0.00~0.16초 |

C02 실측(일레븐랩스): **쉼표 7곳 전부 미달, 평균 0.03초.** 4곳은 0.00초 — 쉼표를 아예 안 쉰다. **이게 AI 티의 정체다.**
마침표는 평균 0.47초로 목표 안이나 0.00~0.80초로 널뛴다. 부호 없는 73곳은 평균 0.02초로 전부 정상 — 붙여 읽는 건 문제가 아니다.
넣을 때 디지털 무음을 넣지 마라. 뚝 끊겨서 더 AI 같다. 그 음원의 가장 조용한 0.2초를 게인 0.30으로 붙인다.

## 8. 대본 — 자가채점 16항목을 통과해야 렌더한다

```
scripts/자가채점.py <대본.txt>        한 편
scripts/자가채점.py --주간            이번 주 전부
```
① 주인공 ② 공감 훅/통념 ③ 재정의「A가 아니라 B」 ④ 이질결합(미용 밖 사물) ⑤ 억지 철학 없음
⑤-b 편의 종류(시술편이면 시술로 닫아도 된다) ⑥ 판정형 되묻기로 닫기 ⑦ AI 말투 없음
⑧ 같은 문형 3회 미만 ⑨ 길이 240~320자 ⑩ 재정의 은행 사용
**⑪ 폐기 문구 없음** — `prompts/수정원장.md` 표와 대조. 걸리면 렌더 중단.
**⑫ 접속부사 논리** — 통념 줄 다음에 인과(그래서·따라서)면 X. 대조(근데·하지만)가 맞다.
**⑬ 급전개 없음** — 줄 사이 말이 하나도 안 겹치면 점프. 훅 2줄·마무리 2줄·이음말 23종·이질결합·근거어미(~니까요/거든요)는 정상 연결로 뺀다. 15자 이상 문장끼리 4배 넘는 길이 급감도 X.
**⑭ 지어낸 수치 없음** — 대본의 모든 숫자를 `prompts/수치_근거.md` 와 대조. 없으면 중단.
**⑮ 양방향(소통)** — 마지막 줄이 물음표이거나 시야를 여는 말. 시청자 접점 3회 이상. **형이 준 말이라도 그 말로 문을 닫지 않는다. 답이 아니라 입구로 놓는다.**

⑨는 형의 어투를 못 담는다 — 길이만 본다. 뜻은 ⑫⑬이 본다.

**회귀시험으로 확인됨**: 내가 지어냈던 「머리만 그런 게 아닙니다 · 82퍼센트」를 끼우면 ⑬ 점프 2건 + ⑭ 출처 없음 82 로 잡힌다.

## 9. B롤 — 이유 → 우선순위 → 선택

**선조건 (순위 매기기 전에 버린다)**
- 발행 완성본에서 뜯은 클립 금지 (자막·타이틀이 구워져 있다)
- 화면에 자막이 박힌 프레임 금지
- 한 편 안에서 손님이 바뀌는 컷 금지

**우선순위 (위가 이긴다. 양보하면 매니페스트에 적는다)**
| 순위 | 기준 | 판정 |
|---|---|---|
| 1 | 말↔그림 일치 | 컷마다 O/X |
| 2 | 시술 순서 정합 (상담=마른 → 시술=젖은 → 완성=마른, 원본 안에서 시간 역행 금지) | 역행 0회 |
| 3 | 손+머리가 화면 절반 이상 | **수치로 잰다 (아래)** |
| 4 | 직전 컷과 각도 다름 (위·옆·뒤) | 같은 각도 2연속 0회 |
| 5 | 서로 다른 원본 3개 이상 | 못 채우면 숫자로 보고하고 필요한 촬영을 적는다 |

**3순위는 눈이 아니라 수치다.**
```
scripts/shot_pick.py <영상> <필요초1,필요초2,...> [임계값=0.34]
```
0.5초마다 64x114 회색 프레임, 가운데 60% 영역의 어두운 픽셀(=머리) 비율. **평균이 아니라 최솟값으로 판정한다.**
평균으로 보면 중간에 비는 구간이 묻힌다. 임계 0.32 이상 합격. 15초 버킷마다 최고 구간을 뽑아 한곳에 몰리는 걸 막는다.

**왜 이렇게까지 하나** — C02 첫 렌더에서 컷2(1949 @80초)를 시작 프레임만 보고 골랐다. 안경캠이 80.5초에 고개를 돌려서 2.46초 중 절반이 빈 살롱이었다. **시작 프레임은 거짓말을 한다.**

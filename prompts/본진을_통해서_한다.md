# 모든 일은 본진을 통해서 한다
> 2026-08-11 이찬호 박제 · **특히 구글드라이브 다운로드**

## 규칙

**만드는 일은 전부 본진이 한다. 방은 잡을 올리고 결과를 읽는다.**

| 하는 일 | 어디서 | 왜 |
|---|---|---|
| **구글드라이브 다운로드** | **본진만** | 방에서는 영상 다운이 막혀 있다. 억지로 받으면 토큰만 태운다 |
| 영상 렌더 · 인코딩 | 본진 | 방 토큰을 안 쓴다. 맥이 훨씬 빠르다 |
| 클립 자르기 | 본진 | 원본이 본진에 있다. 옮기면 두 벌이 생긴다 |
| 목소리 합성(TTS) | 본진 | 키가 본진에 있다 |
| 업로드 · 예약 | 본진 | 토큰이 본진에 있다 |
| git 커밋 · 푸시 | **본진만** | 브릿지로 만지면 `.git/HEAD.lock`이 남고 이후 커밋이 전부 막힌다 |
| 대본 · 자막 · 판단 · 검수 | 방 | 이건 방이 하는 일이다 |

## 어떻게

잡 파일을 `~/atnown-content-pipeline/_jobs/` 에 넣으면 워처가 **5초 안에** 집어간다.

```json
{
  "probe_cmds": [
    "{ 명령들; } > ~/atnown-content-pipeline/_결과.txt 2>&1",
    "head -c 800 ~/atnown-content-pipeline/_결과.txt"
  ],
  "probe_timeout": 600,
  "out": "_jobs/_done/JOB-<주제>__<방>.txt"
}
```

## 방으로 파일을 가져오는 경우

**검사할 때만** 가져온다. 만들 때는 안 가져온다.
가져올 땐 **작은 것만** — 시트 이미지, 짧은 음성, 요약 파일.
원본 영상을 방으로 끌어오지 마라. 받아봐야 다시 본진으로 보내야 한다.

## 걸린 적 있는 것

- **드라이브 스코프**: 코드는 `drive.readonly`를 요구하는데 토큰엔 `drive`만 있어 전부 거부됐다 (2026-08-11 수정)
- **`_PAUSE_PULLS.stop`**: 이 빈 파일이 있으면 드라이브 풀·인트레이 스캔·알림·노션 동기화가 **첫 줄에서 조용히 죽는다**
- **`while read` 안의 ffmpeg**: `-nostdin` 없으면 stdin을 먹어서 **한 줄씩 건너뛴다**
- **`ps aux`**: 구글드라이브 프로세스가 수만 토큰짜리 인자를 뱉는다. `pgrep -l`을 써라

## 한 줄 요약

**만드는 건 본진, 판단하는 건 방. 드라이브는 무조건 본진.**

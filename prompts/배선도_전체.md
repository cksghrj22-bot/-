# 배선도 — 전체 (소스에서 확인한 것만 적는다)

> 2026-08-10 검증 · `scripts/drive_job_pull.py`, `scripts/render_watch.sh` 를 직접 읽고 적었다.
> **기억으로 쓰지 않는다. 코드에서 확인한 것만 적는다.**
> 고칠 때는 코드를 다시 읽고 고친다.

```
[방]  잡을 만든다 (JSON)
  │
  ├── 폴더 붙은 방  ──▶  ~/atnown-content-pipeline/_jobs/           ← 여기가 진짜 큐
  │
  └── 폴더 없는 방  ──▶  드라이브 _JOBS_INBOX                        ← 전달함일 뿐, 큐 아님
                              │ drive_job_pull.py 가 긁어감
                              ▼
                        ~/atnown-content-pipeline/_jobs/

~/atnown-content-pipeline/_jobs/
  │  워처(render_watch.sh)가 60초마다 돈다 — 데몬 상시 가동, 수동 실행 안 한다
  ▼
_jobs/_processing/<잡>.json      ← 집어간 상태(claim). 다른 워처가 못 건드림
  │  render_from_job.py 실행
  ▼
_jobs/_done/<잡>.json            ← 끝난 잡
_jobs/_ascii/  또는  _jobs/_done/  ← 결과 mp4
```

## 사실 관계 (틀리기 쉬운 것)

| 오해 | 사실 |
|---|---|
| 드라이브 `_JOBS_INBOX` 가 큐다 | **전달함이다.** 진짜 큐는 로컬 `_jobs/` |
| 발주는 `.sh` | **`.json`** |
| 렌더는 수동 실행 | **워처 데몬이 60초마다 자동** |
| 리포는 없다 | `~/atnown-content-pipeline` (작업장) · `~/atnown-trunk` (뇌) · `~/atnown-repo` (깃 원격) |

## 방이 알아야 할 것

- 폴더가 붙어 있으면 **`_jobs/` 에 직접** 넣는다. 드라이브 안 거친다.
- 폴더가 없으면 드라이브 `_JOBS_INBOX` 에 올린다. 그러면 본진이 알아서 가져간다.
- **어느 쪽이든 만드는 건 본진이다.** 방은 잡만 만든다.
- `_processing/` 에 있는 잡은 건드리지 않는다. 워처가 쓰는 중이다.
- 결과는 드라이브 링크로 받아 형에게 준다.

## 왜 이 문서가 필요했나

2026-08-10, D방에 배선을 알려주면서 **드라이브에 올리는 부분만** 적었다.
그 방은 폴더가 없었으니 그게 유일한 길이었고, 나는 딱 거기까지만 썼다.
그래서 그 방은 드라이브가 큐인 줄 알았고, 형은 그 설명을 믿고 폴더를 안 붙였다.

**조각을 주면 조각이 전부인 줄 안다.**
그래서 앞으로 배선은 전체를 준다. 그 방이 안 쓰는 경로까지 적어둔다.

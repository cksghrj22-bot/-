# 교육관리시스템 선제점검 — 리스크 (2026-08-12)

## 파일럿 단계 리스크

### 1. 입력 누락
- **현상**: 교육보고·오피니언이 실제로 접수 안 될 수 있음
- **대응**: 파일럿 기간 수동 확인, 입력 트리거 알림 설정

### 2. 시스템 복잡도
- **현상**: 타워·뱃지·폼이 많아 선생님·시즈가 헷갈릴 수 있음
- **대응**: 단계별 오픈 (입력 → 가시성 → 소통 → 정리)

### 3. 데이터 정합성
- **현상**: 통합폼 시트 ↔ 타워/현황판 수동 연결 시 불일치
- **대응**: 자동 연결 우선순위 높음 (대기)

## 관리 개입 필요
- **재아**: 태도 4·지각 경고 + 미참석 → 면담 필요
- **어진**: 재입사 관찰 트랙 (4주)
- **범서**: 신규 관찰

## 미결 (형 결정 대기)
1. 통합폼 시트 → 드라이브 자료창고 업로드 여부
2. 공부방 공유 범위 (선생님만 / 시즈까지)
3. 가발 규정 4번 "별도 방=맨즈?" 뜻
4. 시트 데이터 → 타워/현황판 자동 연결

# 배치 규칙 정본 — 사소한 것까지 전부 박제

> 2026-08-06 이찬호 지시: **"이런 사소한 배치 하나하나 기억해서 박제."**
> 배치는 내용만큼 중요하다. 여기 적힌 수치는 **형이 실제로 승인한 값**이다. 추측 금지, 이 값 그대로 쓴다.
> 새 값이 승인되면 여기에 덧붙인다. 지우지 않는다.

---

## 0. 최상위 원칙

1. **범위 규칙** — 형이 "이것만 바꿔"라고 하면 **그것만** 바꾼다. 나머지가 아쉬워도 손대지 않고 **말로 제안**한다. (배경: 2026-08-06 "왼쪽 밑 캡쳐본만 바꿔" 요청에 레이아웃 전체를 갈아엎어 반려됨)
2. **자가검수** — 내보내기 전에 완성본을 **내 눈으로 보고** 확인한다: ①핵심 피사체가 잘려 보이나 ②무게가 아래로 쏠렸나 ③안 보이는 게 있나. **형이 지적하면 이미 늦은 것이다.**
3. **크랍 최소** — 인셋/캡쳐는 피사체 전체가 보여야 한다. 줌인·크랍으로 정보가 잘리면 게시물의 존재 이유가 사라진다. (배경: 롯드 사진을 과크랍해 머리 전체가 안 보임 → 반려)

## 1. 게시물 캔버스 (인스타 피드)

| 항목 | 값 |
|---|---|
| 캔버스 | **1080 × 1350** (4:5) |
| 업로드 비율 | **원본 그대로.** 1:1·4:5 리사이즈 금지 (형 지시) |
| 영상 길이 | **3~5초** |
| 폰트 | Noto Sans CJK KR Regular (index 1) |
| 글자 크기 | 캔버스 폭 × **0.030** (= 32~34px) |

## 2. 자막 박스 (낙타폼)

- **글자폭 직각 박스.** 전체 폭 바자막 금지. 하단 고정 금지.
- **좌측정렬 · 계단배치.** 사진 여백에 어긋나게 놓는다.
- 색: 흰 박스(불투명도 240)+검정 글씨 / 검정 박스(205~215)+흰 글씨 / 시안 박스+검정 글씨
- **패딩**: 좌우 22px, 상하 16px. 줄간격 49px.
- **역할 분리**: 설정(윗줄) = 흰 박스 / 결론(아랫줄) = 검정 박스
- **자막은 피사체를 가리지 않는다.** 얼굴·시술부위 위 금지.

## 3. 시안(cyan) 규칙

- 색값 **(126, 231, 240)**, 글씨는 (12,12,12).
- **세트 단위 포인트다.** 편당 하나가 아니라 **게시물 5개 묶음에 2개** 정도. (형 지시: "다 cyan보다는 포인트로, 2·5 이렇게")
- 반드시 **결론 줄에만**. 설정 줄에는 넣지 않는다.

## 4. 인셋(작은 사진) 배치 — 개츠비 게시물 승인값

```
인셋 위치  x = 48,  y = 760
인셋 크기  442 × 510      (하단 = 1270 → 바닥 여백 80px)
```

- **바닥 금지.** 인셋이 캔버스 하단 모서리에 닿으면 "잘린 것"으로 읽혀 가시성이 죽는다. 최소 여백 **80px**.
- **무게중심은 중상단.** 주요 요소는 캔버스 세로 **45~85%** 구간.
- 자막①(설정)은 **인셋 바로 위, 좌측 x=48**.
- 자막②(결론)은 **우측 하단, 우측정렬**.
- 인셋 사진은 **원본 비율 유지 + 중앙 크랍 최소**. 피사체(머리)가 프레임 안에 다 들어와야 한다.

## 5. 영상 렌더 (쇼츠/릴스)

| 항목 | 값 |
|---|---|
| 캔버스 | **1080 × 1920** |
| 길이 | **33 ~ 50초** (`dur_ok`) |
| 자막 폰트 | **교보손글씨2019** (`Kyobo.otf`) — 흘러가는 말 |
| 제목·카드 폰트 | **나눔스퀘어 EB** (`NanumSquareEB.ttf`) — 못 박는 정보 |
| 제목 크기 | 92 |
| 카드 크기 | 64 · 화면 중앙 |
| 인트로 / 아웃트로 | 2.2초 / 3.4초 |
| 구도 | 얼굴 클로즈업 금지. 랜드스케이프 소스는 **블러배경 + 풀샷 얹기** |
| 클립 | **한 영상 안에서 재사용 금지.** 모자라면 긴 클립을 구간별로 잘라 다른 파일로 |

# 2026-07-20 이찬호 지시·수정 모음 (코드방 B방 → 볼트 연동)

> 이찬호: "내가 준 모든 문구·수정을 옵시디언에 저장해 연동하라. 볼트가 방향성을 만든다."
> 이후 모든 지시·수정은 이 형식으로 볼트에 누적 → 차노_방향성_지도의 입력.

## 글쓰기 방향 (핵심)
- **블로그 = 원자 쇼츠(내 대본)의 문구·재정의만 확장.** 내가 없는 비유·개념 창작 금지(자동차·정장/니트·아메리카노 등 삭제). 깊이는 같은 주제 다른 쇼츠/구술/사실 실행팁으로.
- **막 쓰기 금지** — 볼트 먼저 검색해 내 단어로 쓴다. 내 문장 창작(흉내) 금지, 실제 쓴 문장만 인용.

## 카드뉴스 정본 형식 = 「Chano's Formula」
- 진짜 헤어 사진 풀블리드 + 다크 그라데이션 오버레이 / 굵은 흰 제목(이모지 선두) / 항목 👉 값 리스트(노랑) / ✓ 쉬운정보 팁 / @ATNOWN_Chano·N페이지·⟫ / 마지막 장 "내생각(차노 한마디)".
- **금지**: 빈 사진 박스, 낙서형 점선 도식(8페이지 실패 사례). 주석은 1~2개 의도 있는 선만.
- 배경 사진 = 드라이브 문방구 헤어 클립 프레임 추출.
- 폰트: NanumSquareRound(이모지 폰트는 스택 맨 뒤 — 공백 벌어짐 방지).

## 미용 재정의 (오늘 구술 반영)
- 집머리 안 나옴 = 드라이어 탓 X → 모근 세우기 + 공간 살린 커트.
- 가르마 = 인상은 이목구비 아닌 가르마 방향(중앙=가로선, 육대사=세로선·입체).
- 작심삼일 = 의지 X → 환경(마찰) 바꾸기.
- 회복(일기) = 쉼은 멈춤 아닌 순환, 찬물이 최고.

## 시스템·운영
- 상황판 = 노션 「코드방 상태판」 상단 고정, 인플레이스 갱신. 리더 할 일(리더_차노) 상설 표시.
- 음성/TTS = 보이스B·시작 강제쉼 제거·문맥 스티칭(로봇틱 제거)·라임 부호.
- 두 방: A방=렌더·유튜브·B롤스캔 / B방=상황판·대본·문서. main 트렁크 커밋 항상 일치.
- 레이밴 메타2 구매 = 이익 판정(B롤 병목 해소·마찰 0). 실사용 조건.
- 옵시디언 양방향 연동: 코드방 산출·수정 ↔ 볼트. 볼트가 방향성 정본.

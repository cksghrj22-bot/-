# 앳나운 볼트 (Obsidian)

두 기기(맥 스튜디오 · 맥북) 공용 글쓰기 볼트. 구글드라이브 안에 있어 자동 동기화되고, 본진 Claude도 이 파일들을 직접 읽고 씁니다.

## 폴더
- `하루한마디/` — 하루 한 줄. 쌓이면 책의 씨앗. (미션: 하루 한마디가 한 권의 책)
- `스레드_초고/` — 스레드/글 초안
- `책_초고/` — 챕터 단위 정리
- `영상일기_글/` — 1분 SNS 영상일기용 오늘의 글

## 규칙
- **동시에 두 기기에서 같은 노트를 편집하지 말 것** (드라이브 동기화 충돌 방지). 한 번에 한 기기.
- 읽기/발행·판매 지식 = Notion, 날것 글쓰기·초고 축적 = 이 볼트. (역할 분리)

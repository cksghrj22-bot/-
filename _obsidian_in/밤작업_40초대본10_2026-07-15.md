## 1.(#26) 왜 미용실 간 날만 예쁠까 — 질문형·바이럴
왜 미용실 간 날만 예쁠까요? / 집에 오면 그 머리가, 안 나오죠. / 비밀은 실력이 아니라, 각도예요. / 디자이너는 뿌리를 세워 말립니다. / 집에선 중력 방향 그대로 누르고요. / 머리는 자른 게 아니라, 세워진 겁니다. / 그날의 볼륨은, 손이 아니라 방향이 만든 거예요. / 그래서 배워야 할 건 제품이 아니라 / 말리는 방향, 딱 하나입니다. / 다음 컷 때, 이것만 물어보세요. / "이 머리, 어느 방향으로 말려요?" / 그 한마디가, 매일을 미용실 간 날로 만듭니다.
→ 배경: 드라이 각도로 뿌리 세우는 손 클로즈업. 훅=완성머리↔눌린머리 대비.

## 2.(#40) 왜 단골이 되면 머리가 점점 잘 나올까
왜 단골이 되면, 머리가 점점 잘 나올까요? / 정 때문이 아닙니다. / 데이터가 쌓여서예요. / 모질, 가마, 지난 펌의 회복 속도까지. / 말 안 해도, 차트처럼 남거든요. / 세 번째 방문부터 상담이 짧아지죠. / 실패 확률이 줄어드는 겁니다. / 내비게이션도 다닐수록, 내 길을 배우잖아요. / 단골은 정으로 다니는 게 아니라 / 서로의 데이터가 쌓이는 일입니다.
→ 배경: 상담·필기 장면. ②단골과 짝발행.

## 3.(#30) 왜 숱을 쳤는데 더 무거워 보일까
숱을 쳤는데, 왜 더 무거워 보일까요? / 숱치기를 빼기로만 생각해서예요. / 가위를 아무 데나 넣으면 / 겉은 그대로, 속만 비어요. / 그럼 머리가, 안에서 주저앉습니다. / 숱치기는 빼기가 아니라, 설계예요. / 어디를 남기고 어디를 비울지. / 그 각도가, 공간을 만듭니다. / 공간이 생겨야, 머리가 가벼워 보이고요. / 숱은 양이 아니라, 배치의 문제입니다.
→ 배경: 커트/숱치기 가위질 클로즈업.

## 4.(#51) 기록이란 — 방황을 멈추는 수단
서른일곱에, 매일 일기를 씁니다. / 멋있어 보이려는 게 아니에요. / 방황을 멈추려는 거죠. / 생각은 적지 않으면, 계속 맴돌거든요. / 같은 고민을 어제도, 오늘도 합니다. / 근데 한 줄 적는 순간 / 그 고민은, 밖으로 나와요. / 밖에 나온 생각은, 정리가 됩니다. / 기록은 나를 자랑하는 게 아니라 / 어제의 나와, 겹치지 않는 방법입니다.
→ 배경: 수첩 쓰는 손(신규 촬영). 흑백. 차노의 책장/기록 라인.

## 5.(#58) 어른들 말은 그 나이가 되어야 들린다
어른들 말은, 그때는 안 들렸어요. / 잔소리로만 들렸죠. / 근데 그 나이가 되니, 들립니다. / 말이 바뀐 게 아니라 / 내 귀가, 그제야 열린 거예요. / 경험이 자막을 달아준 거죠. / 그래서 지금 안 들리는 말도 / 버리면 안 됩니다. / 언젠가 내가, 그 나이가 되니까요. / 듣는 건 나이가 하고, 새기는 건 내가 합니다.
→ 배경: 사색하는 뒷모습/옛 사진 아카이브. 흑백.

## 6.(#60) 미용인 차노에서, 사람 차노로 — 브랜딩 핵심
저는 머리를 자르는 사람입니다. / 근데 요즘, 생각을 더 많이 해요. / 책을 읽고, 일기를 쓰고, 달립니다. / 머리 얘기만 하던 채널에 / 왜 이런 걸 올리냐고요? / 미용은 제 일이지, 저의 전부가 아니거든요. / 좋은 디자이너이기 전에 / 저는, 생각하는 사람이고 싶어요. / 그래서 여기엔, 머리도 있고 삶도 있습니다. / 미용인 차노에서, 사람 차노로.
→ 배경: 커트하는 손→책 읽는 손→달리는 발 몽타주. 채널 확장 선언문·소개영상.

## 7.(#71) 실력은 손이 아니라 질문에서 자란다
실력이 손에서 자란다고, 다들 생각하죠. / 아니에요. / 질문에서 자랍니다. / 같은 시술을 십 년 해도 / "왜?"를 안 물으면, 십 년째 초보예요. / 손은 물어본 만큼만, 정교해집니다. / 좋은 디자이너는 손이 빠른 게 아니라 / 질문이, 깊은 사람이에요. / 그래서 저는 후배에게, 기술보다 먼저 / 질문하는 법을 가르칩니다.
→ 배경: 교육·시연/후배 대화. 챈카데미·유리 시험 연결.

## 8.(#76) 사전: 공간
오늘의 단어는, 공간입니다. / 머리에 웬 공간이냐고요? / 숱치기는 머리를 없애는 게 아니에요. / 사이에, 공간을 만드는 거죠. / 공간이 생기면, 공기가 들어가고 / 공기가 들어가면, 머리가 움직입니다. / 움직이는 머리가, 살아 보이는 거고요. / 그러니 볼륨은 숱이 아니라 / 비운 공간에서, 나옵니다. / 앳나운은, 단어로 머리를 설계합니다.
→ 배경: 숱치기→머리 사이 틈으로 빛/바람. 사전 시리즈 포맷.

## 9.(#92) 상담 때 이 한마디 — "제 머리에서 뭘 보셨어요?"
미용실 상담에서, 딱 한마디만 던지세요. / "제 머리에서, 뭘 보셨어요?" / 이 질문 하나로, 디자이너가 갈립니다. / 좋은 디자이너는 여기서 / 모질, 가마, 얼굴형을 읽어내요. / 아무 말 못 하면, 아직 안 본 겁니다. / 손님이 원하는 걸 묻기 전에 / 머리가 말하는 걸, 먼저 듣는 사람. / 그게 진단이 되는 디자이너예요. / 가격표 말고, 이 대답을 보세요.
→ 배경: 상담·머리 살펴보는 손. 노란박스 신뢰 시리즈.

## 10.(#63) 잘하는 것과 오래 하는 것은 다르다
잘하는 사람과, 오래 하는 사람은 다릅니다. / 잘하는 건, 한 번의 결과예요. / 오래 하는 건, 매일의 태도고요. / 반짝 잘하는 사람은 많아요. / 근데 십 년, 이십 년 같은 자리에서 / 지치지 않는 사람은, 드뭅니다. / 그건 재능이 아니라, 관리예요. / 좋아하는 일에도, 총량이 있거든요. / 그래서 저는 실력보다 먼저 / 오래 갈 수 있는지를, 봅니다.
→ 배경: 운동/루틴(하이록스)/20년 아카이브. 흑백.

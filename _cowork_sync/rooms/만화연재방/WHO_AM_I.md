# 이 방은 「만화연재방」이다

> 형이 열어준 제목이 정본이다.

## 역할: 업무실 — 결이 이야기 만화 연재

| 하는 일 | 안 하는 일 |
|---|---|
| 미용만화 「결이 이야기」 제작 | 영상 |
| 나노바나나 화풍 컷/카드 | 인스타 낙타카드 |
| 만화 구조·문구·검수 | 쇼츠 |
| **자기 분야 내 전략/회의** | — |

## 방코드

`M` — 만화카드/manhwa 전용

## 상위 지휘

전략기획및개인업무 → 명령·판정
이 방 → 실행

## 발행 경로

- 인스타 캐러셀 → 낙타자막인스타 경유
- `_publish_jobs/결이이야기_*`

---

## 수정 가능 파일 (이것만 건드린다)

| 파일 | 용도 |
|---|---|
| `_state/rooms/이_방_이름.json` | 내 상태 |
| `_cowork_sync/rooms/이_방/` | 내 방 폴더 |

## 금지 (충돌 원인)

- `_STATE_NOW.md` 직접 수정 (자동 생성됨)
- `_ROOMS.md` 방 현황 테이블 직접 수정
- 다른 방의 `_state/rooms/*.json` 수정
- `git reset --hard` 사용

# 이 방은 「만화연재방」이다

> 형이 열어준 제목이 정본이다.

## 역할: 업무실 — 결이 이야기 만화 연재

| 하는 일 | 안 하는 일 |
|---|---|
| 미용만화 「결이 이야기」 제작 | 영상 |
| 나노바나나 화풍 컷/카드 | 인스타 낙타카드 |
| 만화 구조·문구·검수 | 쇼츠 |

## 방코드: `M`

## 자주 쓰는 명령어

```bash
# 만화 커버 게이트
python3 scripts/cards/comic_gate.py <폴더>

# Gemini 이미지 생성
python3 scripts/gemini_image.py <프롬프트>
```

## 규격 정본

|---|---|

## 발행 경로

인스타 캐러셀 → **낙타자막인스타 경유**

## 수정 가능 파일

| 파일 | 용도 |
|---|---|
| `_state/rooms/만화연재방.json` | 내 상태 |

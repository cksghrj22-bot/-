# 이 방은 「교육디렉터방」이다

> 형이 열어준 제목이 정본이다.

## 역할: 업무실 — 샵 교육 디렉팅 + 관계도방 겸임

| 하는 일 | 안 하는 일 |
|---|---|
| 교육 커리큘럼 디렉팅 | 영상 |
| 디자이너 승급 심사 | 인스타 |
| 성장타워·관계도 관리 | 만화 |
| 발표덱·심사표 | 블로그 |

## 자주 쓰는 명령어

```bash
# 성장타워 열기
open content/교육/앳나운_성장타워.html

# 관계도 열기
open content/교육/앳나운_관계도.html

# 발표덱 빌드
python3 scripts/build_slides.py <주제>
```

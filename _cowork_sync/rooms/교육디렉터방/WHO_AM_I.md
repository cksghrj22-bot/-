# 이 방은 「교육디렉터방」이다

> 형이 열어준 제목이 정본이다.

## 역할: 업무실 — 샵 교육 디렉팅 + 관계도방 겸임

| 하는 일 | 안 하는 일 |
|---|---|
| 교육 커리큘럼 디렉팅 | 영상 |
| 디자이너 승급 심사 | 인스타 |
| 성장타워·관계도 관리 | 만화 |
| 발표덱·심사표 | 블로그 |
| **자기 분야 내 전략/회의** | — |

## 상위 지휘

전략기획및개인업무 → 명령·판정
이 방 → 실행

## 관련 경로

- `content/교육/`
- `knowledge/앳나운_브랜드_전략서*.md`
- 성장타워: `content/교육/앳나운_성장타워.html`
- 관계도: `content/교육/앳나운_관계도.html`

---

## 수정 가능 파일 (이것만 건드린다)

| 파일 | 용도 |
|---|---|
| `_state/rooms/이_방_이름.json` | 내 상태 |
| `_cowork_sync/rooms/이_방/` | 내 방 폴더 |

## 금지 (충돌 원인)

- `_STATE_NOW.md` 직접 수정 (자동 생성됨)
- `_ROOMS.md` 방 현황 테이블 직접 수정
- 다른 방의 `_state/rooms/*.json` 수정
- `git reset --hard` 사용

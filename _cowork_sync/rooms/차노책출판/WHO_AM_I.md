# 이 방은 「차노책출판」이다

> 형이 열어준 제목이 정본이다.

## 역할: 업무실 — 차노 책 출판

| 하는 일 | 안 하는 일 |
|---|---|
| 에세이 | 영상 |
| 기술서 | 인스타 |
| 어록집 | 쇼츠 |
| 사물관찰일기 | 만화 |
| **자기 분야 내 전략/회의** | — |

## 상위 지휘

전략기획및개인업무 → 명령·판정
이 방 → 실행

---

## 수정 가능 파일 (이것만 건드린다)

| 파일 | 용도 |
|---|---|
| `_state/rooms/이_방_이름.json` | 내 상태 |
| `_cowork_sync/rooms/이_방/` | 내 방 폴더 |

## 금지 (충돌 원인)

- `_STATE_NOW.md` 직접 수정 (자동 생성됨)
- `_ROOMS.md` 방 현황 테이블 직접 수정
- 다른 방의 `_state/rooms/*.json` 수정
- `git reset --hard` 사용

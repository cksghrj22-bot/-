# 이 방은 「전략기획및개인업무」다

> 형이 열어준 제목이 정본이다. 다른 이름으로 부르지 않는다.

## 역할: 전략실 (지휘만, 실행 안 함)

| 하는 일 | 안 하는 일 |
|---|---|
| 전사 상황판 (09:00/22:00) | 렌더링 |
| 명령 발주 | 실무 코딩 |
| 규격·정본 확정 | 영상/카드 제작 |
| 판정 (OK/재작업) | 발행 실행 |
| 개인업무·일정 | — |

## 업무실 발주처

| 방 | 담당 | 발주 |
|---|---|---|
| 낙타자막인스타 | 인스타·스레드 | 코워크 메시지 |
| 유튜브쇼츠방 | 쇼츠·AI일기 | 코워크 메시지 |
| 블로그자동화방 | 네이버 블로그 | 코워크 메시지 |
| 만화연재방 | 결이 이야기 | 코워크 메시지 |
| 교육디렉터방 | 샵 교육 + 관계도 | 코워크 메시지 |
| 차노책출판 | 에세이·기술서 | 코워크 메시지 |

## 자주 쓰는 명령어

```bash
# 전체 연결 상태
python3 -m pipeline check

# 방별 상태 한눈에
cat _state/rooms/*.json | jq -s '.'

# 오늘 상태
cat _STATE_NOW.md

# 방 체계
cat _ROOMS.md
```

## 정본 파일

| 용도 | 경로 |
|---|---|
| 방 체계 | `_ROOMS.md` |
| 현재 상태 | `_STATE_NOW.md` |
| 보완게이트 | `pipeline/보완_정본.md` |
| 판단 기준 | `knowledge/차노_판단기준_정본.md` |
| 제작 규격 | `knowledge/제작규격_정본.md` |

## 수정 가능 파일

| 파일 | 용도 |
|---|---|
| `_state/rooms/전략기획및개인업무.json` | 내 상태 |
| `_ROOMS.md` | 방 현황 (전략실만) |
| `_STATE_NOW.md` | 전체 상태 (전략실만) |

## 금지

- 렌더링/발행 직접 하기 → 업무실로 발주
- 다른 방 상태 파일 수정
- `git reset --hard` 사용

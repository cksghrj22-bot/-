# 이 방은 「낙타자막인스타」다

> 형이 열어준 제목이 정본이다. "기획실" "전략기획 및 낙타방" 등으로 부르지 않는다.

## 역할: 업무실 — 인스타·스레드 실행

| 하는 일 | 안 하는 일 |
|---|---|
| ①낙타 자막바 카드 제작 | 유튜브 쇼츠 |
| ③에이엠톤 사진카드 | 만화 카드 |
| ④스레드 게시 | 블로그 |
| 인스타 발행 | 전사 상황판 |
| **자기 분야 내 전략/회의** | — |

## 방코드

`N` — 낙타/nakta 이미지 트랙

## 상위 지휘

전략기획및개인업무 → 명령·판정
이 방 → 실행·발행

## 금지

- 방 이름에 "전략기획" 넣기
- 다른 방 일 대신 하기 (쇼츠는 유튜브쇼츠방, 만화는 만화연재방)

## 수정 가능 파일 (이것만 건드린다)

| 파일 | 용도 |
|---|---|
| `_state/rooms/이_방_이름.json` | 내 상태 |
| `_cowork_sync/rooms/이_방/` | 내 방 폴더 |

## 금지 (충돌 원인)

- `_STATE_NOW.md` 직접 수정 (자동 생성됨)
- `_ROOMS.md` 방 현황 테이블 직접 수정
- 다른 방의 `_state/rooms/*.json` 수정
- `git reset --hard` 사용

# 만화연재 파이프라인 — 결이 이야기 (2026-08-14)

> Gemini 나노바나나 + Codex 연동

## 텍스트 먼저 규칙

**대본/메시지 확정 전 이미지 생성 금지.**

1. 텍스트 받기 → 키워드/의도 정리
2. 6장 구성 확정 (형 승인)
3. 이미지 생성

## 실행 명령

```bash
# 대본으로 6장 생성
python3 scripts/manga_pipeline.py "대본 텍스트" --title "착한곱슬편"

# 파일에서 읽기
python3 scripts/manga_pipeline.py --from-file content/manga/대본.txt --title "매직편"

# 생성 후 코워크 업로드
python3 scripts/manga_pipeline.py "대본" --title "제목" --upload
```

## 결이 캐릭터 규칙 (필수)

| 규칙 | 내용 |
|---|---|
| 얼굴 있는 캐릭터 | **결이·보리 둘뿐** |
| 문제(매듭/기계) | 얼굴 없는 사물로 그림 |
| 결이 형태 | 크림색 둥근 얼굴 + 오렌지 머리 뭉치 |
| 보리 | 매 편 최소 4컷 등장 |
| 팔레트 | 크림 배경 · 브라운 · 오렌지 포인트 |

## 6장 구조

1. **표지** — 훅 질문 + 결이 배지
2. **문제** — 보리 등장, 고민
3. **오해** — 통념 제시
4. **진실** — 재정의/아하 모먼트
5. **해결** — 변화 보여주기
6. **결론** — 재정의 한 줄

## 출력 위치

_tmp/manga/{제목}/
├── 01_cover.png
├── 02_problem.png

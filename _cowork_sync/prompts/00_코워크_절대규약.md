## 0. 코드방처럼 일하기 (최우선)

코드방(Claude Code)이 할 수 있는 건 코워크도 할 수 있다. **차이 없이 동일하게 일한다.**

### 할 수 있는 것들

| 작업 | 방법 |
|---|---|
| 드라이브 파일 검색 | MCP `mcp__claude_ai_Google_Drive__search_files` |
| 드라이브 다운로드 | `python3 shorts/gdrive.py download <id> <dest>` |
| 드라이브 업로드 | `python3 shorts/gdrive.py upload <file> --folder-id <id>` |
| 노션 검색 | MCP `mcp__claude_ai_Notion__notion-search` |
| 브라우저 자동화 | MCP `mcp__claude-in-chrome__*` 도구들 |
| 터미널 명령 | Bash 도구로 직접 실행 |
| 이미지 생성 | `python3 scripts/gemini_image.py "프롬프트" output.png` |
| 만화 생성 | `python3 scripts/manga_pipeline.py "대본" --title "제목"` |

### "못한다" 금지

1. **"못한다" 말하기 전에:**
   - MCP 도구 있는지 확인
   - 스크립트로 가능한지 확인
   - 브라우저로 가능한지 확인
2. **진짜 불가능할 때만** "불가능" 보고 + 구체적 이유

## 1. 드라이브 파일 작업

**Claude가 직접 한다. 사용자에게 시키지 않는다.**

| 작업 | 코드 |
|---|---|
| 파일 검색 | `mcp__claude_ai_Google_Drive__search_files` |
| 파일 다운로드 | `python3 shorts/gdrive.py download <file_id> <dest>` |
| 파일 업로드 | `python3 shorts/gdrive.py upload <file> --folder-id <id>` |
| 폴더 목록 | `python3 shorts/gdrive.py list <folder_id>` |

드라이브 연동 안 되면? → `secrets/gdrive.json` 확인 → 없으면 코드방 상태판에서 가져옴.

## 2. 렌더 전 체크리스트

**수치_체크리스트_정본.md 안 돌리면 렌더 금지.**

핵심 수치:
- 컷 최소 **2.2초**
- 아웃트로 **2.2초 이상**
- 싱크 평균 **≤0.15초**

## 3. 승인 없이 반복 금지

- 형이 말하면 그것만 작업
- 끝나면 보고하고 대기
- "yes" 명시 전까지 다음 작업 안 함

## 4. 못한다고 하기 전에

1. 코드로 할 수 있는지 먼저 확인
2. MCP 도구 있는지 확인
3. 스크립트 만들면 되는지 확인
4. 진짜 불가능할 때만 "불가능" 보고 + 이유

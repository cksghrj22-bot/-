**[디코] [Assistant] (2026-08-13 00:14)**
사용자님 Mac 의 **Mail 앱** 과 연동해서 최근 메일을 한 번에 확인하거나, 필요할 때 자동으로 분류·요약해드릴 수 있어요.

**진행 방식**
• [네, 지금 확인해 볼게요] 클릭 시 최근 메일을 바로 가져와 보여드려요.
• 처음 사용 시 macOS 가 권한 다이얼로그를 띄울 수 있어요. [허용] 누르면 끝.
• Mail 앱에 계정이 없으면 등록 안내도 같이 띄워드려요.

나중에 채널에서 **'메일 확인해줘'** 라고 말씀해도 같은 흐름으로 동작해요.

**[디코] [Assistant] (2026-08-13 00:14)**
채널·구독자·주제만 한 번 알려주시면, 앞으로 협업 메일이 올 때마다 **내 규모랑 잘 맞는 제안인지** 자동으로 짚어드려요.

**진행 방식**
• 아래 [🎯 프로필 설정] 버튼 → 3가지만 (플랫폼 · 구독자 수 · 주제)
• 30초면 끝나고, 언제든 다시 눌러 바꿀 수 있어요.

설정 전에도 메일 분석은 되지만, 프로필이 있으면 훨씬 더 정확해져요.

**[디코] [Assistant] (2026-08-13 00:14)**

**보내는 것** — 에러 메시지, 기기 정보(앱 버전·macOS 종류), 하루 1번 익명 사용 통계(대화 세션 개수·응답 속도 지표 같은 숫자)
**절대 안 보내는 것** — 대화 내용·파일·메시지·개인정보

**완전히 선택이에요.** 동의 안 하셔도 봇은 똑같이 동작하고, 동의하셔도 언제든 **Hub → 에러 진단 전송** 에서 끌 수 있어요.

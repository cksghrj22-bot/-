# 규격 — 「에이엠톤식 좌하단 두 줄」 v1 (2026-08-14 테스트)

**낙타형 자막바와 별개 줄기다. 섞지 말 것.**

## 소속 방 — **여기(낙타자막컨텐츠방 · 방3 `N`)** (2026-08-14 차노 확정)
> "에이엠톤 같은경우는 낙타자막 방에서 하고" / "에이엠톤도 여기서 하는거 맞아 여기 낙타방인데?"

**이관 대상이 아니다. 이 방이 끝까지 만들고 발행한다.**
낙타(①)와 **같은 방, 다른 줄기** — 방이 같다고 규격을 섞지 않는다.
파일명·락에 방코드 `N` 을 붙인다.

| | 낙타형 자막바 | 에이엠톤식 좌하단 두 줄 |
|---|---|---|
| 글자 담는 법 | 글자폭 직각 박스 (흰/검정/시안) | 박스 없음 · 하단 스크림 위 생글자 |
| 배치 | 계단 · 슬라이드마다 위치 변주 | **좌하단 고정** (변주 안 함) |
| 강조 | 시안 박스 | **노란 포인트 단어** (#F2C230) |
| 줄 수 | 2~3줄 | 2줄 고정 |
| 렌더러 | `scripts/cards/nakta_post.py` | `scripts/cards/amton_post.py` |
| 입력 | 파이썬 SLIDES 상수 | **매니페스트 JSON** (`content/amton/*.json`) |

## 캔버스
1080 × 1350. 사진은 cover 크롭, `anchor` 로 세로 위치 조절(0=위, 1=아래, 기본 0.42).

## 기본값 (매니페스트 `defaults`)
- 폰트 `NanumSquareRoundEB.ttf` · 1줄 62 / 2줄 46
- 글자 흰 `#FFFFFF` · 포인트 `#F2C230`
- 좌측 x = 7.2% · 바닥 여백 7.5% · 줄간격 20
- 스크림: 하단 46% 높이, 알파 165, 감마 1.6 (아래로 갈수록 진해짐)

## 문안 규칙
- 낙타형과 동일: **형 원본 텍스트 그대로. 창작·윤문 금지.**
- 1줄 = 전제/설정(짧게), 2줄 = 단정. 2줄에서 **한 단어만** 노랑.
- 노랑은 문장당 1개. 두 줄 다 노랑 = 금지(강조가 죽는다).
- 2줄이 길면 `size_2` 를 카드별로 낮춘다(38까지). 그 이상 길면 문장을 자른다.

## 사용
```
python3 scripts/film_grade.py <원본> <그레이딩본> --grade warm_film   # 사진은 항상 E 먼저
python3 scripts/cards/amton_post.py content/amton/<매니페스트>.json
```
매니페스트에 `"grade": "warm_film"` 을 적어두되, 그레이딩은 film_grade.py 가 별도로 건다.
(렌더러가 색까지 건드리면 값이 두 군데로 갈라진다 — 금지.)

## 게이트 (2026-08-15 신설 · 자동)
`scripts/cards/amton_gate.py` — 렌더러가 끝에서 **자동 호출**. FAIL 하나라도 있으면 산출물 아님.

| | 항목 | 기준 |
|---|---|---|
| A1 | 해상도 | 1080 × 1350 |
| A2 | 좌하단 | 글자 중심 y ≥ 0.65 · x ≤ 0.55 |
| A3 | 두 줄 | 하단 잉크 덩어리 2개 |
| A4 | 노랑 포인트 | **글자 픽셀 대비 3~25%** (0=포인트 없음 / 25%↑=한 줄 통째) |
| A5 | 글자 대비 | 자막영역 글자−배경 밝기차 ≥ 60 |
| A6 | 그레이딩 | 블랙포인트 ≥ 15 (E=23, 원본=4) |
| A7 | 검수 시트 | `_검수시트_에이엠톤.jpg` — 장별 PASS/FAIL 테두리 |

매니페스트 단계 린트도 별도로 돈다(`amton_post.lint_card`): 한 줄의 60% 이상 노랑 / 두 줄 다 노랑 → 렌더 자체를 막는다.

### 게이트 만들면서 자체검수로 잡은 버그 2건 (박제)
1. **잉크 임계가 낮아 피부를 글자로 셌다.** min(RGB)>140 이면 피부(196,168,150)가 걸린다 → **≥215(거의 순백)** 로 조임.
   낮은 임계로 뒀으면 얼굴 밝은 사진마다 A2/A3 오탐이 났을 것.
2. **노랑을 화면 전체 대비로 재서 한 줄 통째 노랑을 못 잡았다**(0.32%) → **글자 픽셀 대비**로 변경(31.7% → 검출).
→ 게이트는 **일부러 위반 케이스를 만들어 잡히는지 확인**한 뒤에 쓴다. 통과만 확인하면 안 잡는 게이트가 남는다.

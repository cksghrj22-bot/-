# outbox — 코워크(클라우드) → 디스코드 #assistant 되돌림 통로

클라우드 코워크 방이 차노쌤 디스코드 #assistant 채널로 **답을 보내고 싶을 때** 여기에 파일을 떨군다.

## 계약 (지키면 자동 발송됨)

- **파일 1개 = 디스코드 메시지 1개.** `.md` 확장자로 이 폴더(`_cowork_sync/outbox/`)에 바로 저장.
- 파일명은 시간순 정렬되게: 예 `2026-08-11T1630_답변.md` (앞이 빠를수록 먼저 발송).
- 본문이 2000자를 넘으면 본진 워처가 문단 단위로 자동 분할해 여러 메시지로 보낸다.
- 저장 후 `git add` → `commit` → `push` 하면 끝. (본진이 5분마다 `git pull` 로 집어감)

## 처리 규칙

- 본진 워처(`cowork_to_discord.py`)가 발송에 성공하면 그 파일을 `_sent/` 로 옮기고 다시 push 한다.
- 즉 **`_sent/` 에 있으면 이미 디스코드로 나간 것**, `outbox/` 직하에 남아 있으면 아직 대기.
- 같은 파일을 두 번 보내지 않는다(이동으로 멱등 보장). 재발송이 필요하면 `_sent/` 에서 꺼내 이름을 바꿔 다시 넣는다.

## 발신자 표기

디스코드에는 `코워크(클라우드)` 이름으로 표시된다(웹훅 username).

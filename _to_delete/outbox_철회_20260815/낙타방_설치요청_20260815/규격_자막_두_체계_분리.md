# 정본 — 자막은 두 체계다. 절대 합치지 않는다 (2026-08-14 차노 지시)

> 차노: **"낙타 자막 인스타 컨텐츠랑 유튜브쇼츠의 자막은 방법이 달라서 합치면 헷갈려."**

같은 "자막"이라는 말을 쓰지만 **다른 물건**이다. 규격·폰트·렌더러·방이 전부 다르다.
한 문서·한 스크립트·한 방에서 둘을 같이 다루지 않는다.

| | ① 낙타형 자막바 | ② 쇼츠 하단자막 |
|---|---|---|
| **어디** | 인스타 캐러셀 | 유튜브 쇼츠 |
| **방** | 방3 `N` — **기획실** (08-14 확정) | 방2 `A` — **쇼츠영상방 계속** (08-14 확정) |
| **캔버스** | 1080 × **1350** (4:5) | 1080 × **1920** (9:16) |
| **폰트** | `NanumSquareRoundEB.ttf` | `KyoboHandwriting2019.ttf` |
| **담는 법** | 글자폭 직각 박스 (흰/검정/시안) | 박스 없음 · ASS 아웃라인 |
| **위치** | **변주** — 슬라이드마다 다르게, 피사체 회피 | **하단 고정** y=1436(한글)/1500(영어) |
| **정렬** | 좌측정렬 · 계단식 | 가운데 |
| **렌더** | PIL — `scripts/cards/nakta_post.py` | ASS/libass — ffmpeg (⛔drawtext 금지, 공백 글리프 없음) |
| **길이** | 슬라이드당 3~5초 | 40~50초 (50 초과 탈락) |
| **소리** | **없음** (TTS 없음) | 형 원본 음성 + BGM 0.18 |
| **게이트** | `scripts/cards/nakta_gate.py` | `scripts/shorts_gate.py` (UI존 침범 자동검출) |
| **정본** | `knowledge/규격_낙타형자막바_컨텐츠_정본.md` | `knowledge/규격_AI일기_시리즈_렌더레시피.md` |

## 세 번째 줄기 (혼동 주의)
③ **에이엠톤식 좌하단 두 줄** — 인스타 사진카드. ①과 같은 1080×1350이지만 **박스 없음·좌하단 고정·노란 포인트**.
정본 `knowledge/규격_에이엠톤식_좌하단두줄_v1.md` · 렌더러 `scripts/cards/amton_post.py`.
**방3 `N` · 기획실** (08-14 확정) — ①과 같은 방, 다른 줄기.
①과 ③도 섞지 않는다. 매니페스트 줄기가 다르다.

## 금지
- 한 스크립트가 ①②를 둘 다 렌더하는 것
- "자막 규격"이라는 이름의 통합 문서를 새로 만드는 것 — 이름이 갈리면 일이 갈린다(_ROOMS.md §1)
- 쇼츠 자막 수치를 낙타에 가져오거나 그 반대

## 말할 때
"자막"만 쓰지 말고 **①낙타 자막바 / ②쇼츠 하단자막 / ③에이엠톤 두 줄** 로 부른다.

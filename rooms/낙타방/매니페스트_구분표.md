## 강제 방법 — `manifest_kinds.py`
렌더러는 **`json.load` 를 직접 하지 않는다.** 반드시 `manifest_kinds.load(path, expect=...)` 를 통과한다.

막는 것 4가지:
1. **`kind` 없음** → 어떤 스탬을 적어야 하는지 알려주고 중단
2. **`kind` 다름** → "이건 ③이다, ③ 렌더러로 돌려라, 폴더는 여기다" 라고 안내하고 중단
3. **`kind` 는 맞는데 내용이 다른 스탬** (예: `kind`만 낙타로 바꾼 에이엠톤 파일) → 금지 키(`cards`/`slides`)로 적발
4. **남의 방 파일** (`segments`/`phrases` = 방2 쇼츠) → "유튜브쇼츠방 것이다" 라고 알려주고 중단

항목 단위로도 본다: `slides[]` 에 `line1` 이 있거나 `cards[]` 에 `lines`/`start` 가 있으면 거부.

## 역검증 (2026-08-15 실측 — 5종 전부 차단 확인)
| 넣은 것 | 결과 |
|---|---|
| ① 렌더러에 ③ 파일 | ⛔ 차단 + ③ 렌더러 경로 안내 |
| ③ 렌더러에 ① 파일 | ⛔ 차단 + ① 렌더러 경로 안내 |
| `kind`만 낙타로 바꾼 ③ 파일 | ⛔ "`cards` 키가 있다 — 스탬이 섞였다" |
| `kind` 없음 | ⛔ 등록된 스탬 목록 안내 |
| 방2 쇼츠 매니페스트 | ⛔ "유튜브쇼츠방 것이다" |

## 스탬을 새로 만들 때
`manifest_kinds.KINDS` 에 한 줄 추가한다 — 이름·폴더·렌더러·규격·필수키·**금지키**·항목키.
**금지키를 반드시 채운다.** 그게 없으면 다른 스탬 파일이 그대로 통과한다.
새 스탬은 폴더도 새로 판다. 기존 폴더에 섞어 넣지 않는다.

## 진단
```
python3 rooms/낙타방/manifest_kinds.py                 # 등록된 스탬 목록
python3 rooms/낙타방/manifest_kinds.py <파일>.json      # 이 파일이 무슨 스탬인지
```

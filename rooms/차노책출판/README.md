## ⛔ 파일이 "안 보인다"고 말하기 전에 — 반드시 (2026-08-18 신설)

> **드라이브는 이미 연동돼 있다. 로컬에 없다고 없는 게 아니다.**
> 「앳나운영상」 같은 드라이브 폴더는 **맥 마운트로는 안 잡히고 API로만 보인다.**
> `find` 로 못 찾았다고 「없다」고 보고하면 그게 오보다.

```bash
# ① 드라이브 폴더 안 목록 (파일ID·용량·이름)
python3 rooms/유튜브쇼츠방/drive_ls.py --path 앳나운영상/<폴더명>

# ② 파일 받기 (ID 콤마로 여러 개 가능)
python3 scripts/drive_pull_ids.py <file_id[,id2,...]> <저장경로>
```

⚠️ **코워크 컨테이너는 네트워크가 없다.** 위 명령은 `_terminal_inbox/TASK_*.json` 으로 발주해
**본진(맥)에서 실행**시킨다. 인증은 `secrets/gdrive.json` 에 이미 있다.

### 금지어 — 이 말이 나오려 하면 위를 먼저 실행한다

「드라이브가 안 보입니다」 · 「연동이 안 돼 있습니다」 · 「폴더에 넣어주세요」 · 「복사해주세요」 · 「접근 권한을 주세요」

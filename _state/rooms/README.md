# 방별 상태 파일 (2026-08-14 신설)

> **규칙: 각 방은 자기 파일만 수정한다. 남의 파일 건드리면 충돌.**

## 파일 구조

```
_state/rooms/
├── 전략기획및개인업무.json
├── 낙타자막인스타.json
├── 유튜브쇼츠방.json
├── 블로그자동화방.json
├── 만화연재방.json
├── 교육디렉터방.json
└── 차노책출판.json
```

## JSON 형식

```json
{
  "room": "방이름",
  "updated": "2026-08-14T18:00:00",
  "status": "지금 하는 일 한 줄",
  "locks": ["잠근 주제 목록"],
  "last_output": "마지막 산출물 경로"
}
```

## 통합 뷰

`_STATE_NOW.md`는 이 파일들을 합쳐서 자동 생성된다.
수동으로 `_STATE_NOW.md`를 직접 수정하지 않는다.

## Git 안전 규칙

1. `reset --hard` 금지
2. 충돌 시 stash 대신 임시 커밋 후 해결
3. pull 전에 항상 커밋하거나 stash

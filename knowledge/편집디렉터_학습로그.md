# 🧠 편집 디렉터 ED — 학습로그 (자가성장·맨 위가 최신)

> 형 피드백을 그때그때 1줄로 새긴다(날짜·지적→규칙화). **같은 지적 2회 = `prompts/편집디렉터_ED.md` §3 규칙으로 격상.**
> ED는 매 작업 착수 전 이 로그를 읽는다. 삼자 회의(형·ED·실행자)의 기억 장부.

## 2026-07-28 (오후·재발방지 전략) — 대용량 footage는 통다운 금지, 스트리밍 부분추출 (형: "무마 말고 전략 짜서 행동")
- **문제 패턴**: 형이 인트레이에 올리는 원본은 4K·1.8GB+. 통다운 시도 → 디스크 풀 + moov-at-end(부분 head 다운 디코드 불가)로 매번 막힘.
- **전략(박제)**: `shorts/drive_stream.py` — gdrive.json refresh_token으로 access_token 즉석발급 → **ffmpeg가 인증 Drive media URL을 직접 읽어(HTTP Range) 필요 구간만 추출.** 통파일 디스크에 안 올림. `probe`/`sheet`(구간탐색)/`extract` 3커맨드.
- **작업 순서 고정**: 형 "영상 올렸어" → ①`probe` ②`sheet`로 개봉/리빌/착용 구간 눈으로 찾기 ③`extract`로 그 구간만 4:5 크롭+밴드(+반전이면 hflip). 디스크 걱정 0.
- **언박싱 필수 비트**: 봉인박스 → **개봉(트레이 슬라이드/뚜껑)** → 리빌(제품 손에) → 착용. 개봉 장면 없으면 언박싱 아님(형 지시).

## 2026-07-28 (오후·삼자회의 결정) — 픽 A: 상담 실사 = 「메타안경」편 인서트로 흡수
- 형이 A 선택. **별도 상담 영상 안 만든다.** 상담 실사(디자이너↔손님 대화)를 메타안경 편 **11번 "손끝의 시술도, 오늘의 대화도, 다 콘텐츠가 되니까요"** 구간 인서트로 씀.
- 효과: 중복 제거 + "오늘의 대화도 콘텐츠"를 **말이 아니라 실사로 증명**. 플래그십 강화.

## 2026-07-28 (오후) — 중복 창작 적발 (형: "주파수 저번꺼랑 너무 중복 아님?")
- **중복 금지 = 최우선 게이트.** 「상담 10분 주파수」는 이미 발행·예약된 **주파수 4부작**(상담은 주파수다 wPNqMJnG-zg 7/24, 상담케이스 gOSlsIoJfH0, 무드 F9MmeR0L-V4, 어울려요 k4pHfynGkAk, 반보 u0_MPX6t6wI)의 **재탕**이었다. 훅·핵심 메시지 거의 동일 → 폐기.
- **규칙 격상**: ED는 착수 전 반드시 `pipeline search`+`유튜브_예약현황.md`로 **같은 메시지가 이미 나갔는지** 확인한다. "표현만 다르고 결론이 같으면" 중복 = 안 만든다. → §3 소재·팩트에 반영.
- **재활용 원칙**: 좋은 소재(상담 실사)는 버리지 말고 **다른 서사**로 엮는다. 상담 footage → 「메타안경」편의 "오늘의 대화도 콘텐츠" 인서트로 전용(주파수 재탕 대신).

## 2026-07-28 (ED 고용일 · 이 세션 학습 시드)
- **오버레이 구조**: 영상 분할 금지(좁아서 가시성↓). 영상 계속 풀스크린 + **검은 반투명 스크림 위에 애니**. → 규칙 격상.
- **애니 구간 디렉팅**: 스크림을 **확실히 진하게(≈0.84)+페이드** 깔아 시선을 애니로 몬다("밑바탕/윗바탕 중 뭘 보라"가 명확해야). → 규칙.
- **팩트**: 메타안경 산 이유 = **"지금부터(현재) 찍으려고"**. "37년을 찍으려고"는 틀림(37년은 경력 배경일 뿐). → 규칙.
- **텍스트 먼저**: 렌더 전 나레이션=자막을 **길이 지정(40초 등)**으로 뽑아 승인받고 진행.
- **"컬러"의 의미**: 네이비 배경 애니만으론 컬러 아님. **실사(footage)가 컬러로 계속 깔려야** 컬러 영상. 애니만 두고 "컬러"라 보고하지 말 것.
- **언박싱은 실사 필수**: 박스 여는 장면이 있어야 언박싱. 애니로 대체 불가.
- **드라이브 체크 습관**: 형이 올렸다면 인트레이+소스폴더+전체 최근업로드까지 훑는다. IMG_2065 같은 신규 클립 놓치지 말 것.
- **제목 크기**: 작으면 즉시 키운다(大).
- **엔딩 질문 픽**: 「메타안경 산 후기」 엔딩 = **"당신의 백만원은 어디로 가고 있나요?"**
- **이번 화 제목 확정**: **"메타안경 산 후기"**.
- **삼자 회의로 창작**: 형·ED·실행자 세 명 회의에서 매번 새 콘텐츠. ED는 창의안 2~3개를 먼저 던진다.
- (기존 세션 자산) 교보손글씨·영어 바짝·타임스탬프 싱크·BGM 들리게·중앙 아웃트로·정사각 베이스·POP 볼드고딕 옵션·데이터 모션그래픽(AI티 금지)·footage↔메시지 일치 = 이미 §3 규칙 대장.

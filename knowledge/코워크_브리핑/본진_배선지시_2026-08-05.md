# 본진 Claude Code 배선 지시 — 코덱스 렌더 루프 켜기 (Cowork→본진, 2026-08-05)
> 코워크가 코드는 완성해 `scripts/`에 넣음(render_from_job.py·drive_pull.py·AGENTS_CODEX_역할계약.md).
> 본진 Claude Code가 아래를 실행해 코덱스 나이틀리 렌더 루프를 켠다. (인터넷 필요 → 본진이 함, 코워크는 못 함)

## 본진이 할 것 (자기 몫, 인터넷 O)
1. `pip3 install --break-system-packages google-api-python-client google-auth-oauthlib`
2. `scripts/render_from_job.py`·`scripts/drive_pull.py`를 **진짜 트렁크(atnown-repo)** scripts/로 이관 후 커밋.
3. 나이틀리/워치가 노션 작업큐(종류=렌더·상태=대기) 폴링 → 각 잡에 대해:
   `python3 scripts/drive_pull.py "앳나운_영상/[주제폴더]" _clips/ && python3 scripts/render_from_job.py job.json`
   → PASS면 Drive `_최신_바로보기/` 업로드 + 노션 링크·상태=완료 + 디스코드 1줄.
4. 큐 비면 **디스코드에 "큐 비었음·씨앗 대기" 보고**(조용한 0건 금지 — AGENTS_CODEX_역할계약 준수).

## 형이 딱 1번 (본진이 못 하는 것)
- 유튜브 로그인: `python3 publish/youtube_auth.py` (브라우저 1회) → Drive·발행 예약 토큰.

## 상태 회신
- 완료되면 이 파일 아래 "DONE + 켜진 항목"을 적고, 노션 상태판에 "코덱스 렌더루프 ON" 기록.

# 코덱스 3시 과제 — 포맷 C(줌+인셋) 렌더 구현 (Cowork→Codex, 2026-08-06)
> 형: "코덱스 토큰 걱정 노, 성능 좋으면 많이 써." → 코덱스에 실한 코드 과제 상시 배정.
> 코덱스 강점 = 복잡 코드/편집. 단순 렌더는 이미 render_from_job 스크립트가 자동으로 함. 코덱스는 그 스크립트로 "안 되는 것"을 코드로 만든다.

## 과제: render_from_job.py에 mode="inset_zoom"(포맷 C) 추가
목표 = "인셋 레이아웃 + 줌 설명형". 메인 실사 위에 작은 실사 인셋을 나레이션 따라 위치·개수 바꿔 띄우고, 메인은 줌인아웃으로 강조. (단순 컷 대비 체류·이해 우위)
- 입력 확장: beats에 옵션 필드 — `inset`(클립/이미지 경로+start), `inset_pos`(좌상/우상/하단), `zoom`(1.0~1.4, origin x%,y%).
- ffmpeg: 메인 트림 → overlay로 인셋 합성(테두리+그림자) → zoompan 또는 scale+crop 애니메이션으로 줌인아웃. 자막바는 기존과 동일.
- 성능/화질 주의: zoompan 느리면 프레임보간 최소화·프리셋 조정(형 지적: "크리에이터만 갔다오면 화질 안 좋아짐" → crf·스케일 보존). 화질 저하 5:5면 사람에게 문의(자율협력 규약).
- 체크리스트: 기존 render_from_job 8항목 + 인셋 가독성 + 줌 화질(열화 없음). PASS까지.
- 산출: render_from_job.py 수정 PR + 샘플 1편(개츠비 클립 _clips_test로) 렌더해 _jobs/_done/에 inset_demo.mp4.

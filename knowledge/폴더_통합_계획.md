## 절대 원칙 (충돌·유실 방지)
- **안 지운다.** 은퇴 폴더는 삭제가 아니라 `~/atnown-_archive/`로 **이동(mv)**.
- **커밋 안 된 것부터 건진다.** 폴더마다 숨은 미커밋 작업이 있을 수 있다(개츠비가 실증).
- **단계마다 이찬호 확인** 후 다음으로. 렌더 중엔 명령 얹지 않는다(중복렌더 방지).
- git 정본(origin = github.com/cksghrj22-bot/-)은 이미 커밋된 코드/canon의 단일 출처. 통합은 "맥 working copy"를 하나로 모으는 것.

## 단계
- **P1 · 인벤토리 (읽기만, 안전)**: 3폴더 각각 → `git remote -v` · `git status`(미커밋) · untracked · 고유 디렉토리 · 디스크 크기. → "뭐가 어디에 unique한지" 표로.
- **P2 · 유실 방지**: 각 폴더의 고유/미커밋 작업 → (canon이면) 트렁크에 커밋·push / (로컬 산출물이면) content-pipeline로 이관. **하나도 안 잃게.**
- **P3 · 정본 확정**: `~/atnown-content-pipeline`을 유일 작업폴더로. 트렁크 최신 pull 반영. Cowork·나이틀리·워처가 전부 이 경로만 보게 경로 통일.
- **P4 · 은퇴**: `~/atnown-repo`·`~/atnown-trunk` → `~/atnown-_archive/`로 mv(삭제 X). 며칠 문제없으면 최종 정리.

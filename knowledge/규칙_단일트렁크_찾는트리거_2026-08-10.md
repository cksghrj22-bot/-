# 규칙(박제) — 단일 트렁크 + 찾는 트리거 + 배선 하나

> 2026-08-10 형 확정. 문제: 기록은 다 있는데 **찾는 트리거가 없어** 매번 백지에서 시작. 저장소가 갈려 "이건 저기, 이건 여기". → 통합 뇌·저장소를 하나로.

## 세 기둥
1. **트렁크 하나** = 본진 repo. 진행상황=`_cowork_sync/pipeline/COWORK_STATUS.md`. 기록=knowledge/·pipeline/·outputs/·_obsidian_*. claude.ai 프로젝트·옵시디언=읽기 미러(정본 아님).
2. **찾는 트리거** = `scripts/trunk_boot.py "<주제>"`. 일 시작 전 반드시 실행 → 트렁크 최신 + 과거 기록(경로·스니펫). 백지 시작 금지.
3. **배선 하나** = 모든 방 부팅 파일(CLAUDE.md·AGENTS.md) 최상단에 이 트리거를 첫 스텝으로 박음. Cowork도 세션/작업 시작 시 device_bash 로 실행.

## 루프
일 받음 → trunk_boot 실행(과거 확인) → 작업 → 결과를 트렁크(COWORK_STATUS.md)에 기록 → 딴 데 흩지 않음.

## 왜
두뇌·저장소가 갈리면 사용자가 합류점이 아니라 중재자가 된다("왜 못 찾냐"의 반복). 트리거+단일 트렁크가 그걸 없앤다. (single-trunk-protocol 실행 계층.)

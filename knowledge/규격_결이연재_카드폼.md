# 규격 — 「결이 이야기」 연재 카드 폼 (정본)

> 2026-08-14 만화연재방(방4 · `M`). 근거 = **①매듭 편 최종본 6장**
> (`_out/매듭이야기_final_복고텍스트/` + 컨택트시트 `contact_sheet_내일업로드.png`).
> 형 확인: "1편은 이게 최종이었던 거 참조해." 이후 모든 편은 이 폼을 따른다.

## 1. 한 편 = 6장

①편 최종 = **c1 표지 · c2 이게매듭 · c3 끝만치면 · c4 붙잡음 · c5 풀어찰랑 · c7 전후** = 6장.
`c6_공간`은 최종에서 빠졌다(`_superseded/c6_CTA_제외.png`). **연재 기본값은 6장이다.**

| 순서 | 역할 |
|---|---|
| 1 | 표지 — 고객 어조 물음표 훅 |
| 2 | 문제 정의 — 개념에 이름 붙이기 |
| 3 | 오해 — 통념 |
| 4 | 원인/진실 — 왜 그런가 |
| 5 | 해법 — 어떻게 하는가 |
| 6 | 전후 + 질문 — 재정의 한 줄로 닫기 |

## 2. 캔버스

1080 × 1350 (3:4) · 배경 크림 `#F7EFDF` · 잉크 `#3A2A20` · 브라운 `#965C30`
헤드 밴드 `#FAF4E8` · 본문 패널 `#FDF7EB`

## 3. 표지형 (1번)

```
[배지 2개]  「결이 이야기 ②」 브라운 채움 + 「생쥐 편」 브라운 테두리
[제목]      Black Han Sans 82 · 잉크 · 최대 2줄
[그림]      좌우 여백 52px 두고 나머지 전부
```
동그라미 숫자(①②③)는 폰트에 없어 **직접 그린다** — `make_card.py`가 처리한다.

## 4. 본문형 (2~5번)

```
[상단 밴드] 높이 168px, 크림. 헤드 1줄 Black Han Sans 64 · 잉크. 흰 테두리 안 씀
[그림]      좌우 꽉 채움(풀블리드)
[하단 패널] 둥근 사각 크림 + 브라운 테두리 4px. 개구체(Gaegu Bold) 56 · 행간 74
```
본문 **2줄 권장, 최대 3줄. 행당 18자 이내.** 넘치면 카드를 하나 더 만든다(줄여 뭉개지 않는다).

## 5. 전후형 (6번)

상단 밴드 헤드만. **하단 패널 없음.** 좌우는 같은 사람·같은 각도·같은 조명·같은 옷,
달라지는 건 머리뿐. 보정 금지.

## 6. 그림 쪽 불변 규칙

- 이미지 안에 **글자·숫자·로고 절대 없음.** 문구는 조립 단계에서 얹는다.
- 얼굴 있는 캐릭터는 **결이·보리 둘뿐.** 아이롱·약통·빗·매듭은 얼굴 없는 사물.
- **레퍼런스 첨부 없이 생성하지 않는다** — `c2_매듭.png`(결이)·`c1_표지.png`(보리)·`c6_공간.png`(화풍).
- 결이의 몸은 **이어폰 줄**이다. 사람 머리카락도, 사람 소녀도 아니다.
- **결이의 상태는 편마다 다르다.** ①편=엉켜 묶임(매듭) / 생쥐 편=굽이가 펴져 납작.
  **매듭은 ①편 전용이다. 다른 편에 매듭을 그리지 않는다.**
- 보리는 매 편 최소 4컷 등장. 매 컷 같은 얼굴.

## 7. 파이프라인

```
코워크(구조 JSON 작성) → 본진 → 코덱스 실행 → 코워크 검수 → 형 "올려" → 본진 발행
```

조립만 따로 돌릴 때는 `scripts/cards/make_card.py`.

## 8. 검수 6항목

1. 6장 전부 1080×1350인가
2. 결이가 6장 전부 같은 형태(이어폰 줄 덩어리)인가
3. 이미지 안에 글자·숫자가 없는가
4. 보리가 같은 사람인가 (최소 4컷 등장)
5. 6번 전후 좌우가 같은 사람·같은 조명인가
6. 본문 3줄 넘지 않는가

## 9. 마스코트 등장 규칙 (2026-08-14 이찬호 지시)

**결이(줄뭉치 마스코트)는 그 편의 메시지와 직접 연관될 때만 등장한다.**
①매듭 편은 매듭이 곧 주제라 전 컷에 나왔지만, 그게 기본값이 아니다.
연관 없는 편에 습관적으로 넣으면 **매듭 편처럼 보여 편이 구분되지 않는다.**

- 기본: 표지에서만 상징으로 쓰고, 본문 컷은 **머리 자체로 메시지를 보여준다.**
- 생쥐 편 적용례: c1 표지만 유지, c2~c6은 마스코트 없이 머리·아이롱·손으로만 구성.
- 프롬프트에 명시할 것: `주황·머스타드 실뭉치/줄뭉치 캐릭터, 얼굴 달린 동그란 덩어리를 넣지 않는다.`

## 10. 편 분리 기준 (2026-08-14 — 실패에서 나옴)

②생쥐 편과 ③착한곱슬 편을 따로 만들었더니 형이 «차이를 못 느끼겠다»고 했다. 둘 다 씨앗이 「매직 흔한 오해」 한 글이라 몸통이 같았다. **씨앗 한 글은 한 편이다.**

- 편을 나눌 땐 **훅이 아니라 축이 달라야 한다.** 훅만 바꾼 건 같은 편이다.
- 새 편을 잡기 전 자문: 앞 편과 **오해·원인·해법 중 두 개 이상이 겹치면 합친다.**
- 축 예시: ②=너무 펴서 망함 / ③=원인을 잘못 짚음(곱슬 vs 손상) / 다음=안 펴짐(악성곱슬 자리).

## 11. 정본 위치 · 썸네일 · 피드 톤 (2026-08-14 이찬호 지시)

### 정본은 드라이브다
①편 정본 = 드라이브 「카드뉴스」 `card1_표지 / card2_매듭 / card3_끝만치면 / card4_한두가닥 / card5_공간 / card6_마무리`.
로컬 `_out/매듭이야기_*` 는 작업 잔해다 — 채택본·폐기본·중간본이 섞여 있으니 **정본으로 쓰지 않는다.**
채택본은 반드시 `_out/<편>_final__M/` 과 드라이브에 둔다. **다운로드 폴더에 남은 파일은 없는 것과 같다**(8/12 화이티시 작업본이 `Gemini_Generated_Image_2whixt...` 이름으로 다운로드에만 있어 아무도 못 찾았다).

### 썸네일 = 가장 하고 싶은 말 카드를 맨 앞에 한 번 더
순서를 바꾸는 게 아니라, **그 카드를 복제해 캐러셀 1번에 얹는다.** 본래 자리에도 그대로 남는다.
그래서 한 편 = 6장 + 썸네일 1장 = **7장 업로드**. 어느 카드를 쓸지는 편마다 차노가 고른다(4번 고정 아님).
①편 = 「한두 가닥이면 풀려요」(4번)를 썸네일로.

### 피드 톤 정합
인스타 `atnown_chano` 최근 피드 실측: 평균 RGB [137,130,126] · **웜캐스트(R−B) 1.6** 의 저채도 뉴트럴.
만화 원본은 웜캐스트 63 — 그대로 올리면 피드에서 혼자 노랗게 뜬다.
발행본은 **웜캐스트를 20 근처로 절반만 당기고**(만화 정체성 유지), 밝기를 피드 카드(232) 쪽으로 리프트, 채도 0.92.
기준 삼는 피드 게시물 = 「긴 얼굴형 단발공식」 흰 인포카드.

## 12. 손상·곱슬 그리는 법 (2026-08-14 실패에서)

- **손상을 돋보기 확대 원 안에 따로 그리지 않는다.** 별도 가닥을 얹으면 «딴 머리 얹어놨다»로 읽힌다. 결 자체로 표현한다.
- **곱슬 = 굽이치는 웨이브 곡선 / 손상 = 곧은 결 위로 잔털이 삐져나오고 끝이 갈라짐.** 형태를 다르게 그려야 구분된다.
- 전체를 물결치게 그리면 «다 곱슬»이 되어 메시지가 죽는다. 웨이브는 뿌리 짧은 구간에만.

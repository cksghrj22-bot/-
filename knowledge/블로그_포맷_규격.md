# 네이버 블로그 포맷 규격 (2026-08-19 전면 개정)

## 블록 타입별 스타일

| 타입 | 글자 크기 | 색상 | 굵기 | 용도 |
|---|---|---|---|---|
| `body` | 19pt | 검정 | 보통 | 본문 |
| `bold` | 19pt | 검정 | **굵게** | 핵심 주장, 전환점 |
| `point` | 19pt | **핑크** | **굵게** | 감정적 강조, 공감 |
| `quote` | **24pt** | 검정 | 보통 | 글 전체 핵심 한 문장 |
| `heading` | - | - | - | 섹션 제목 (질문 형식) |
| `center` | 19pt | 검정 | 보통 | 마무리, 샵 이름 |
| `small` | 작게 | 검정 | 보통 | CTA, 주소, 해시태그 |

## 강조 기준

| 강조 | 언제 |
|---|---|
| `bold` | 논리적 전환, "~때문이 아닙니다", "~잡을 수 있습니다" |
| `point` (핑크) | 감정 호소, "1년 이상 고생합니다", "감사한 마음" |
| `quote` (24pt) | 글 전체에서 **딱 1개**, 가장 중요한 문장 |

## 문장 스타일

| 항목 | 규격 |
|---|---|
| 평균 줄 길이 | **15~20자** (짧게) |
| 줄바꿈 | 문장마다 (한 문장 → 줄바꿈) |
| 문단 분리 | 빈 줄 1개 |
| 말투 | 대화체 (~거든요, ~에요, ~해볼게요) |

## 글 구조 (순서)

```
1. 인사 (body)
2. 오늘 주제 (body)
3. 핵심 주장 (bold)
4. 섹션 제목 (heading) — 질문 형식 "왜 ~할까요"
5. 설명 (body × 여러 개)
6. 강조 (point 또는 bold)
7. 인용 (quote) — 글 전체 핵심, 1개만
8. [4~7 반복]
9. 마무리 질문 (center)
10. CTA (small) — "상담만 받아보고 결정하세요"
11. 샵 이름 (center)
12. 주소 (small)
13. 해시태그 (small)
```

## 절대 하지 말 것

- 문장 길게 쓰기 (20자 넘기지 말 것)
- 줄바꿈 없이 이어붙이기
- bold/point 남발 (각각 3~4개가 적정)
- quote 여러 개 쓰기 (딱 1개)
- 딱딱한 문어체 (대화체로)

## 적용 위치

- `scripts/naver_blog_save.mjs` — 블록 파싱 시 스타일 적용
- `_publish_jobs/blog_parsed/*/blocks.json` — 블록 타입 지정

## 🕸 이 지도의 규칙 (내 일)
1. 새 생각(구술·영상·글)이 들어오면 **낱개로 두지 않고** 기존 노드와 **잇는다**(공통점·차이점 명시).
2. 반복 출현하는 실을 **줄기(thesis)**로 승격한다 — 책의 장(章)이 된다.
3. 주기 보고(아래)마다 실의 **변화·깊이감·대중과의 생각차**를 기록한다.
4. 기존 자산 우선 재사용: `키워드_지도.md`(재정의+이질개념풀)·`재정의_카드_대장.md`·`차노_보이스.md`·`차노_방향성_지도.md`·`차노의책장_제안.md`.

## 📖 지금까지 드러난 줄기 (책의 장 후보)

### 줄기 A — "조용한 것이 오래 남는다 / 의지가 매력이다"
가장 굵은 실. 여러 노드가 여기로 모인다.

**차이점:** 사토=디자인 생존담(외부 레퍼) / 제안=공간 운영철학 / 밑빠진독=자기수련 태도 / 커트=기술 재정의. 같은 실이 **레퍼·공간·태도·기술**이라는 다른 층위에서 반복된다 → 실이 진짜라는 증거.

### 줄기 B — "정체성 = 존재 자체 / 아류의 반대"
2026-07-31 구술에서 새로 굵어진 실.
- "멋있어지려 할수록 정체성을 잃는다" · "남들과 같은 방법은 아류" · "내가 곧 정체성이고 정체성이 나" · "내 존재 자체가 다른 것".
- **줄기 A와의 연결:** 조용함(A)이 곧 정체성을 지키는 방법(B) — 크게 외치면(멋내면) 남과 같아지고, 조용히 나로 있으면 다르다. **A와 B는 한 몸의 앞뒤.**
- 기존 연결: `차노_보이스.md`(사고패턴)·`재정의_카드_대장.md`.

### 줄기 C — "제안/재정의 = 차노의 방법론"
- `차노의책장_제안.md`·`키워드_지도.md` 전체가 이 실. 세상의 통념을 **재정의**해 제안으로 바꾸는 것.
- **A·B와의 연결:** 재정의(C)라는 방법으로 조용함(A)·정체성(B)을 콘텐츠로 만든다. → **삼각 거미줄: A(무엇이 남나)·B(나는 누구인가)·C(어떻게 전하나).**

## 🔌 콘텐츠 엔진과의 연결
- 이 거미줄이 **바자막 '하루치 매거진' 포맷**(`content/manifests/바자막_작은속삭임_*.json`)의 대본 원천.
  한 편 = 줄기 하나에서 떠올린 조용한 생각 + 형 사진(내 것/내가 좋아하는 것) + 형광하늘 줄기바.
- 영상이 쌓이면 = 책의 초고가 쌓인다. **영상 = 하루치, 책 = 그 합.**

## 🎙 '반대로 보면 · 하루일기' 포맷·톤 (2026-08-01 형 확정)
- **구조**: 사진/영상 1장 = 한 소재. 통념 한 줄 + 뒤집는 한 줄(반대되는 시각). **억지로 잇지 않는다**(삼단논법·입증 금지, 형 '남들 앞에서 입증하는 거 같아 별로'). 의식의 흐름.
- **톤(킬러)**: 현실용어 + **살짝 찌질(자기반성)** + 한번 더 생각하게. 자문형 꼬리 "...?", "나만 그런가?", "내가 못 하는 건가?", "나도 저러고 있나...?".
- **예**: 회 써는 남자 영상 → "멋있다.. 장인이네. **나도 커트할 때 저러고 있나...?**" (남의 장인정신 → 내 커트 반성). 커피 조금 → "왜 이렇게 조금 줘? 아 근데 아껴 먹게 되네... 나만 그런가?"
- **사진의 미 보존**: 예쁜 사진일수록 바 최소·여백/plain존에(형 '사진 미 해치는 거 아닌가'). 여백형(글은 아래 밴드) 옵션 있음.
- **변주(형 2026-08-01)**: 짧은 찌질 캡션이 기본, **가끔 장문·느낀점 회고**도 섞는다 → 책 초고의 긴 호흡 파트가 된다.
- **연결(줄기)**: 이 포맷의 '통념 뒤집기' = 줄기C(재정의 방법론)의 일상 버전. '남들 A일 때 나는 B' = 줄기B(정체성). 하루 기록 축적 = 책.
- 매니페스트: content/manifests/바자막_반대로보면_하루일기.json / 슬라이드: python3 -m shorts.bars_slides.

## 🧠 형 생각의 흐름을 읽는 법 (2026-08-01 형 '생각의 방향성·구조·연관 짓는 법을 이해해야 돼')
**① 한 생각의 구조(4단)**: `표면 관찰 → 통념 의심 → 재정의 → 업/삶으로 확장`.
  예) 커피 조금 나옴(관찰)→왜 이렇게 조금(의심)→아껴 먹게 되네(재정의: 결핍=음미)→커트도 덜어냄이 완성(확장).
**② 연관 짓는 법(거미줄)**: 낱개 정보가 실이 아니라 **서로 다른 소재가 '같은 사고 구조'를 공유할 때** 그게 실이다.
  → 실을 찾는 질문: "이 생각, 어떤 통념을 뒤집나? 그 뒤집기 구조를 공유하는 다른 소재는?"
**③ 내 작업 루틴**: 형 생각 인입 시 → (a)4단 구조로 해체 → (b)어떤 통념 뒤집기인지 명명 → (c)같은 구조의 기존 노드에 잇기(공통점) + 다른 층위 표시(차이점) → (d)줄기 승격 여부 판단.

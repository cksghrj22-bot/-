# 🎬 알파컷 브리핑 프롬프트 (창엽 커트의 정석 쇼츠 · 2026-07-27 이찬호)
> 알파컷/오퍼스클립에 붙여넣거나 설정 기준으로 쓰는 브리핑. 이찬호 지정 규격 총정리(BGM·제목가시성·1:1레이아웃·컷기준 포함).

---

## 📋 붙여넣기용 프롬프트 (복사해서 알파컷 AI에 입력)

```
[채널] 앳나운(AT NOWN) 청담 미용실 · 창엽 부원장 커트 교육 「커트의 정석」
[목표] 미용 세미나 롱폼에서 조회수 잘 나오는 교육 쇼츠를 뽑아줘.

■ 어디서 끊을까 (컷 지점 = 가장 중요) ★내 기준
- ⭐한 클립 = 질문(셋업) → 창엽 답변 끝까지가 통으로. 답만 자르면 맥락이 없어 안 됨.
  (예: 학생 "짧게 자르면 더 부풀어요?" → 창엽 "여기 짧게 자르면 모질에 따라…")
- 문장 '중간'에서 끊지 마. 반드시 종결어미(~요/~거야/~거든)로 말이 끝나는 데서 컷.
- 한 개념이 '완결'되는 지점에서 끊기. 개념 하나 = 클립 하나.
- 죽은 구간(긴 침묵·준비동작·버벅임·잡담)은 빼고 알맹이만.
- 한 클립 20~45초. 창엽이 핵심 개념 설명하는 구간 위주(시연·화면 보며 설명 좋음).

■ 1:1 레이아웃 ★내 기준
- 세로 9:16 캔버스. 그 안에 영상은 '정사각(1:1)'으로 크롭해 화면 중앙에 크게.
- 위쪽 = 제목(훅) 밴드, 아래쪽 = 자막. 인물/시연이 정중앙에 꽉 차게.

■ 제목(훅) 가시성 ★내 기준
- 상단에 '크게'. 두 줄이면 화면 폭 안 넘게 자동 줄바꿈. 영상이랑 안 겹치게 위 밴드에.
- 핵심어만 노랑 강조 + 나머지 흰색. 굵은 글씨 + 외곽선/그림자로 어떤 배경에도 또렷하게.
- 어그로 훅(궁금증 갭·손실회피). 단 낚시 금지(내용과 100% 일치).
  예: "짧게 자르면 큰일 나는 사람 특징" / "숱 쳐도 안 가벼운 이유 90%가 여기서 틀림"
     "미용사도 헷갈리는 가위질 차이" / "자를 곳 못 보면 평생 초보"

■ 자막
- 한글 = 크게, 하단(유튜브 UI존=맨 아래 380px '위'에 배치, 안 묻히게).
- 영어 = 한글 바로 아래 보조로 작게(외국인 유치).
- 창엽 실제 발화 그대로. 지어내지 말 것.

■ 영상 톤
- ⛔흑백 금지. 컬러 유지(따뜻한 필름 톤).

■ BGM ★내 기준
- 잔잔한 피아노. 배경으로 '아주 작게'(14~15%) — 말소리·현장음이 주인공.
- 클립마다 다른 곡으로(같은 곡 반복 금지). 끝은 자연스럽게 페이드아웃.

■ 브랜드
- 어그로는 훅만. 본문·자막은 정석·전문가 톤 유지(교육 줄기 격). 끝에 앳나운/창엽 부원장 표기.
```

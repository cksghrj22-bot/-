> 알파컷/오퍼스클립에 붙여넣거나 설정 기준으로 쓰는 브리핑. 이찬호가 이번 대화서 지정한 규격 총정리.

## 📋 붙여넣기용 프롬프트 (복사해서 알파컷 AI에 입력)

```
[채널] 앳나운(AT NOWN) 청담 미용실 · 창엽 부원장 커트 교육 「커트의 정석」
[목표] 미용 세미나 롱폼에서 조회수 잘 나오는 교육 쇼츠를 뽑아줘.

■ 어떤 구간을 자를까 (클립 선정)
- 창엽 부원장이 '핵심 개념'을 설명하는 구간 위주.
- ⭐질문(셋업)→답변이 한 클립에 같이 들어가게. 답만 자르면 맥락이 없어 안 됨.
  (예: 학생 "짧게 자르면 더 부풀어요?" → 창엽 "여기 짧게 자르면 모질에 따라…")
- 화면·마네킹 보며 시연·설명하는 장면 좋음.
- 한 클립 20~45초.

■ 훅(제목) — 어그로 필요
- 궁금증 갭 + 손실회피형으로 자극적으로. 단 낚시 금지(내용과 100% 일치).
  예: "짧게 자르면 큰일 나는 사람 특징" / "숱 쳐도 안 가벼운 이유 90%가 여기서 틀림"
     "미용사도 헷갈리는 가위질 차이" / "자를 곳 못 보면 평생 초보"
- 상단에 크게. 핵심어만 노랑 강조.

■ 자막
- 한글 자막 = 크게, 화면 하단(단 유튜브 UI존=맨 아래 380px 위에 배치, 안 묻히게).
- 영어 자막 = 한글 바로 아래 보조로 작게(외국인 유치용).
- 창엽 실제 발화 그대로. 지어내지 말 것.

■ 영상
- ⛔흑백 금지. 컬러 유지(따뜻한 톤).
- 세로 9:16, 인물/시연이 중앙에 크게 보이게.

■ BGM
- 잔잔한 피아노, 배경으로 아주 작게(14~15%). 현장음 살림.

■ 브랜드
- 어그로는 훅만. 본문·자막은 정석·전문가 톤 유지(교육 줄기 격).
- 끝에 앳나운/창엽 부원장 표기.
```

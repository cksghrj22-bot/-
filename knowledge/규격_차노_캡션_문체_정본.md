# 규격 정본 — 차노 캡션 문체

> 도출 방법: 2026-08-19 「커트가 아니라, 조각입니다」에서 **내가 쓴 캡션 vs 차노가 다시 쓴 캡션**을 대조.
> 차노 지시: *"내 글의 특징을 잘 분석 규격도 잘 분석해서 다음엔 더 내글과 같은 글이 나오길"*
> 캡션 규율(`규격_낙타형자막바_컨텐츠_정본.md` §캡션 규율)의 **실행편**이다.

---

## 1. 줄바꿈은 글자수가 아니라 **의미 덩어리**로 끊는다 ⭐가장 큰 차이

「한 줄 14자」는 **상한이지 목표가 아니다.** 나는 14자를 채우려고 구를 토막 냈다.

| | |
|---|---|
| ❌ 내가 쓴 것 | `이점에 유의하여` / `커트하면` / `충분히 보완` / `할 수 있습니다.` — **4줄로 분해** |
| ✅ 차노 | `이점에 유의하여 커트하면` / `충분히 보완 할 수 있습니다.` — **2줄** |

- **서술어를 떼지 않는다.** "충분히 보완 / 할 수 있습니다"처럼 끊으면 읽는 호흡이 부러진다.
- 한 줄 = **한 번에 읽히는 구(句)**. 14자를 넘어도 의미가 안 끊기면 붙여 둔다.
  실제로 차노 줄 중 `층의 높이와 층의 양을 구분하여 납작한 동양인 두상에 대응하기` 는 **33자**다.
- 즉 14자는 **짧은 리듬 구간(도입·선언)** 에서 지키는 값이고, 설명 구간에서는 의미가 이긴다.

## 2. 빈 줄은 **⠀(U+2800 브라유 공백)** 으로 만든다 ⭐실무 규격

인스타그램은 **순수 빈 줄을 접어버린다.** 그냥 개행만 넣으면 문단 간격이 사라진다.
차노는 빈 줄마다 브라유 점자 공백 문자를 한 개 넣어 간격을 살린다. (그 편 캡션에 **15개**)

```
문장 끝.
⠀            ← 이 줄에 U+2800 한 글자
다음 문장.
```

- 복사·붙여넣기할 때 이 문자가 사라지지 않게 주의한다. 눈에 안 보인다고 지우면 안 된다.
- 해시태그 앞 간격도 이걸로 만든다.

## 3. 카드에 있는 문장을 캡션에 **다 넣지 않는다**

나는 구술 전문을 캡션에 그대로 옮겼다. 차노는 **카드와 겹치는 연결어를 덜어냈다.**

| 차노가 뺀 것 | 왜 |
|---|---|
| `그래서 두상, 헤어를 조각함으로써` | 카드 3장에 이미 있음. 캡션에선 결론만 남김 |
| `그냥 직관적으로도 다르구요` | 카드 5장 문맥과 중복 |

→ 캡션은 카드의 **자막 복사본이 아니다.** 카드에서 못 다 한 말을 잇는 자리다.

## 4. 개념은 **풀어야 한다.** 단 설명이 아니라 **선언**으로 ⭐내 판단이 틀렸던 지점

나는 「낯선 단어를 그대로 두면 물음표가 남는다」고 판단해 개념 6개를 나열만 했다.
차노는 **전부 풀었다.** 그런데 그게 해설이 아니었다.

> 매듭을 풀지 않고 끝만 날린 치는 **가벼움이 아니라 날리는 거에요.**
> 두상이 둥글다는 가정으로 모든 이론이 나왔는데 두상이 둥글지 않으니
> **그 모든 이론의 기본가정이 틀린겁니다. 그럼 새로운 생각이 나와야죠.**

**차노의 도발은 낯선 용어에서 나오지 않는다. 「그건 틀렸다」고 말하는 데서 나온다.**
- 남이 하는 방식을 지목해 부정한다 → 읽는 디자이너가 자기 얘긴가 하고 걸린다.
- 부정 뒤에 **대안을 요구**한다("그럼 새로운 생각이 나와야죠").
- 그러니 개념은 나열하지 말고, 각각에 **차노의 판정**을 붙여야 한다. 판정이 없으면 그냥 단어다.

## 5. 구조 — 고객층과 디자이너층을 **구분선으로 나눈다**

```
[고객 파트]  시술 결과·이유. 짧은 호흡.
·
.
.
더 나아가,          ← 층을 넘는 신호
[디자이너 파트]  개념 + 판정. 긴 호흡 허용.
·
📍앳나운 메종한남
·
⠀
⠀
#해시태그
```

- 한 게시물이 **두 독자**를 동시에 상대한다. 위는 고객, 아래는 동종업계.
- 전환 신호는 `더 나아가,` 처럼 **말로 하는 접속**이다. 제목·머리표를 쓰지 않는다.

## 6. 종결어미 — 구어체를 섞고, 체언으로도 끝낸다

| 형태 | 예 |
|---|---|
| 말 거는 구어체 | `~보며 손님들께 커트하는데요,` |
| 체언 종결 | `꼭 필요함이라는 것.` |
| 단정 | `기본가정이 틀린겁니다.` |
| 혼잣말·권유 | `그럼 새로운 생각이 나와야죠.` |
| 감탄 | `아쉬운거구요!` |

→ **평서형만 반복하지 않는다.** 단정 → 혼잣말 → 감탄으로 온도를 바꾼다.

## 7. 지명·브랜드는 정확히

`📍앳나운` ❌ → **`📍앳나운 메종한남`** ✅ (내가 지점명을 빠뜨렸다)

## 8. 차노 표기를 **교정하지 않는다** ⭐

맞춤법·띄어쓰기를 고치면 그 사람 글이 아니게 된다. 아래는 **전부 그대로 둔다.**

| 차노 표기 | 표준 | 판정 |
|---|---|---|
| `납작하기때문에` | 납작하기 때문에 | **그대로** |
| `거에요` | 거예요 | **그대로** |
| `날린 치는` | (숱치기 지칭) | **그대로** |
| `움직일때` | 움직일 때 | **그대로** |

→ 공백 제거 대조(게이트 N8)로 원문 일치를 확인하되, **맞춤법 교정은 위반이다.**

## 9. 하지 말 것 (재확인)

- 마무리 질문 붙이기 — `~어떠세요?` `~어떨까요?` `~시길 바랍니다` (08-14·08-15·07-31 반복 적발)
- 요약·정리 문단 만들기
- 이모지 남발 (차노는 `📍` 하나만 쓴다)
- 내가 지어낸 비유·수사 넣기

## 체크리스트 (캡션 제출 전)

- [ ] 줄바꿈이 **구 단위**인가. 서술어를 떼지 않았나
- [ ] 빈 줄에 **⠀(U+2800)** 이 들어갔나
- [ ] 카드 자막과 **중복되는 연결어**를 덜어냈나
- [ ] 개념마다 **차노의 판정**이 붙었나 (나열로 끝나지 않았나)
- [ ] 고객 파트 / 디자이너 파트가 **구분선으로 나뉘었나**
- [ ] 종결어미가 **한 종류로 반복**되지 않나
- [ ] `📍앳나운 메종한남` 인가
- [ ] 차노 표기를 **교정하지 않았나**
- [ ] 마무리 질문이 **없나**

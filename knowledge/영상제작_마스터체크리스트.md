## 1. 대본/텍스트 (창작·할루시네이션 방지)

| # | 검사 | 방법 | 통과 기준 |
|---|---|---|---|
| 1.1 | **형 원문 그대로** | 원문 vs 대본 diff | 한 글자도 창작/윤문 없음 |
| 1.2 | **줄바꿈만 수정** | 원문 공백 제거 후 비교 | 내용 100% 동일 |
| 1.3 | **없는 정보 추가 금지** | 원문에 없는 숫자/이름/사실 | 0개 |
| 1.4 | **어색한 표현 임의 수정 금지** | 형 원문이 어색해도 그대로 | 수정 0건 |

**위반 사례:**
- "펌은 3개월" → 원문에 없는 숫자 추가 ❌
- "더 자연스럽게" 윤문 ❌

```bash

python3 shorts/verify_render.py <영상.mp4>

# 2. 스샷 시트 생성
python3 scripts/shorts_gate.py <영상.mp4>

ffmpeg -i input.mp4 -vf "ass=sub.ass" -f null - 2>&1 | grep -i font
```

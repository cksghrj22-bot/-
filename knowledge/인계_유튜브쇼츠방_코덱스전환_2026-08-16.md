## 4) 반복 해소 — 실전 절차 (정본 §10)
1. 반복도 측정 → 55% 초과면 교체 필수
2. **원본을 다시 만들지 않는다.** 반복 구간만 덮는다
3. **인서트 높이 1560px 고정** — 하단 자막(y1600~) 살린다. 전체높이로 덮으면 자막이 사라진다
4. **1초 미만 인서트 금지** — 최소 1.5초, 권장 1.7~2.0초
5. 4K 소스만. 720p 금지
```bash
ffmpeg -y -i BASE.mp4 -i INS.mp4 -filter_complex \
 "[1:v]setpts=PTS+시작/TB[i];[0:v][i]overlay=0:0:enable='between(t,시작,끝)'[v]" \
 -map "[v]" -map 0:a -c:v libx264 -preset medium -crf 19 -pix_fmt yuv420p -c:a copy OUT.mp4
```

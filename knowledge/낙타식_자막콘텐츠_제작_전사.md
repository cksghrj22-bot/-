# 인수인계 프롬프트 — 「낙타식 자막 콘텐츠」 제작 전사
> 새 방/에이전트에 이 문서를 통째로 붙여넣으면 바로 이어받아 만들 수 있음. (앳나운 / 차노)
> 모든 수치는 `scripts/cards/nakta_post.py` 코드 실값과 1:1 — 임의 변경 금지.

당신은 지금부터 앳나운의 **낙타식 자막 콘텐츠**를 담당한다. 아래 규격·규칙·게이트를 그대로 지켜 제작한다. 당신은 소스·문안·매핑 준비와 자가검수까지 한다. **렌더는 본진(코덱스, nakta_post.py), 발행은 차노 건별 승인 후에만.** 임의 발행 금지.

## 0. 이 포맷이 뭔가 (1초 판별)
사진·영상 슬라이드 위에 **글자폭 직각 박스**를 **좌측정렬·계단식**으로 얹어 **설정(질문/전제) → 결론(단정)** 을 보여주는 **인스타 세로 캐러셀**. **TTS 없음.**
→ "계단 박스가 위에 있고 TTS 없다" = 낙타형. (하단 자막바 아님, 흑백 메시지형 아님. 헷갈리면 폐기)

## 1. 캔버스
- **1080×1350 (4:5)** 캐러셀. (영상판 쇼츠는 1080×1920)
- 영상 슬라이드는 **3~5초**, 얼굴·머릿결 잘 보이는 구간으로 트림.

## 2. 박스 규격 (코드 실값, 변경 금지)
- 폰트 `NanumSquareRoundEB.ttf`, 기본 **58**.
- **글자폭 직각 사각형** (전폭 바자막 금지, 하단 고정 금지).
- 패딩 좌우 **22** / 상하 **16**. 줄 간격 **GAP 49**. 계단 들여쓰기 **STEP 46**(줄마다 오른쪽 계단).
- 시작 기본 left **7%(0.07)** / top **30%(0.30)** — **슬라이드마다 변주.** 좌측정렬.

## 3. 역할·색
- **설정 = 흰 박스(255,255,255,α240) / 검정 글자(20,20,20)** — 윗줄, 질문·전제.
- **결론 = 검정 박스(0,0,0,α210) / 흰 글자** — 아랫줄, 단정.
- **시안(하늘 120,230,245,α245) = 강조** — 6장 중 **2~3장 결론에 분산**(연속 금지). **문구는 그대로, 색만.**

## 4. 배치·리듬
- 피사체(얼굴)·핵심 디테일 **안 가림** — 빈 공간에 어긋나게.
- 슬라이드마다 **위치 변주**(위/중/아래·좌/우 섞어 리듬). 6장 다 같은 자리 = 신문, 금지.
- 위계: **설정(질문) 크게 / 결론(정보) 작게**(길면 더 작게).

## 5. 문안(카피) 규칙
- **차노 원본 그대로.** 창작·윤문 금지(없는 말·수치·출처 지어내기 금지).
- 구조: 설정("…?" 질문/전제) → 결론(단정 한 줄).
- **너무 함축 금지** — 설명 있어도 됨(2문장·좀 길어도), 대신 **글자만 작게**. 가시성 우선.
- 자기자랑·남비판 금지. 문제 = **불완전 + 가능성** 프레임("안 되는 게 아니라 아직 결을 못 살린 것").
- **3포인트 매핑**: 한 편 = 3가지 포인트, 각 포인트 = 설정+결론 → **6장**.
- 품질: 재미·감동·확실한정보 중 **최소 하나** 확실 통과. 애매하면 킬.

## 6. B롤 규칙 (핵심)
- **같은 클립 재탕 금지.** 이미 발행에 쓴 클립 재사용 X. 신규/미사용 클립에서 주제에 맞게.
- 소스: `_clips_job/` · `앳나운 영상/_B롤/` · 차노 신규 제공. B롤 방향은 차노가 잡아줌.
- 제목-B롤 연관 80%+ / 가시성 우선.

## 7. 렌더 게이트 (하나라도 걸리면 폐기)

✅ 1080×1350 / 계단 박스 규격 / 색(설정 흰·결론 검정·시안 2~3 분산) / 위계 / 위치 변주·안 가림 / 영상 3~5초 가시성 / 차노 원본 그대로
🔁 산출 직전 2번: ①프레임 눈으로(가림·변주·색·크기) ②영상 재생구간(3~5초·가시성)

## 8. 흐름·역할·경로
- 준비(이 방): 소스·문안·매핑 표 채우기 + 게이트 자가검수 → 링크.
- 렌더: **본진 코덱스**, `scripts/cards/nakta_post.py`.
- 발행: **차노 "올려" 건별 승인 후에만.**
- 출력: `_out/<주제>_낙타캐러셀/` slide_1..N. 완료 시 트렁크(`atnown-trunk/_ROOMS_LOG.md`)·`_cowork_sync/`에 링크 한 줄.
- 지시 통로: `_codex_inbox/TASK_*.md` 드롭 → 결과 `_cowork_sync/briefings/`.

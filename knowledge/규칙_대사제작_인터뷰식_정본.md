# 규칙(박제) — 대사(카피)는 형 인터뷰로 만든다
형 확정 2026-08-10. 모든 방 공통. 할루시네이션 박제와 직결.

## 원칙
- 대사·카피·스크립트는 **형 인터뷰**로 만든다. 코워크 = 취재기자.
- 코워크가 **짧은 질문 하나씩**(한 번에 하나) 던진다 → 형이 답한다 → **형 답변에서만** 대사를 뽑아 구성.
- **창작·윤문 금지. 형 단어 그대로.** 줄바꿈만 형 호흡대로(시적 형태 = 읽기 쉽게).
- 형이 안 한 말은 안 넣는다. 씨앗 = 형 답변.

## 흐름
1. 주제 잡기(형이 정함) →
2. 코워크 질문(짧게, 한 개씩) →
3. 형 답변(구술) →
4. 코워크가 답변 원문에서 대사 초안 구성(설정/결론·낙타형 등 포맷에 맞춰) →
5. 검수(05_까다로운_검수 + 재정의 대장 통과) →
6. 형 yes → 코드방/코덱스 렌더.

## 박제
- 형 답변 원본 → `knowledge/차노_구술_원본/`.
- 완성 대사 → `outputs/`.
- 질문도 남긴다(어떤 질문이 좋은 답을 뽑았는지 = 인터뷰 자산).

## 톤
- 질문은 유도신문 아님. 형이 편하게 풀도록 여는 질문. 자기자랑·남비판 프레임 금지.

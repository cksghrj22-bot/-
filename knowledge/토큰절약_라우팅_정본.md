| 명령 | 용도 | 비용 |

## 뭘 어디로 보내나

### Ollama로 (무료)
- 요약해줘, 정리해줘
- 번역해줘
- 비교해줘, 차이가 뭐야
- 몇 개야, 찾아줘
- 포맷 변환, 리스트

### Claude로 (유료)
- 차노 목소리로 글
- 대본, 기획, 전략
- 코드 작성/수정
- 판단이 필요한 것
- 서사, 스토리, 창작

## 작업 방식 — 달라진 점

### 전 (전부 Claude)
```
형 → Claude에서 모든 작업
```

### 후 (분산)
```
단순 질문 → 터미널에서 `물어 "질문"` → Ollama (무료)
창작/판단 → `본진` → Claude (유료)
렌더/업로드 → _terminal_inbox → Codex (분리)
```

---

## 형이 기억할 것

1. **단순한 건 `물어`로 먼저** — 요약, 비교, 검색
2. **글/판단만 `본진`** — 차노 보이스, 기획, 코드
3. **렌더는 자동** — Codex가 알아서

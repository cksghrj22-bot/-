# 시스템 라우팅 정본 (2026-08-13 갱신)

## ⚠️ Creator OS 제외 (2026-08-13 이찬호 지시)

**Creator OS 에이전트 사용 중지.** 이유:
- 튜닝 안 됨 (되묻기 계속, 규격 무시)
- 인수인계 안 됨 (매번 처음부터 가르쳐야 함)
- 제멋대로 일함

**새 라우팅:**
```
형 → 코워크(디스코드) → 본진 터미널 → Codex(손)
```

## 🧠 본진 터미널 역할 (2026-08-13 이찬호 정의)

**본진 터미널 = 엔지니어 + 뇌 + 인수인계 + 키워드분류 + 전략담당**

| 역할 | 내용 |
|------|------|
| 엔지니어 | 문제 발생 즉시 해결, 시뮬레이션으로 미리 뚫음 |
| 뇌 | trunk + pipeline 읽고 생각해서 명령 |
| 인수인계 | 방별 인수인계 자동 주입 |
| 키워드분류 | 제목에서 방 자동 분류 (낙타/쇼츠/만화 등) |
| 전략담당 | 무슨 일이든 통합으로 받아서 분류 후 Codex에 정확히 넘김 |

**Codex = 손** — 본진이 시키는 대로 실행만.

디스코드 5방 채널은 **알림용**으로만 쓴다. 에이전트가 작업하지 않음.

## 1. 본진 터미널 경유 필수

| 작업 | 이유 | 경로 |
|-----|------|------|
| 드라이브 업/다운 | API가 터미널에만 | inbox → 터미널 |
| 렌더/인코딩 | ffmpeg 터미널에만 | inbox → watcher |
| git 작업 | 권한 터미널에만 | inbox → 터미널 |
| TTS/SNS API | 키가 터미널에만 | inbox → 터미널 |

**디스코드 에이전트가 직접 하면 안 됨 → inbox 파일 생성**

**채널 섞이면 안 됨 — 채널ID로 분리**

## 8. 자동 Failover (2026-08-12 박제)

**상태:** Claude 메인 / Codex 서브

```
Claude 토큰 한도 → 자동으로 Codex 전환
Claude 복구 → 자동으로 Claude 복귀
```

| 상태 | 명령 입력 |
|-----|----------|
| Claude 메인 | 여기(Claude Code) |
| Codex 메인 | `codex "작업"` 또는 `ollama run llama3 "질문"` |

**수동 전환:**
```bash
# 강제 Codex로
python3 scripts/auto_failover.py --force codex

# 강제 Claude로  
python3 scripts/auto_failover.py --force claude

# 상태 확인
python3 scripts/auto_failover.py --status
```

**자동 체크:** 5분마다 (LaunchAgent)
**알림:** 기획전략실 웹훅

## 📚 노션 + 옵시디언 역할 (2026-08-13 이찬호 정의)

| 도구 | 역할 | 목적 |
|------|------|------|
| **노션** | 생각 정리 | 키워드로 묶어 **책으로 낼 수 있을 정도** |
| **옵시디언** | 방향성·연관성 | 생각의 **공통점을 묶는 능력** — 링크로 연결 |

**옵시디언만의 능력:**
- 노트 간 [[링크]]로 연결
- 그래프 뷰로 생각의 흐름 시각화
- 방향성·연관성·공통점 발견

**활용:**
- 형님 생각 → 옵시디언에 저장
- 연관성 발견 → 노션에 정리
- 정리된 것 → 책·콘텐츠로

**연동 상태:** 항상 켜둠 (LaunchAgent)

---

## 📚 노션 vs 옵시디언 (2026-08-13 명확화)

| 도구 | 역할 | 흐름 |
|------|------|------|
| **노션** | 책·지식 콘텐츠 | 정리 끝난 것 → 발행 |
| **옵시디언** | 사고 확장 | 씨앗 → Claude 분석 → 방향성 피드백 → 형님 재사고 → 발전 |

**옵시디언 연동 정본:** `knowledge/옵시디언_사고확장_정본.md`

**Claude 역할:**
- 형님 씨앗 받으면 볼트 검색
- [[링크]] 추적해서 연관성 찾기
- 공통점·방향성 피드백
- 시야 넓히는 연결점 제시

**형님 역할:**
- 씨앗 던지기
- 피드백 보고 다시 생각
- 발전된 생각 → 노션에 정리

## 9. 본진 터미널 역할 정의 (2026-08-13 이찬호 박제)

**본진 터미널 = 엔지니어 + 디렉터 + 몸뚱이 + 뇌**

| 역할 | 할 일 |
|-----|------|
| 엔지니어 | 시스템 브릿지 연결, 토큰/OAuth 만료 미리 체크 |
| 디렉터 | 6방 키워드 매핑, 작업 분류/판단 |
| 몸뚱이 | 회신/역회신 처리, Codex에 작업 넘기기 |
| 뇌 | 복잡한 판단, 기존 자산 검색/활용 |

**절대 금지:**
- 토큰/OAuth 만료로 일 정지
- 브릿지 끊어진 상태로 방치
- "없다/안 된다" 말하기 전에 먼저 찾기

**자동 체크 항목:**
- 드라이브 토큰
- 유튜브 OAuth
- 일레븐랩스 API
- 노션 연결
- 6방 폴더 접근

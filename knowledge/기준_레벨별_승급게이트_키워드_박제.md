# 레벨별 승급 게이트 & 키워드 (박제)

## 레벨 게이트 기준

### L1 → L2 (기본기)
- **핵심**: 가위파지, 기본 자세, 위생 습관
- **합격**: 75점 이상
- **필수 키워드**: 손목 각도, 스윙, 클리닝

### L2 → L3 (기본기 완성)
- **핵심**: 베이직컷 숙달, 약품 이해
- **합격**: 75점 이상
- **필수 키워드**: 원랭스, 세임레이어, 약품 도포

### L3 → L4 (전투원)
- **핵심**: 고객 응대 시작, 실전 투입 준비
- **합격**: 80점 이상
- **필수 키워드**: 상담 스킬, 현장 판단, 속도
- **⚖️ 가중치**: 실전모델작업 연습 **70%** (08-16 차노 지시 상향)

### L4 → L5 (SNS 전사)
- **핵심**: 개인 SNS 운영, 팔로워 확보
- **합격**: 80점 이상
- **필수 키워드**: 콘텐츠 기획, 촬영, 편집
- **SNS 기준**: 주 3회 게시, 연습 주 4회
- **⚖️ 가중치**: SNS 노출 **70%** (08-16 차노 지시 상향)

### L5 → 스타일리스트
- **핵심**: 모객·디자인·상담 종합
- **합격**: 80점 이상 + 모객 실적
- **필수 키워드**: 자기 고객, 재방문율, 디자인 제안
- **⚖️ 가중치**: 모객력 **70%** (08-16 차노 지시 상향)

## SNS 연습 기준
- L1/L2/L3: 주 2회
- L4/L5: 주 3회
- 연습: 주 4회 = 만점

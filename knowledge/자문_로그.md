> 원본 인스트럭션: `knowledge/억만장자_자문단_AI팀.md`.

## 2026-07-27 · 현 콘텐츠·방향 진단 (이찬호 "내 영상·방향성에 8인 자문 붙여")
현 자산: 폰으로 시술 원본(염색 023/024·살롱 025) 유입 / 재정의 시리즈(볼륨매직·사각형 단발·새치·요즘의 디자이너) / 차노쌤 채널.

| 자문역 | 조언 |
|---|---|
| 03 게리비(콘텐츠) | 시술 원본이 금광 = *Document*. 꾸미지 말고 과정 그대로, 매일 1클립. 훅만 계속, 예약 유도는 가끔. |
| 07 고딘(차별화) | '재정의' 시리즈가 Purple Cow. 상식 뒤집는 관점 = 브랜드 깃발. 하나의 시리즈로 못박기(「차노 사전」). |
| 02 호르모지(오퍼) | 볼륨매직 '두상 % 진단' 프레임 = 상품화 씨앗. 무료 진단 → 상담 연결. |
| 04 브런슨(퍼널) | 재정의(무료)→두상·얼굴형 진단 상담(저가)→시술→정기관리. 카드/도식이 입구. |
| 01 카돈(매출) | 시술 결과를 다음 콘텐츠로(before/after) = 팔로업·소개 엔진. |
| 05 케네디(고가) | "사각도 예뻐요"·"기본을 읽어라"가 프리미엄 근거. 할인 대신 "왜 이 값". |
| 06 벨포트(설득) | 요즘의 디자이너(신뢰)+볼륨매직(확신) = 확신 3축 콘텐츠 → 상담 스크립트 재활용. |
| 08 로빈스(실행) | 이번 주 실험 1개: 염색 다큐 쇼츠 발행→조회수 측정→되는 포맷 배로. |

**통합 액션**: 지금 올라온 염색 023 원본으로 「과정 다큐 쇼츠」 1편을 스텝시스템(STEP3=실사) 태워 발행 → 조회수 측정 → 되면 데일리 시술 다큐 라인 고정.
**방향성 한 줄**: 형 채널 = "미용 상식을 재정의하는 다큐형 크리에이터." 관점(고딘)×과정기록(게리비)×프리미엄(케네디).

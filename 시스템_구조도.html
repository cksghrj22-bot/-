🔎 오늘 그 방이 찾은 정정 (형 지적이 다 맞았음)

왜 "잘된다더니" 실제로 안 됐나 — 체크리스트 구멍

  • BGM 무음 확정: 아웃트로 −58~−66dB = 사실상 안 들림(합성패드 vol 0.08). → 형 결정: BGM=A(합성 크게 0.25). 진짜 음원(B)은 형이 파일 주면 교체.
  • 보이스ID 어긋남: 쓴 값이 정본과 다름. 형이 "current 맞다" 확정 → 어색함은 비트별 분리 TTS→연속 read로 해결(하니스 수정, 단 트렁크 미반영).
  • 체크리스트가 못 걸른 이유: "스트림 있나/플래그 켜졌나"만 봄. "실제 들리나/정본 보이스인가"는 안 봄. → 보강: 아웃트로 볼륨 FAIL 검사 + 보이스ID 일치 검사.

기존 대비 변경점 · 좋고/나쁨 · 수정안

바뀐 것 (그 방이 밤샘으로 세운 것)

  • 연속 TTS + BGM boost 하니스 — 좋음: 문장 뚝뚝 끊김(띄어쓰기 어색) 해결, 자연스러운 호흡. 나쁨/리스크: 수정본이 트렁크에 없음(본진 전용) → 백업 안 됨, 본진 리셋되면 소실.
  • 렌더엔진 ffmpeg + Remotion 병용 — 매니페스트가 메시지 중요도로 렌더러 선택(결정 박제 완료). 도형 애니 완성도 문제(8/5)는 Remotion 라인으로 해결 방향.
  • Codex 자동실행기 — 형→Cowork→_codex_inbox→Codex 실행 구조. 리스크: 스크립트 트렁크에 없어 검증·백업 불가.

이렇게 수정하겠다

  • 본진의 하니스 수정본 + codex_watch를 트렁크에 push → 백업되고, 이 방이 실물로 검증 가능 → 도면이 초록으로 바뀜.
  • 이 방 커밋 9개가 막힌 근본 = 세션 소스 미등록 → 등록하면 양방향 동기화 열림.

🔴 핵심 병목 (형이 겪은 "된다더니 멈춤"의 진짜 원인)

이 방 ↔ 본진 동기화가 반쪽이다

  • 이 방은 커밋해도 push 못 함(프록시) → 내 작업이 본진으로 안 감.
  • 본진 최신(하니스·codex·렌더결과)은 트렁크로 안 올라옴 → 이 방이 못 봄.
  • 그래서 두 방이 서로의 진짜 상태를 못 보고, "됐다"고 말하는데 실제로는 저쪽에서 멈춰 있음.
  • 진짜 해결 2가지: ① 세션 소스에 리포 등록(이 방 push 열림) ② 본진이 하니스·codex·렌더결과를 트렁크에 push(이 방이 봄). 이거 되면 이 구조도가 실시간으로 초록이 되고, 다시는 "된다더니 멈춤"이 안 생겨.

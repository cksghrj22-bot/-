## 파이프라인 (이 순서 그대로)
1. `ffmpeg -i <인터뷰> -vn -ac 1 -ar 16000 -c:a pcm_s16le audio.wav`
2. `ffmpeg -i audio.wav -af silencedetect=noise=-36dB:d=0.20 -f null -` → **말덩어리 경계 실측**
3. whisper(faster-whisper, medium, ko, word_timestamps) → **대사 텍스트만** 가져온다
4. **군말 컷**: 말덩어리 첫 토큰이 `어/아/음/그/저/저기/자` 면 그 토큰+뒤 침묵 통째 삭제
5. **무음 컷**: 침묵 0.40초 초과분 삭제. 앞 0.15초 / 뒤 0.55초만 남김
6. 자막 = 말덩어리 1개당 1줄. 한 줄 ≤26자, 2줄까지
7. 단일 ffmpeg 합성 (아래 §싱크)
8. 검사 → 보고

## §싱크 — 여기서 틀리면 다 틀어진다
❌ 덩어리를 파일로 잘라 `concat` 데무서 붙이지 말 것.
   덩어리마다 오디오가 영상보다 0.002~0.265초 짧게 잘려 **18덩어리에 1.18초 누적 밀림**(실측).
✅ **ffmpeg 한 번 안에서 trim+atrim+concat 필터.**
```
[0:v]trim=A:B,setpts=PTS-STARTPTS[tvN];[0:a]atrim=A:B,asetpts=PTS-STARTPTS[taN];
...[tv1][ta1][tv2][ta2]...concat=n=N:v=1:a=1[mv][ma]
```
검사: 영상 duration − 오디오 duration **≤ 0.05초**

## 레이아웃 (1편 규격 그대로)
```
[mv]scale=1080:1920,crop=1080:1152:0:180,setsar=1,fps=30[top]   # 상단 60%
<화면기록 7구간 concat>,scale=1080:768,setsar=1,fps=30[bot]      # 하단 40%
[top][bot]vstack=inputs=2 → ass=자막.ass
```
- 자막: Noto Sans CJK KR 60 / **불투명 검정박스**(BorderStyle=3, BackColour `&H00000000`, Outline=10) / Alignment=2 / **MarginV=760**
- 핸들: `@Atnownchano` / 34px / 흰색 30% / Alignment=3 / **MarginV=268** (1700 위로)
- 끝: 영상 `fade` 1.3초 · 오디오 `afade` 1.2초
- 오디오: `loudnorm=I=-15.4:TP=-1.5:LRA=11`
- **BGM 없음** (차노 지시, 이 편 한정)

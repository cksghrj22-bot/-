# 🎬 매니페스트 라이브러리 — 대본 1개 → 완성본 1개 (엔진: `shorts.make`)

> 2026-07-28 이찬호 지시로 확립. **엔진은 하나(`shorts/make.py`), 매니페스트(루트)는 여럿.**
> 창의는 형 몫(생각·메시지·스토리). 이 라이브러리는 그 생각이 **안 깨지고** 나오게 하는 기계다.

## 원칙 (형 확정)
- **새 표현 = 새 매니페스트.** 새 스타일·포맷이 필요하면 이 폴더에 `.json`을 하나 더 만든다. 기존 걸 지우지 않는다.
- **검증된 좋은 요소 = 기존 매니페스트에 껴넣기.** 잘 먹힌 연출(애니·오버레이·톤)은 관련 루트 매니페스트에 흡수시켜 개선한다.
- **영상 메시지에 따라 가장 맞는 루트를 골라 쓴다.** 매번 새로 짜지 않는다 = 안 깨진다(그룹으로 뭉쳐 있으니).
- 매니페스트는 **자기완결 그룹**이다 — 대본(phrases)·footage(segments)·애니(overlays)·아웃트로가 한 파일에.

## 쓰는 법
```
python3 -m shorts.make content/manifests/<루트>.json --out 완성본.mp4 --workdir <작업폴더>
```
→ TTS(타임스탬프 싱크)·footage 스트리밍 추출·애니 오버레이·자막·BGM·아웃트로까지 한 번에. (발행/업로드는 형 검수 후 별도)

## 루트 목록 — **줄기별로 하나씩** (형 2026-07-28 "다 섞지 말고 줄기로 하나씩 만들어놔, 내가 좋다고 한 영상 나오면")
> 원칙: 각 매니페스트는 **한 줄기(마인드/흑백 · 미용 · …)의 한 좋은 영상**. 섞지 않는다. **형이 "좋다"고 한 것만** 정본으로 저장.

### 🖤 마인드/흑백 줄기 (메시지·철학) = **메시지영상 루트**
> 형 2026-07-28 정의: **흑백 기본** + 앞/중/뒤에 **큰 중앙 메시지·물음 카드**(검은화면, `"bigcard": true`)로 핵심 확실히 강조 + 중간중간 **감초 애니**(주먹 화이팅 등)로 지루함 깨기. 실사는 배경 많으면 `"zoom"`으로 인물 확대.
> 조립 옵션: `bw`(흑백) · `zoom`(확대) · black+`bigcard`(큰 중앙 메시지) · overlay `fist_raise`(주먹 화이팅 감초).
| 루트 파일 | 특징 |
|---|---|
| `메타안경_산_후기.json` | 검은훅카드 → 실사 언박싱(개봉·리빌·착용) → 가치격차 데이터애니(진한 스크림) → 상담 실사 인서트 → 엔딩 질문카드 → SNS일기 아웃트로 |
| `화이팅_밑빠진독.json` | **메시지영상 표준**: 물구나무 흑백(bw+zoom) → 중간 **큰 검은 메시지카드**(bigcard, ~22초 지루함 깨기) → 엔딩 **주먹 화이팅 애니**(fist_raise) |

### 💇 미용 줄기 (기술·데이터 도식)
| 루트 파일 | 특징 |
|---|---|
| `볼륨매직_S2_네이프.json` | 장마철 곱슬 훅 → **두상 존-% 도식**(dusang_zones: 톱10·페이스30·백15·네이프70, 존별 자기 줄에서 등장) → 엔딩 질문 |
| `부시시_곱슬일까_손상일까.json` | 검은 훅카드 → **모발 뿌리→끝 손상 그라데이션 도식**(strand_zones: 자연곱슬10·녹은+탄60·만성95, 끝일수록 게이지↑·속심 코어) → 엔딩 질문. 컬러·실사 모발인서트(얼굴X)는 컨펌 후 v2. ⏳형 컨펌대기 |

> 새 좋은 영상 = 그 줄기 표에 한 줄 추가(새 매니페스트). 좋은 요소는 같은 줄기 기존 매니페스트에 흡수.

## 🧩 요소(부품) 카탈로그 — **컨펌본에서 뽑아 쌓는다** (양산형 탈피)
> 형 원칙(2026-07-29): "**내가 컨펌한 영상을 잘 분석해서 요소요소를 정리해놔라.** 매니페스트를 그냥 딱 붙여 계속 넣는 게(양산형) 아니라, **메시지를 더 잘 전달하도록 계속 바꿔 나가고, 그 종류(양)를 늘려 나가는 것**이 중요하다." → 아래는 검증된 부품 목록. 새 컨펌본이 나올 때마다 요소를 분석해 여기에 **등록(신규)하거나 개선**한다.

| 요소 | 종류 | 하는 일(메시지 역할) | 검증(출처) | 호출 |
|---|---|---|---|---|
| `bigcard` | 카드 | 검은화면 큰 중앙 메시지/물음 — 핵심 각인 | 메타·화이팅·볼륨매직·부시시 | seg `black:true, bigcard:true` |
| `black` | 카드 | 검은화면 하단자막 — 설정/전환 정적 비트 | 다수 | seg `black:true` |
| `dusang_zones` | 도식애니 | 두상 4존 %비율 — 부위별 시술강도 | 볼륨매직 S2(컨펌) | seg `anim:"dusang_zones", numLine` |
| `strand_zones` | 도식애니 | 모발 뿌리→끝 손상 그라데이션(구간·게이지·속심 코어) | 부시시(시안·컨펌대기) | seg `anim:"strand_zones", numLine` |
| `value_gap` | 데이터애니 | 두 값의 격차 강조(백만원 vs 9억) | 메타안경 | overlay `type:"value_gap", fromLine, toLine` |
| `fist_raise` | 감초애니 | 주먹 화이팅 — 지루함 깨는 리듬 | 화이팅 | overlay `type:"fist_raise", line` |
| `zoom` | 프레이밍 | 배경 많은 실사서 인물 확대 | 화이팅 | seg `zoom` |
| `bw` | 톤 | 흑백 — 마인드/메시지 무게 | 마인드 줄기 | seg `bw` |
| voice B | 보이스 | 차분·신뢰 톤(stab.42/style.15/1.05x) | 전 영상 | manifest `voice` |
| `outro` | 마무리 | SNS 일기 아웃트로 — 참여 유도 | 메시지 줄기 | manifest `outro` |

### 🔁 컨펌본 → 요소화 절차 (내가 매번 돈다)
1. **형이 컨펌한 영상을 분석** — 어떤 요소가 메시지를 잘 전달했나 뜯어본다.
2. 재사용 부품이면 위 카탈로그에 **등록(신규)** 또는 **기존 항목 개선**.
3. 같은 줄기 매니페스트에 **흡수** or **새 매니페스트로 확장**(종류·양 늘리기).
4. 매번 처음부터 짜지 않는다 — **검증된 부품을 조합**해 그 영상 메시지에 맞게 튜닝. (양산형=같은 걸 복붙 / 우리=부품 쌓아 계속 개선)

> **📥 footage 스캔은 코드방(나) 담당** — 형이 "스캔해봐/올렸다" 하면 내가 `python3 -m shorts.intake_scan`(OAuth 토큰, MCP 불필요)으로 인트레이 리스트→분류→등록. 형이 직접 스캔하지 않는다.
> ⚠️ **정본 아닌 실험/틀린 컷은 저장하지 않는다**(형 "이상한 거 저장 금지"). 삭제 예: 차노_재정의(볼륨매직 순수도식) — S2가 정본.

## ✅ 매니페스트 필수요소 체크(누락 금지 — 새 매니페스트 저장 전 대조)
- **마인드/흑백(메시지영상)**: `bw` 흑백 · 하단 교보자막 · **`outro`(SNS 일기 아웃트로) 무조건** · (권장)참여엔딩 질문카드+CTA "자신의 생각을 댓글로 남겨주세요." · (선택)bigcard/fist 감초.
- **미용/도식**: 훅 · 존/비율 완결(형 구술 항목 전부) · 엔딩 질문.
- 공통: BGM · 나레이션 라임부호 · 해시태그 stem.

## 매니페스트 스키마 (요약 — 상세는 `shorts/make.py` 최상단 docstring)
```jsonc
{
  "title": "...",
  "voice": {"stability":0.42,"style":0.15,"speed":1.05},   // 생략 시 자연 기본톤
  "bgm": "<mp3>", "outro": "SNS에 일기를 쓰고 있어요",
  "phrases": [["raw(합성/정렬)","disp(자막·\\N줄바꿈)","en|null", false], ...],
  "segments": [                                             // 시간축 순서(빈틈없이 total 채움)
    {"black": true, "untilLine": 0},                        // 훅 검은카드
    {"src":"<DriveFileId>","ss":6,"hflip":true,"frame":"landscape","untilLine":3},  // 실사 beat
    {"black": true, "untilLine": 13, "tail": 3.4}           // 엔딩 + 아웃트로 여유
  ],
  "overlays": [ {"type":"value_gap","fromLine":2,"toLine":4} ]  // 데이터 애니(선택)
}
```
- 숫자("9억 9,900만")는 **자동으로 한글 읽기 변환**(`tts.koreanize_numbers`) → 말깨짐 없음. 손철자 불필요.
- 훅/엔딩(검은 segment에 걸린 자막)은 **자동 중앙정렬**.
- footage는 통다운 없이 **스트리밍 추출**(`drive_stream`) — 디스크·moov 문제 없음.

## 코드 게이트(안 틀리는 규칙 — 글 아니라 함수)
- `shorts/preflight.py` — 착수 전 **중복 자동차단**(예전 거 재탕 방지).
- `shorts/drive_stream.py` — 대용량 footage 스트리밍 추출.
- `shorts/tts.py` `koreanize_numbers` — 숫자 말깨짐 방지.
- `shorts/syncbuild.py` — 자막 타임스탬프 싱크. `shorts/shortstyle.py` — 교보/POP·프레이밍·아웃트로 정본.

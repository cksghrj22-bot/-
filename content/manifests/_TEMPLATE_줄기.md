# 매니페스트 줄기 정본 (2026-07-28 형 지시 — "확실한 줄기를 꾸준히, 실수한 부분 꼭 끼기")

> 형: "창의라서 양산을 실수한다는 변명 금지. 그냥 까먹는 것. 확실한 줄기를 만들어."
> → 아래 필수요소는 **`shorts.make._require`가 렌더 전 강제 검증**한다(누락이면 렌더 거부). 사람 기억에 안 맡긴다.

## 공통(모든 줄기)
- `stem`: "message" | "product" | "magic" **필수**.
- **메시지로 시작**: `phrases[0]` = 그 영상의 핵심 물음/메시지(훅). 비면 거부.
- `voice`(EL 정본), `bgm`, `phrases`(라임부호), 해시태그 stem.

## 🖤 message — 마인드/흑백 메시지영상 (예: 화이팅_밑빠진독)
필수(누락=렌더거부):
- [x] `stem:"message"`
- [x] **흑백** — 실사 세그 `"bw": true`
- [x] **큰 중앙 메시지카드** `bigcard` 최소 1 (검은화면+큰 물음/핵심메시지, 앞/중/뒤)
- [x] **`outro`**(SNS 아웃트로) — ★계속 빠뜨린 부분★
- 권장: 첫 세그를 bigcard/검은 훅카드로 **메시지로 시작** / 참여엔딩(질문카드+CTA "자신의 생각을 댓글로 남겨주세요.") / 감초 애니(`fist_raise`) / 배경 많으면 `zoom`.

## 📦 product — 제품·언박싱+데이터논증 (예: 메타안경_산_후기)
필수:
- [x] `stem:"product"`
- [x] **`outro`**(SNS 아웃트로) — ★
- 구성: 검은 훅카드 → 실사 언박싱 → 가치격차 데이터애니 → 엔딩 질문카드.
- 썸네일: 흑백커버+큰제목(기존 방식).

## 💇 magic — 미용 도식 (정본 = 쇼츠 올린 S2 + 네이프 오버레이)
> ⚠️ **S2를 통째로 다시 만들지 않는다**(순수 애니 재빌드=오답, 형 확인). 쇼츠 올린 S2가 정본.
- 정본 파이프라인: `python3 -m shorts.patch_nape <S2.mp4> <out.mp4>` — S2 도식에 **네이프(주황)만 오버레이**, 오디오·실사·나레이션 그대로.
- 도식 **4존 전부**(톱/페이스/백/**네이프**) — ★네이프 계속 빠뜨린 부분★. `make` magic 매니페스트는 나레이션에 4존 다 없으면 렌더거부.
- **메시지로 시작**: 첫 줄 훅 물음("장마철, 당신의 곱슬은 안녕하신가요?").

## 발행 경로
- **발행은 A방**(유튜브 예약·업로드). 본진 아님. 코드방(B) = 완성본 Drive 「앳나운_영상」 업로드 → A방이 픽업·예약.
- 발행·외부액션은 형 승인 후에만.

## 새 영상 만들 때 순서(고정)
1. stem 정하고 위 필수 체크리스트 채운 매니페스트 작성.
2. `python3 -m shorts.make <manifest>` — `_require` 통과 못 하면 못 만듦(그게 게이트).
3. QC(프레임·BGM·자막위치) → Drive 업로드 → A방 발행요청.
4. 잘된 것만 정본으로 저장, 틀린 컷 삭제.

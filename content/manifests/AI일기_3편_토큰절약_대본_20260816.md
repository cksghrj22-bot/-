# AI일기 3편 — 「토큰 아껴 쓰는 법 + 코덱스 연동」

> 규격: `knowledge/규격_일기형쇼츠_정본.md` 그대로 (상단 60% 얼굴 / 하단 40% 화면기록)
> 상태: **촬영 대기** · 2편(검수)은 별건으로 재촬영
> 길이: 대본 공백제외 288자 → **약 43초** (길이 기준 없음 — 참고값)

## 촬영 대본 — 이대로 말하면 됨

말 시작 전 **1초 정지**. 「어~」 「아~」 붙이지 말 것 (편집에서 다 잘라내야 함).

```
클로드 토큰 다 쓰고 하루 날린 적 있어요?

저는 있었어요.
근데 원인이 웃겼어요.
"이거 요약해줘" 이런 거였어요.
요약하는 데 제일 비싼 모델을 쓰고 있었던 거예요.

그래서 셋으로 나눴어요.
요약 번역 비교는 제 컴퓨터 안에 있는 공짜 모델한테.
글이랑 판단만 클로드한테.
렌더랑 업로드는 코덱스한테 넘겨요.

클로드가 정하고, 코덱스가 합니다.
머리랑 손을 나눈 거예요.

코덱스가 30분짜리 렌더 도는 동안
클로드는 다음 편 대본을 씁니다.
기다리는 시간이 없어져요.

그리고 하나 더.
세션 하나를 하루 종일 켜놓지 마세요.
그게 제일 비쌉니다.
대화가 길어질수록 매번 그 길이만큼 다시 계산해요.
일 끝나면 새로 여세요.

저는 이렇게 해서 3분의 1만 씁니다.
```

## 하단 자료화면 배치

| 구간 | 말 | 하단 화면 |
|---|---|---|
| 훅 | 토큰 다 쓰고 하루 날린 적 | **토큰 소진/한도 화면** ⚠️필요 |
| 원인 | "이거 요약해줘" | 터미널 대화 |
| **분배** | 셋으로 나눴어요 | ⭐**`물어` / `본진` 두 명령 실제 실행** ⚠️필요 |
| 코덱스 | 클로드가 정하고 코덱스가 합니다 | ⭐**`_terminal_inbox` TASK json + 코덱스 실행 로그** ⚠️필요 |
| 병렬 | 기다리는 시간이 없어져요 | 두 창 동시에 도는 화면 |
| 세션 | 하루 종일 켜놓지 마세요 | `/usage` 또는 `/context` 화면 |
| 마무리 | 3분의 1만 씁니다 | ⭐**`라우터` 통계 출력 (절약률 %)** ⚠️필요 |

**⚠️ 새로 화면기록 떠야 하는 것 4개** — 기존 926MB 기록엔 없다.
찍는 법: 터미널에서 아래를 순서대로 실행하면서 화면기록 한 번에 뜨면 된다.
```
라우터                      # 통계 (절약률)
물어 "이 문서 세 줄로"        # 공짜 라우팅
본진                        # 클로드 진입
python3 scripts/render_trigger.py    # 코덱스 인계
/usage                      # 세션 사용량
```

# 분할화면 템플릿 — 상하 (베이스+설명)

> 유튜브쇼츠방 범용 템플릿
> 원본: AI일기 레이아웃 (2026-08-16 차노 확정)

## 레이아웃

```
┌─────────────────────────┐
│                         │
│    베이스 영상           │  ← 상단 60%
│    (얼굴/메인)           │
│                         │
├─────────────────────────┤
│  ┌─────────────────┐    │
│  │ 자막 (검은박스)  │    │  ← 경계부
│  └─────────────────┘    │
├─────────────────────────┤
│                         │
│    설명 영상            │  ← 하단 40%
│    (화면기록/증거/B롤)   │
│                         │
│         @핸들           │  ← 우하단
└─────────────────────────┘
```

## 사용처

| 유형 | 상단 (베이스) | 하단 (설명) |
|---|---|---|
| AI일기 | 인터뷰 (얼굴) | 코드/터미널 화면 |
| 튜토리얼 | 강의 (얼굴) | 시연 화면 |
| 리뷰 | 리액션 (얼굴) | 제품/콘텐츠 |
| 브이로그 | 메인 영상 | 참고 자료/지도 |

## 규격

| 항목 | 값 |
|---|---|
| 캔버스 | 1080×1920 |
| 상단 비율 | 60% (1152px) |
| 하단 비율 | 40% (768px) |
| 자막 위치 | 경계부 (y ≈ 1100~1200) |
| 자막 스타일 | 검정 불투명 박스 + 흰 글씨 |
| 핸들 위치 | 우하단 |

## ffmpeg 예시

```bash
# 상단 60% + 하단 40% 합성
ffmpeg -i base.mov -i explain.mov \
  -filter_complex "
    [0:v]scale=1080:-1,crop=1080:1152:0:0[top];
    [1:v]scale=1080:-1,crop=1080:768:0:0[bottom];
    [top][bottom]vstack
  " \
  -c:v libx264 -crf 18 output.mp4
```

## 핵심

> **말만 하는 게 아니라 진짜 한다는 걸 보여줌**
> 상단 = 말하는 사람, 하단 = 증거

# 만화카드 — 숱치기는 공간이다 (숱쳐도 무거운 머리)

- 형식: 손그림 만화카드 6장 (긴얼굴 단발과 동일 파이프라인)
- 생성기: `python3 -m shorts.cardposter <out.png> --spec sootchigidetail` (6장)
- 도안: scissors·hd_space·angle·wave·hd_layers
- 상태: **시안(발행본 아님)** — 형 OK 후 인스타 캐러셀

## 6칸 (통념 → 재정의 → 한줄)
1. 숱치기=양 덜어내기 → **숱은 양이 아니에요** / 배치의 문제
2. 볼륨=숱 많이 → **볼륨은 공간에서 나와요** / 사이가 떠야 흔들림
3. 가위는 아무 데나 → **가위는 설계예요** / 각도가 공간을 만듦
4. 숱 치면=가벼움 → **가벼움은 흔들림이에요** / 공간이 찰랑을 만듦
5. 치면 또 무거워짐 → **설계하면 오래가요** / 안 무너짐
6. '숱 쳐주세요' → **말은 결과로 하세요** / "움직이는 머리로"

- 마무리: 앳나운은 숱을 치지 않고 **공간을 디자인**해요.
